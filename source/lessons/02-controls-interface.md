## 学完能做到什么

- 看懂部署界面、地图界面、死亡界面和计分板四个区域的作用，不找错菜单。
- 看懂 HUD 上的罗盘、弹匣颜色、快慢机、姿态、体力和跳跃六类信息。
- 记住必须形成肌肉记忆的键位：移动、探头、翻越、换弹、医疗、标记和三个语音频道。
- 在一局里能不看键盘完成开枪、换弹、趴下、探头和标记五个动作。
- 能分清“流血”和“被压制”两种画面，不在受伤时做出错误判断。

::: takeaway
界面和键位不是背出来的，是在正确的位置重复出来的。先把常用动作练成条件反射，再谈战术。
:::

## 四个界面区域

Squad 的界面分成四个常用区域，新人第一件事是分清它们，不要在战斗中找错菜单。

**部署界面**：按 `Enter` 打开，是加入小队、换阵营、选兵种和选复活点的入口。左侧复活点列表，右侧地图，下方兵种。状态颜色：绿色正常，黄色或红色被压制或未激活，灰色不可用。

**地图界面**：按 `M` 打开，`N` 三级缩放。上面有占点、队友、队长标记、观察标记和网格。报点时对照网格和参照物，每 30 秒看一次即可。

**死亡界面**：被击倒后出现，显示黑白屏和倒计时。此时你还可以观察周围、报点、等医疗兵，不要立刻放弃。倒计时结束仍未被救，才会进入部署界面。

**计分板**：按 `Tab` 查看，显示双方票数、小队得分和模式。死亡后先看票差，判断这一波该稳还是该拼。

小队管理也在 `Enter` 界面：看成员、兵种、谁在说话，也能建队、锁队、转让队长。战斗中按 `Enter` 会进入部署界面，别乱按。

部署界面管“从哪活、用什么兵”，地图管“敌我在哪”，死亡界面管“等不等救”，计分板管“票差多少”。四个界面各司其职，不混用。

## HUD 与身体状态

屏幕上的信息很多，新人先盯住六样，其他可以慢慢学。

**罗盘**在屏幕最下方，数字是方位角度，`N`/`E`/`S`/`W` 是北东南西。罗盘还显示队长标记和 50 米内队友方向。报点用“角度 + 参照物”，不说“左边”。

**弹匣弹药量**在右下角，用颜色表示余量：白满，依次黄、橙、红，黑为打空。最右边是已装弹匣。30 发弹匣复活后枪膛已有 1 发，显示 29；换弹后 30+1，不要看到 29 就误按 `R`。

**快慢机**显示单发、连发或三连发。按 `1` 或鼠标中键切换。远距单发，中距快速单点，近距连发。三连发要按住左键才会持续射击。

**身体姿态**图标显示站、蹲、趴和左右倾。`Ctrl` 蹲，`Z` 趴，`Q`/`E` 左右倾。倾身只探小半个身子，看一眼就缩，不要架枪久露。

**体力值**是右下角白条。奔跑和匍匐消耗体力，白转红。体力低时枪口晃，`Shift` 屏息也撑不久。恢复速度：趴着不动最快，其次蹲、站、走。长距离交替跑走，别跑红。

**跳跃值**是右下角另一条竖线。每次跳约加四分之一，连跳四次后变矮。`Space` 翻矮墙、窗台；略高障碍用“跳一下立刻蹲”。不要乱跳。

**流血**：屏幕忽明忽暗、重影、心跳声，姿态图标橙白闪，会持续掉血。**被压制**：子弹擦过的咻咻声、画面变暗、视野变窄，但不会掉血。流血先找掩体止血，压制先换位置。

::: takeaway
HUD 六件套：罗盘看方向，弹匣看颜色，快慢机看单连发，姿态看身位，体力看白条，跳跃看黑条；流血会掉血，压制只挡视野。
:::

## 必须形成肌肉记忆的键位

新人不需要记住所有键位，但下面这些必须在第一局内练到不看键盘也能按出来。键位可以在设置里改，改完后以自己屏幕上的提示为准。

| 动作 | 默认键 | 要点 |
|---|---|---|
| 移动 | `W` `A` `S` `D` | 基础移动，不要边走边看地图 |
| 冲刺 | 按住 `Shift` | 消耗体力，低体力时枪口晃 |
| 下蹲 / 趴下 | `Ctrl` / `Z` | 先降身位再对枪 |
| 左倾 / 右倾 | `Q` / `E` | 掩体后短探头，探完就缩 |
| 跳跃 / 翻越 | `Space` | 翻矮墙、窗台；跳蹲上稍高的障碍 |
| 开火 / 瞄准 | 鼠标左键 / 右键 | 不开镜时没有准星 |
| 换弹 | `R` | 找掩体再换，不在敌人面前换 |
| 快慢机 | `1` 或鼠标中键 | 远单发、近连发 |
| 屏息 / 稳枪 | 按住 `Shift` | 消耗体力，红条时无法稳枪 |
| 架设脚架 | `C` | 机枪、特射架枪后更稳 |
| 切换装备 | `1`–`9` 或滚轮 | 手雷、烟雾、医疗、铲子都在这里 |
| 互动 | `F` | 上车、装弹、卸货；长按出轮盘 |
| 地图 / 缩放 | `M` / `N` | 每 30 秒看一次 |
| 部署 / 兵种 | `Enter` | 死亡后先看状态条 |
| 计分板 | `Tab` | 看票差和小队得分 |
| 附近语音 | 按住 `V` | 数十米内队友，三秒警告 |
| 小队语音 | 按住 `B` | 全队可听，主工作频道 |
| 指挥频道 | 按住 `G` | 只有队长和指挥官能发言 |
| 标记 / 队长轮盘 | 队长或火力组长按住 `T` | 选观察、进攻、防守标记；放队包、电台也在这里 |

`V` 是附近语音，不是报点菜单；`B` 是小队语音；`G` 是指挥频道。新人常把 `V` 当“报告敌人”，其实远处队长听不见。普通队员先在 `B` 里说“方向、距离、目标”；只有小队长或火力组长能按住 `T` 在地图或准星上补标记。附近语音不会被敌方听到，但枪声和动作仍会暴露位置，所以别用它闲聊。

手雷和烟雾：左键远、右键近。扔前用 `V` 喊“我扔手雷了/封烟了”，确认队友不在落点。筒子尾焰会伤人，室内或贴墙发射前先看身后。

::: takeaway
先记五组：移动与身位（WASD、Shift、Ctrl、Z、Q/E、Space）、射击（左键、右键、R）、医疗（5）、语音与标记（V、B、G、T）、界面（M、N、Enter、Tab）。`V` 是说话，不是报点；标记只有队长/火力组长能做。
:::

## 地图里的三类信息

地图上密密麻麻的标记分三类，新人要分清。

**第一类是敌我占点**。蓝方、红敌、灰白中立。黄色下箭头是可进攻点，紫色盾牌是需防守点。红点附近有队友，说明正在战斗；某点长时间没人，说明那条线可能空了。

**第二类是队友与敌方标记**。蓝点是队友，绿旗是本队队包，蓝旗是友邻队包（不能复活）。红色标记是队长或火力组长用 `T` 轮盘标的，可能已过时；普通队员用 `B` 报点，由队长补标。看到新情况及时补报。

部署物图标：橙色圆圈是主基地或可用复活点，绿旗是本队队包，蓝色/粉色城堡是兵站（蓝正常、粉被压制），白色弹药、扳手、机枪、迫击炮分别是弹药箱、维修站、机枪堡、迫击炮。红色前哨和堡垒是敌方电台和兵站。

**第三类是网格坐标和参照物**。粗线大格、细线中格、白线小格；纵向 A/B/C，横向 1/2/3。完整坐标是“字母 + 大格 + 中格 + 小格”，如 `E3-7-5`。标尺：大格约 300 米，中格 100 米，小格 33 米。

地图是决策工具。每 30 秒看一次，知道哪个点被占、哪里在战斗、队友在哪；同时看蓝点分布，判断哪里缺人。

::: takeaway
地图三类信息：占点（红蓝灰、黄箭头、紫盾牌）、标记（蓝点、绿旗、红旗、部署物）、网格（字母 + 数字，大格 300 米）。每 30 秒看一次，不盲目跑图。
:::

## 第一局键位练习

任务：进入训练场或单人本地服务器，不看键盘完成以下动作。

1. 身位：前进、后退、侧移、冲刺、蹲、趴、左右倾、翻矮墙，各 5 次。
2. 射击：举枪、开火、停火、瞄准、取消，各 5 次；切换一次单发和连发。
3. 换弹：打空后按 `R`，等动画完成，重复 5 次。
4. 医疗：按 `5`，右键给自己止血、左键对队友使用，各 3 次。
5. 语音与标记：按住 `B` 报“方向 + 距离 + 目标”3 次；如果是队长/火力组长，再按住 `T` 在轮盘里补 3 个观察标记。
6. 地图：按 `M` 打开、`N` 缩放，读出本队网格坐标。

完成后进入一场实战，尝试在不看键盘的情况下完成开枪、换弹、趴下、探头和报点五个动作。探头只探一秒，缩回来再判断，不要架着枪等人。

::: takeaway
肌肉记忆不是背出来的，是重复出来的。训练场每个动作重复 5 次，实战中用一次就记住一次。
:::

## 决策速查

- 死亡后先看死亡界面和状态条，不要盲目点复活点。
- 按 `M` 打开地图，按 `N` 缩放，每 30 秒看一次占点和队友位置。
- 报点先用 `B` 说“方向 + 距离 + 目标”；队长/火力组长再用 `T` 补标记。
- `V` 是附近语音，`B` 是小队语音，`G` 是指挥频道，三者不要混。
- 跑步消耗体力，长距离移动交替跑和走，不把白条跑红。
- 换弹前先找掩体，不在敌人面前空枪。
- 屏幕闪烁、心跳声是流血；咻咻声、视野变窄是压制。

::: takeaway
速查表解决“先按哪个键、先看哪块屏”：先看状态，再看地图，再选频道，最后才开枪。
:::

## 实战案例

::: case 标记加语音的区别
两名新人同时发现敌方载具。A 直接开火，打不穿装甲，暴露后被机枪扫倒。B 先按住 `B` 说“C4 路口，西北 300 米，敌方步战车，沿公路向南”，队长在地图上补了标记，随后三人包抄，用反坦克武器击毁。

复盘：A 只考虑自己开火，B 把敌人信息变成全队可执行的目标。标记让队友知道“在哪”，语音让队友知道“是什么、要做什么”，两者缺一不可。
:::

::: case 频道选错的代价
C 在附近语音喊“队长，B 点有敌人！”，但队长在 80 米外听不见，身边只有两个新人。D 按住 `B` 说“二队，B 点敌方步兵两人，沿围墙向北”，全队收到，队长立刻让机枪架住北侧路口。

复盘：附近语音只覆盖身边一小圈队友，传不到远处队长；小队语音不受距离限制。敏感汇报用小队语音，三秒内的警告才用附近语音。
:::

::: takeaway
信息要传给对的人：标记负责位置，语音负责内容，频道负责范围。传给错的人等于没传。
:::

## 常见错误

::: mistake 症状—原因—改法
- 症状：战斗中找不着换弹键，被打死。原因：键位没形成肌肉记忆。改法：训练场重复换弹 10 次，闭着眼也能按出来。
- 症状：地图不看，跑进敌方占点。原因：只看眼前，不看全局。改法：每 30 秒按 `M` 看一次地图。
- 症状：发现敌人不报告，只自己开枪。原因：不懂信息共享。改法：先按住 `B` 报方向距离，再由队长/火力组长补标记。
- 症状：按 `V` 喊队长，队长没反应。原因：把附近语音当小队语音。改法：远处队长用 `B`，身边队友才用 `V`。
- 症状：把 `T` 当语音切换键。原因：记错键位。改法：`V`、`B`、`G` 是按住说话，`T` 是队长菜单。
- 症状：屏幕一闪就以为自己被打，站着找敌人。原因：分不清流血和压制。改法：流血先找掩体按 `5`，压制先换位置。
:::

::: takeaway
常见错误都是“只看自己，不看团队”或“键位记混”。看地图、会标记、用对频道，新人就能立刻对全队有用。
:::

## 实战练习

::: drill 界面与键位一局通关
- 进服后 1 分钟内，按 `M` 打开地图，找出本队至少两个占点并说出网格坐标。
- 一局内按住 `B` 报点至少 3 次；如果你是队长/火力组长，用 `T` 补 3 个标记。
- 一局内不看键盘完成至少 5 次换弹和 3 次探头（`Q` 或 `E`）。
- 死亡后，在死亡界面停留 3 秒，判断是等救还是放弃，再选复活点。
- 按住 `B` 向队长汇报一次自己的位置，按住 `V` 对身边队友说一次“我扔手雷了”。
- 完成标准：地图坐标说对 2 个以上，标记生成 3 个以上，换弹和探头不看键盘，三个频道各用对一次。
:::

::: takeaway
把界面和键位练成条件反射，后面每一课都会更轻松。
:::
