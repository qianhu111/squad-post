## 学完能做到什么

- 听到枪声、爆炸或引擎声，先判方向、再找掩体，不站着找火光。
- 把情报拆成事实、推断、猜测，只把前两层送上频道，并给推断标注依据。
- 用五栏记录信息：时间、地点、事件、来源、可信度，事后能复查。
- 在 10–15 秒内给队长一条可执行的态势更新。
- 信息过载时按“是否影响 30 秒内决策”取舍，主动丢掉无关细节。

::: takeaway
态势感知的成果不是“我感觉这边有人”，而是能被复核、能直接触发动作的记录。守住这条标准，汇报才有重量。
:::

## 什么是态势感知

态势感知不是“看得多”，而是“看懂了”。它分三层：感知，看到听到什么；理解，敌人在做什么；预判，敌人下一步去哪。

| 层级 | 要回答的问题 | 合格输出 | 不合格表现 |
|---|---|---|---|
| 感知 | 在哪、几个、什么兵种 | “C5 路口，两名步兵，一挺机枪” | “有人” |
| 理解 | 在做什么、为什么 | “他们架枪封路，掩护另一组绕后” | “不知道，反正有人” |
| 预判 | 30 秒后可能出现在哪 | “下一波可能从西侧楼梯上来” | “等打起来再说” |

新人常卡在第一层：看到红点就报“有人”，说不清敌人要干什么。合格的观察员能说出“我看到什么、我认为敌人想干什么、建议怎么办”。

::: figure 图 12-1：态势感知是闭环：感知、理解、预判、行动、回报，少一步信息就断。
![态势感知闭环](../../assets/images/g2-sa-loop.svg)
:::

态势感知也不只针对敌人。友军蓝点的朝向、死亡的速度、复活点还在不在、弹药和医疗够不够，都会改变“下一步能做什么”。一队人全挤在正面，侧翼没有蓝点，这本身就是一条情报；友军在两分钟内成片倒下，说明那条线正在被压穿；队包突然消失，说明 30 米内进了敌人。把友军状态当成态势的一部分，才不会只盯着红点看。

正确循环是观察—判断—决策—行动—回报：每 3–5 秒转一次头，每 30 秒看一次地图，把蓝点、红点和亲眼所见对照。矛盾时以可复核来源为准：亲眼优先于转述，转述优先于过期标记。地图是账本，不是照片。

::: takeaway
从“看到”到“看懂”差的是意图和下一步。每 30 秒把地图、声音、目视对一次账，红点才会变成可用的判断；友军状态也是态势的一部分。
:::

## 从友军枪声读出战线

不用看到人，也能从枪声节奏判断友军那边发生了什么。声音是免费的态势更新，前提是你知道每种节奏对应什么距离。

| 听到的节奏 | 大致含义 | 你该做什么 |
|---|---|---|
| 单发、慢速点射 | 友军在中远距离精确射击 | 打开地图看他朝向，判断敌人在哪 |
| 单发或三连、节奏较快 | 中近距离交火，双方都在找机会 | 准备侧翼支援，别从正面加入 |
| 全自动、快速三连 | 近距离交战，可能已经贴脸 | 立即转向，优先救人或压制 |
| 手雷、烟雾、救人声 | 敌人已在附近，通常 50 米内 | 停止直线前进，找掩体，报方位 |
| 长时间没有声音 | 可能已清、可能被清、也可能在绕后 | 不要假设安全，用眼睛和地图补确认 |

听友军枪声时，先看小地图上他的朝向。他朝北打，敌人大概率在北面；他朝北打但枪声离你越来越近，说明敌人正在往你这边压。枪声密集度还能看出交火烈不烈：稀稀拉拉的单发是互相试探，连续全自动是已经咬住，突然全停可能是有一方倒了或在换弹。

支援方向比支援速度更重要。正面已经打成一团，你从正面冲进去只会多送一个人；从侧翼绕过去，哪怕晚十秒，也可能打到对方的侧身。听到友军交火，先问“敌人在他哪个方向、我从哪边能打到敌人的侧面”，而不是“我要多快跑到他身边”。

::: takeaway
友军枪声是免费情报：慢点射是远距离，快速三连是中近，全自动是贴脸；先看朝向，再从侧翼支援，别从正面加入。
:::

## 事实、推断、猜测的区别

三类信息混在一起，队长就不知道该信哪一部分，只能凭感觉下令。

| 类型 | 定义 | 举例 | 汇报措辞 | 队长怎么用 |
|---|---|---|---|---|
| 事实 | 亲眼看到或听到，可复核 | “东侧二楼窗口，一个人头” | “我看到……” | 直接调枪线 |
| 推断 | 基于事实的合理推论 | “窗口有人，说明敌人在观察这条街” | “我认为……因为……” | 可参考，留后手 |
| 猜测 | 没有直接依据的判断 | “敌人应该在准备偷点” | “可能……需要确认” | 只能用来提问 |

错误汇报：“东侧有人，他们要偷点，我们必须回防。”三类信息糊成一团，队长无法判断风险。正确汇报：“东侧二楼窗口，一名敌方步兵，大约 150 米，正往北移动。我认为他在侦察，因为窗口覆盖我们进点路线。建议派一人压制，其余人不动。”事实先行，依据跟上，建议最后。

措辞要分级：看到就是看到，推断要带“因为”，猜测要带“需要确认”。一条汇报最多一个猜测，且放在最后。没有依据的推断本质上就是猜测，不该占用战斗频道。

::: takeaway
汇报顺序固定为事实、依据、推断、建议。没有“因为”的推断不要上频道，猜测永远放在最后并标明待确认。
:::

## 记录关键信息：时间与来源

交火后 90 秒，短时记忆就会明显失真。记录固定五栏：时间、地点、事件、来源、可信度。

| 时间 | 地点 | 事件 | 来源 | 可信度 |
|---|---|---|---|---|
| 14:22 | D6 桥北 | 敌方坦克向东 | 侦察车目视 | 确认 |
| 14:25 | D6 桥北 | 坦克可能去 E 点 | 由路线推断 | 待确认 |
| 14:31 | C4 东侧楼 | 两名步兵进二楼 | 亲眼所见 | 确认 |
| 14:36 | C4 东侧楼 | 窗口出现机枪 | 队友“阿岚”报告 | 转述 |
| 14:40 | 北侧公路 | 反复听到引擎声 | 声音 | 方位确定，距离不明 |

时间用游戏内计时或“开局第几分钟”都行，关键全队统一。地点用地图网格，如“D6 桥北”“C4 东侧二楼”，不要用“我这边”。来源写明亲眼、某位队友、无人机、载具观察还是声音；来源决定可信度，可信度决定这条信息能不能拿来做决策。

值得记的有：敌方 FOB 或兵站的大概位置和发现时间、敌方载具的方向与时间、队包放置时间和冷却、己方死亡人数、点位归属。不要记“谁开了第一枪”“谁踩了队包”，记录变成杂记，关键信息反而被淹没。

### 记录敌人的习惯

单次事件是情报，重复出现就是规律。敌方小队也会有自己的习惯：每次都从西侧楼梯上、每次都在同一个窗口架枪、每次丢完烟再冲、增援间隔大约两分钟、医疗兵总躲在同一个墙角。把这些重复行为记下来，下一次就能提前架好枪，而不是等他们出现再反应。

记录习惯不用写长，一句话就够：“敌方三次从西侧楼梯上，间隔约 90 秒”“机枪每次都在钟楼二层，先架枪再推进”。一局里能记下两条，下一局就能用上。但规律也会被对方修正：你连续两次在楼梯口打退他们，第三次他们可能改走窗户或先扔雷。规律是用来预判的，不是用来偷懒的；连续得手两次后，要主动想“他们会怎么变”。

::: takeaway
五栏记录法的核心是来源和可信度：同样的位置，亲眼确认和听人转述是两回事。写下来，队长追问时你才拿得出证据；把重复出现的行为记成规律，才能提前一步。
:::

## 向队长输出态势更新

队长不需要战场解说，只需要能直接决策的信息。标准结构：地点 + 敌我状态 + 建议动作。

| 场景 | 模板 | 示例 |
|---|---|---|
| 接敌报 | 地点 + 敌人数量兵种 + 我方状态 + 请求 | “C4 东侧，敌方两名步兵，我们一人在掩体后，请求火力压制。” |
| 观察报 | 地点 + 动向 + 推断 + 建议 | “D6 桥北，一辆运兵车往南，我认为要绕 C 点侧翼，建议机枪转东。” |
| 求援报 | 地点 + 危机 + 支援 + 时限 | “B3 兵站被压，敌人三人 25 米内，需要两人回防，30 秒内。” |

完整示例：“C 点东侧，敌方两人正往北移动，我们机枪在南侧架枪，建议从西侧绕侧。”地点、敌我状态、友军状态、建议齐全，队长可以直接下令。

不要只说“敌人很多”或“情况不妙”。没有数量、方位、动作，只会增加决策负担；也不要从三分钟前讲起。战斗中每 30–60 秒更新一次，位置变化立即更新，没有变化不重复。一条控制在 10–15 秒，结尾说“完毕”。队长正在下令时先记下，等他说完再报。

::: takeaway
态势更新是给队长的决策素材，不是战场解说。地点、敌我、建议三件套齐全，十秒内说完，才算合格。
:::

## 行动之后要回报

信息闭环的最后一步是回报。你看到的、判断的、做的，如果不告诉队友，别人就不知道那块地方现在是什么状态，整张信息网就断了一根线。

回报的内容不是过程，而是“结果”和“状态变化”：

| 你做了什么 | 该回报什么 | 不该只说 |
|---|---|---|
| 清掉一个房间 | “二楼清了一个，楼梯口安全” | “我打死了” |
| 没打掉目标 | “没打掉，他缩回窗口，别从正面露头” | “没打中” |
| 转移到位 | “我已到 C4 北侧，正在看东边” | 沉默 |
| 搜过一片区域 | “仓库北侧看过，没有敌人” | “这边没人” |
| 需要补给 | “弹药快没了，谁有弹药包” | 继续打空枪 |

回报要及时，但不必每做一件事都报。判断标准还是那三条：会不会影响 30 秒内的决策、会不会改变当前任务、有没有人要立刻行动。清掉关键位置的敌人、发现目标没死、转移到新位置，这三类要马上报；普通换弹、补血、捡东西，可以等战斗间隙再说。

回报还有一个作用：让队长知道“这条信息已经用过了”。你报“二楼有人”，队长调了机枪；你打完后报“二楼清了”，队长才能把机枪转去下一个方向。只报发现不报结果，队长会一直以为那里还有威胁，火力就浪费在空窗口上。

::: takeaway
行动后回报结果和状态变化，不报过程；清掉、没打掉、转移到位都要说，队长才知道哪条信息已经用完。
:::

## 信息过载与态势图节奏

交火时频道里同时有枪声、脚步、队友喊话和命令。全部转述等于没有转述。开口前问三句：会影响 30 秒内的决策吗？会改变当前任务吗？有人要立刻行动吗？三问没有一个“是”，就先压住。

| 信息 | 是否上报 | 理由 |
|---|---|---|
| 敌人进入 50 米内 | 立即报 | 直接威胁，所有人要调枪线 |
| 兵站被压、复活中断 | 立即报 | 改变全队增援计划 |
| 远处 300 米交火 | 记录，不报 | 与当前任务无关 |
| 击倒一名敌人 | 可报，一句带过 | 有用，但不该挤掉威胁信息 |
| 敌人拿什么枪 | 看情况 | 只有影响打法时才报 |
| 同一名敌人第三次被看到 | 不重复 | 没有变化的信息不占频道 |

优先级：先报生死，再报点位，最后报战果。生死是敌人已威胁到队员或复活点；点位是 HAB、队包、占领点、载具路线变化；战果通常不改变下一步。两人同时开口，让正在交火的那组先说。

看图节奏随战况变：开局 20–30 秒看点位和友军分布；行军每 30 秒看前方 200 米和两翼；交火中每 10–15 秒扫小地图边缘和死亡标记；驻守每 30–45 秒检查接近路线；乘车每 20 秒看道路前方。看得太勤会站桩挨打，太少会错过包抄。标图只标确认过的敌人，推断用嘴说；标记还在不等于敌人还在，超过一两分钟没更新只能当参考。

::: takeaway
三问过滤：影响 30 秒决策吗、改变任务吗、有人要立刻行动吗。三问皆否就闭嘴记录；看图节奏则随阶段变，交火快、行军稳。
:::

## 决策速查

| 场景 | 第一动作 | 汇报要点 |
|---|---|---|
| 听到不明枪声 | 先找掩体，别找火光 | 方位 + “疑似”，不报人数 |
| 看到敌人 | 先数数量和兵种 | 地点 + 数量 + 方向 + 距离 |
| 想说推断 | 先找依据 | 没有“因为”就不说 |
| 频道拥挤 | 判断三问 | 只报生死和点位变化 |
| 标记过期 | 降级为参考 | 补“最后目视在几分钟前” |
| 队长正在下令 | 记下，等说完 | 不抢话，紧急先喊“紧急” |
| 交火两分钟 | 每 15 秒扫小地图 | 重点看两翼和死亡标记 |

这张表是交火时的最低动作标准。打起来没有时间逐条回忆，练到看到场景就能做出第一反应。

::: takeaway
速查表解决的是“第一秒做什么”：先保命、再定位、后汇报。顺序反了，信息再准也没人听得见。
:::

## 实战案例

城市图，我方两人小队驻守 C 点东侧街区，玩家担任侦察手，队长带另一人在点内。

| 时间 | 发生的事 | 处理 |
|---|---|---|
| 00:00 | 东侧公路传来引擎声约 4 秒 | 卧倒贴墙，判断约 2 点方向 |
| 00:05 | 第一次汇报 | “C 点东侧 200 米，公路方向有引擎声，疑似载具，需要确认。” |
| 00:20 | 运兵车驶过，车头朝南 | 目视确认，“一辆运兵车，往南，可能在东侧路口下人” |
| 00:35 | 车辆停靠，后门打开 | 推断敌人沿东侧楼梯进点，建议机枪转东 |
| 00:50 | 队长调转机枪 | 不重复报同一辆车，只报变化 |
| 01:10 | 四名步兵下车，两人进楼梯 | “步兵四名，两名进楼梯，两名留车边” |
| 01:30 | 交火，敌方两人倒地 | 只报“两名倒地，剩余退入东侧楼” |
| 02:10 | 北侧传来第二辆车引擎声 | 结合记录提醒“北侧可能有第二辆，注意背后” |

结果：队长提前把机枪转向东侧楼梯，第一波进楼的两人被压制；北侧提醒让点内队员及时转身。全程仅六次报，频道没堵。

复盘：做对的是声音先当提示、目视后才确认，每次汇报都带地点和数量，没有变化不重复。可改进的是 00:35 的推断说得偏满，应加“可能”，并说明依据是“车停后门、有人下车”。最危险的是 01:30 后盯着倒地敌人看了两秒，差点漏掉北侧第二辆车。

::: takeaway
案例里真正救命的不是某句神报点，而是“声音降级、目视升级、变化才报”的纪律。记录让 02:10 的提醒有据可查，而不是临时慌张。
:::

## 常见错误

| 症状 | 原因 | 改法 |
|---|---|---|
| 汇报“敌人很多”，追问才说数量 | 只描述感受，没有量化 | 开口前先数：几个、什么兵种、哪个方向、多远 |
| 把“他们要偷点”当事实说 | 事实和推断混层 | 改成“我看到两人往西，我认为可能绕后” |
| 同一条信息重复报三遍 | 没有变化也更新 | 设 30–60 秒节奏，只在变化时开口 |
| 记录只有地点，没有时间和来源 | 把记忆当档案 | 固定五栏，交火后 90 秒内补写 |
| 盯着地图超过五秒 | 把看图当观察 | 三秒扫、十秒判，看完抬头 |
| 听到枪声就报“前方 100 米” | 把声音当测距仪 | 声音只报方位，距离靠目视或标记 |

这些错误的共同点是信息没有分层。分层不是形式，而是让队长知道哪句话可以押上全队的命。

::: takeaway
大部分错误不是不会看，而是不会分。把事实、推断、猜测分开，把声音和目视分开，准确率会立刻上一个台阶。
:::

## 实战练习

分三项练，每局只盯一项。

| 练习 | 要求 | 合格标准 |
|---|---|---|
| 五栏记录 | 一局记录至少 5 条，含时间、地点、事件、来源、可信度 | 能凭记录回答“敌方载具最后在哪、几分钟前” |
| 完整更新 | 给队长至少 3 次“地点 + 敌我状态 + 建议动作” | 每次 15 秒内说完，队长不用追问 |
| 信息取舍 | 选一段 2 分钟以上的交火，只发 3 条信息 | 至少 1 条改变了队友动作 |

进阶练法：让队友随机报一个真假混合的消息，你在 5 秒内判断它属于事实、推断还是猜测，并说出该用什么措辞转述。每天十组，一周后听到模糊描述会本能地追问来源。

完成标准：三项各完成一次，记录可复查，更新不超时。做不到就重来一局；越乱越需要这套流程。

::: takeaway
练习的目标不是写满本子，而是把“先分层、再开口”变成本能。每局只练一项，练到不用想，才算真正掌握。
:::

## 自检 3 问

1. 向队长汇报时，事实、推断、猜测按什么顺序说，推断必须带什么？
2. 态势更新的标准结构是什么，多久更新一次，何时立即更新？
3. 信息过载的三问过滤是什么，哪两类信息永远优先？

::: takeaway
三问都能用自己的话答出来，并且各举一个战场例子，说明你已经能把“看到的”转成“队长能用的”。下一步去学复活点与资源规则，把信息优势落到实际增援上。
:::
