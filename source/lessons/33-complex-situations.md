## 学完能做到什么

- 多点接敌时，用统一标准判断首要矛盾，不跟着喊声跑。
- 把任务翻译成火力组能执行的位置、动作、时限和完成信号。
- 按主攻、牵制、预备的比例分兵，撤退时处理电台和载具。
- 补给中断、士气下滑时维持指挥链，局势恶化时带全队有序撤出。

::: takeaway
复杂局面不是敌人多，而是多个任务同时争抢同一批人。指挥要先排序，再让每个组知道下一步。
:::

## 复杂局面的共同结构

伏击、载具被击中、两线作战、补给断裂、队长阵亡，看起来不同，底层都是威胁超出火力上限、信息不全、时间在流失。接敌前十秒按固定顺序扫一遍，不要先抬枪：弹道从哪个扇区来，队形有没有被隔开，身后二十米有没有掩体，筒子和医疗还剩多少，队长还能不能下令。

扫完只回答三个问题：什么能在三十秒内杀死我们，现在还能做什么，退出交战区走哪条线。答案不清时，先做能立刻降低伤亡的动作，比如全部贴掩体、断开被压制的视线、把伤员拖到墙后，再补信息。

| 局面 | 最先处理 | 暂时放下 | 判断信号 |
|---|---|---|---|
| 近距离伏击 | 脱离交叉火网 | 追击暴露的敌人 | 队形被压在一个扇区，退路仍可用 |
| 两线接敌 | 更近、能包抄的一线 | 远距离正面火力 | 一侧敌人已进入手雷距离 |
| 载具被击中 | 乘员下车进掩体 | 抢救载具 | 车体起火、炮塔失效 |
| 补给断裂 | 收缩到可补给点 | 非关键阵地 | 弹药低于三成、医疗耗材见底 |
| 指挥中断 | 指定接替人 | 原定进攻计划 | 频道出现多个矛盾命令 |

::: figure 图 33-1：复杂局面的十秒排序。先扫描，再回答三问，最后只留一个主攻和一条退路。
![复杂局面排序示意图](../../assets/images/g6-priority-scan.svg)
:::

::: takeaway
先扫弹道、队形、退路、资源、指挥，再回答“三十秒内谁最致命、还能做什么、从哪里退”。扫描不是停顿，是把第一反应从开枪改成排序。
:::

## 多点接敌：先定首要矛盾

最忌讳把每个接触点都当主战场。三个组同时喊支援，如果平均分人，最后每个点都差一口气。选择首要矛盾按四条比较：

- 时间：哪一路能在最短时间内造成不可恢复的损失，先打哪一路。已经进入阵地纵深、正在架枪、正在贴脸扔雷的，优先于两百米外的对射。
- 位置：哪一路丢掉后会让全队被包围，先处理哪一路。侧翼和后方通常比正面更危险。
- 成本：一个机枪组加烟能稳住的方向，不值得抽走两个步枪组。
- 机会：敌人暴露、背对、正在换弹时，可以短促突击，但必须预设撤回信号，不能追进去。

把首要矛盾写成一句话：“主任务是打掉西侧围墙后的机枪，因为它封住唯一退路；其余方向只许压制，不许追击。”这句话包含目标、原因、限制。没有“因为”的命令，执行一定走样。

牵制方向也要给边界。比如“二组在正面保持点射，不许前出超过路缘”，否则牵制组会打成第二个主攻。主攻组要明确停止线，打到哪面墙、哪扇门为止。

定完主次还要分兵力。满编九人时，一个可执行的默认分法是：**主攻四到五人、牵制两到三人、预备两到三人**；残编六人时，主攻三人、牵制两人、预备一人。原则是主攻人数不少于牵制，预备至少留一人，不能三个方向平均分。只有两个组时，主攻组带机枪和筒子，牵制组只带步枪和烟；不要把一个组拆成两半同时干两件事。

分兵之后不要再平均调整。主攻方向吃紧，从预备组补；牵制方向吃紧，先让它退到更硬的掩体，而不是从主攻抽人。抽主攻去救牵制，等于让敌人替你完成了兵力分散。

::: takeaway
按时间、位置、成本、机会排序，标准是“哪一路能最快让全队失去选择”。主攻只给一个，牵制方向必须写明不许做什么。
:::

## 把任务分到火力组

命令越长越容易丢。给火力组的任务只保留四项：去哪里、做什么、何时开始、怎么算完成，再加一条限制。

| 组 | 位置 | 动作 | 触发 | 完成信号 | 限制 |
|---|---|---|---|---|---|
| 一组 | 西侧矮墙 | 压制二楼窗口 | 听到“开火” | 窗口停火 | 不进院子 |
| 二组 | 北侧巷口 | 烟后横穿到门洞 | 第一颗烟落地 | 报“二组到位” | 不回头救人 |
| 三组 | 队尾 | 掩护撤离、打烟 | 听到“撤” | 报“尾清” | 不追出三十米 |

坚持一组一任务。不要同时“压制、救人、看后门”，组员会不知道先做哪个。伤员由最近的组临时止血，再由医疗兵接走，不要把整个火力组钉在原地。队长最好留三到四人的预备组，哪怕只是两个步枪兵，用来堵漏、接替、抬人。没有预备队，任何意外都会逼你从主攻方向抽人。

下达后只回述关键动词：“二组，烟落地后你做什么？”“三组，什么时候打烟？”答对才算命令送达。频道同时有人说话时，先指定“只留二组和我说话”，其他人静默。

::: takeaway
任务卡写位置、动作、触发、完成信号、限制，一组只领一个主任务。队长至少留一个预备组，用关键动词回述确认。
:::

## 补给中断怎么办

第一症状不是没子弹，而是有人开始问“谁还有弹匣”。先盘点，不要继续往深处推。每组报三档：绿色够打一轮，黄色只够一次交火，红色开始借弹。红色组收缩到二线，绿色组顶到接触面，医疗耗材优先给最可能马上用的人。

- FOB 被毁：确认还有没有其他 HAB 能出生，别让全队继续从失效出生点补人。就近设集结点，重建时选离目标两百到四百米、有遮挡、有第二条进出路的位置。
- 运输线被截：不要连续派单车硬闯同一条路。改成两车同行、一车警戒一车卸货，或换一条更远但视野更好的路线。遇袭先停车进掩体，不原地掉头。
- 弹药见底：弹包和绷带集中管理，先满足机枪和反载具。筒子不打步兵，机枪不对空窗口长扫。必要时放弃次要阵地，收缩到能补给的一侧。

卸货顺序也要提前说。通常先卸建材后卸弹药，因为要先起 HAB 和工事，人才有地方复活；如果当前正被载具压、急需反载具弹，就先卸弹药，这个例外由队长在车到之前决定。补给车不是运兵车：司机卸完就走，车停在能掉头、有掩体的位置，不要停主街。补给分配按威胁排序——反载具弹、机枪弹、医疗耗材优先，步枪弹和建材其次，不按人头平均撒。

补不上就主动降低目标：从“占领并守住”改成“守住入口并保持观察”，从“全歼”改成“逼退”。撤出前带走能带的补给，带不走的弹药箱宁可打空。

::: takeaway
补给中断先按绿黄红盘点，收缩红色组、保障机枪与反载具。FOB 毁就换集结点，运输线被截就换路线，补不上就降低目标。
:::

## 士气下滑的识别与处理

士气下滑有具体信号：频道突然安静，没人报点；重生的人往反方向走；有人说“这局没了”；同一个错误被反复指责；命令下达后只得到沉默。等到有人退服才处理就晚了。

处理顺序是减负、给方向、造小胜、再轮换：

1. 减负：停止多线任务，只保留一个能完成的目标，让所有人知道接下来三分钟只做一件事。
2. 给方向：把“我们被包围了”改成“从北门出去，二组先走，一组掩护”。具体动作能压住无力感。
3. 造小胜：安排一次低风险行动，比如用烟救回伤员、打掉孤立机枪点、接回落单队员。完成后明确说“这次做对了”。
4. 轮换：连续顶一线的人后退一个房间换弹报位，二线的人顶上，不要让同一组从开局撑到结束。

批评针对动作，不针对人。“三个人挤在门口被一颗雷收掉，下次间隔五米进”可执行；“你怎么这么菜”只会让人闭嘴。队长越乱越要用短句，先报自己的位置和下一个动作。

::: takeaway
士气下滑看频道沉默、重生逆行、互相指责。处理靠减负、给具体方向、制造小胜和轮换，不靠空泛鼓励。
:::

## 有序撤退：分工、路线、通信

该撤的信号很明确：主攻无法推进，侧翼被压缩，医疗和弹药见底，继续留下只会被逐个点名。决定后先说清楚：“全队撤退，二组先走，一组掩护，三组断后，集结点在北侧蓝色围墙。”不要一边打一边往后蹭，那叫被推着走。

1. 定集结点：有掩体、能看来路、离敌人至少一个街区或八十米，能容纳全队，不是死胡同。
2. 分先后：伤员、医疗兵、缺弹组先走，火力完整的组掩护。断后组要听得懂命令、舍得打烟。
3. 分段移动：一次只动一个组，另一组保持射击，每组移动二十到三十米，到位报“到位”。
4. 用烟断视线：烟扔在敌我之间，不扔脚下；第一颗烟落地后再动。
5. 收拢清点：到点按组报“人在、弹量、伤员”，缺人立刻说缺谁、最后位置，不先争论要不要回去。
6. 重建指挥：停三到五秒，重述任务和下一个集结点，通信恢复成“组长对队长”单线。
7. 处理资产：电台守不住就主动拆，载具开到下一防线或藏进有顶车位，带不走的弹药箱打空。主动拆电台不扣 20 票，留给敌人拆才扣。

断后组最容易打上头，命令要带触发条件：“打完两个弹匣或敌人进二十米就撤，不许追。”撤退不要穿开阔地，不要沿同一直线连续跑，不要在拐角堆人。通信中断时，预先约定：连续两声“收拢”向集结点集中，三声短促表示停止移动、就地隐蔽。

::: takeaway
撤退先定集结点，再分先后、分段移动、烟断视线、到点清点、重建指挥、处理资产。断后组要有撤退触发条件，通信要有备用信号。
:::

## 决策速查

- 接敌前十秒：扫弹道、队形、退路、资源、指挥，再决定打还是走。
- 首要矛盾：选最能在三十秒内造成不可恢复损失的一路，侧翼和后路优先。
- 分任务：一组一个主任务，写清五项；主攻人数不少于牵制，预备至少留一人。
- 补给断裂：绿黄红盘点，先保机枪和反载具；卸货通常先建材后弹药，被压时先弹药；补不上就降低目标。
- 士气下滑：减负、给方向、造小胜、轮换；批评动作，不贴标签。
- 撤退：定集结点，伤员先走，分段移动，到点清人，撤前处理电台和载具。

::: takeaway
速查只保留十秒内能说出口的规则。真到复杂局面，先执行三条：定主次、留预备、保退路。
:::

## 实战案例

地图 Narva，小队从南侧推进到城区中部，任务是在铁路旁建立前沿据点。一组带机枪，二组带筒子和烟，三组是步枪加医疗。推进到东西向街道时，情况同时变坏：正面二楼窗口出现机枪，西侧巷口有敌方步兵向队尾投雷，后方补给卡车被反载具武器击中，弹药和绷带一起烧掉。

队长十秒扫描：正面机枪封街，但中间有矮墙；西侧敌人已进三十米；车救不回来；全队弹药剩一半，绷带只剩四个。三个答案：最致命的是西侧步兵，其次是正面机枪；能做的是用一组压正面、二组反冲西侧；退路是北侧蓝色围墙后的院子。

命令：“一组，矮墙后压制二楼窗口，二十秒后报弹量，不许过街。二组，两颗烟到西侧巷口，烟起后沿墙根推，打到第一道门就停，不许追。三组，把伤员拖进北院，清点绷带，在院门架枪。集结点北侧蓝色围墙，听到‘收拢’就走。”

二组用烟遮巷口，贴墙推进，用手雷逼退敌方前锋，没有追进巷子。一组短点射压住窗口。三组拖回一名腿部伤员，用掉两个绷带。补给已断，队长把目标降级为“守住院子，等下一车货”。

两分钟后，敌方从正面和西侧同时加压，一组只剩两个弹匣，二组一人倒地。队长判断继续守会被吃掉，执行撤退：三组带伤员先走，二组打烟，一组最后撤。每组移动二十五米，到位报“到位”，断后组打完一个弹匣就脱离。全队在北侧第二个路口收拢，缺一人；二组最后看到他在院门内侧。队长没让全队回去，派二组两人贴墙回院门，三十秒把人拖出，再沿小巷撤到临时集结点。

复盘只留一个改动：补给车不再单独停主街，卸货点改到隔一栋楼的院子，司机和押运员先约定遇袭后的掩体。

::: takeaway
案例里救命的是顺序：先打最近威胁，再稳正面，最后在弹药见底前主动撤。后勤细节也要在复盘里变成一个具体改动。
:::

## 常见错误

| 症状 | 原因 | 改法 |
|---|---|---|
| 三个组同时喊支援，队长逐个救，最后全崩 | 没有主次 | 选最致命一路，其余只许牵制，写停止线 |
| 命令说很多，组员不知道去哪 | 只有意图，没有位置和信号 | 改成“去哪、做什么、何时开始、怎么算完成” |
| 补给断了还进攻，弹尽人亡 | 占点看得比续航重 | 绿黄红盘点，补不上就降低目标 |
| 士气下滑只喊“别怕” | 空泛鼓励不能降低不确定性 | 减负、给下一个动作、造小胜、轮换 |
| 撤退全队一起转身跑 | 没有先后和掩护 | 定集结点，分组交替，烟断视线 |
| 断后组追出去 | 没有撤退触发条件 | 明确“两个弹匣或二十米就撤” |
| 频道所有人同时讲话 | 没有通信优先级 | 指定“只留某组和队长说话” |

::: takeaway
复杂局面的错误大多不是不会打，而是没有排序、没有边界、没有退路。补上这三样，比多练枪法提升更快。
:::

## 实战练习

**十秒扫描。** 找一段接敌录像，在接触瞬间暂停，用十秒说出弹道、队形、退路、资源、指挥五项，再写“最致命目标、可执行动作、撤退路线”。连续五次，五次都在十秒内说完算达标。

**一组一任务。** 实战中给三个组各写一张任务卡，必须包含位置、动作、触发、完成信号、限制。局后检查有没有组领了两个主任务、有没有人不知道完成信号。三张卡都有人能复述关键动词，算达标。

**有序撤退。** 选局势不利时主动撤一次，按步骤执行。记录从下令到全队报数用了多少秒、有没有人掉队、频道有没有互相覆盖、电台和载具是否处理。各步完成且无人失联，算达标。

每次只写一条改进，下一局只改这一条，三次练习的改进不要重复。

::: takeaway
练习拆成三个变量：十秒扫描、任务卡、完整撤退。每次只改一个动作，下一局才看得出有没有学会。
:::

## 自检 3 问

1. 多点接敌时，你用什么标准决定先打哪一路？能不能一句话说出主攻、牵制和停止线？
2. 给火力组下达任务必须包含哪五个元素？完成信号由谁报、报什么？
3. 决定撤退后，从下令到收拢要依次做哪些步骤？通信中断靠什么信号收人？

::: takeaway
三问都能用具体动作回答，说明你已有复杂局面的指挥骨架；只能说出原则，就把答案写成任务卡再练一次。
:::
