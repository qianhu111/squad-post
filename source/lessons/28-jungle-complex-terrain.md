## 学完能做到什么

- 按视线长度决定队距：密林五到十米，疏林十五到二十五米，林间空地边缘三十米以上。
- 三人小组分三个方向观察，侧翼永远有人负责，不三个人一起盯正面。
- 用一套约定好的手势和低声短词完成低频通信，渗透时不开无线电也能动。
- 识别渗透与反渗透的常见迹象，知道什么时候停、什么时候绕、什么时候放弃。
- 在丛林中组织火力与机动，支援组不跟着突击组一起冲。
- 与队伍走散后按固定流程收拢，而不是原地乱转或独自找人。
- 用“安全三环”选观察位置，站在信息够多、又不太暴露的次外圈。
- 用投掷物探路、逼走位，按“观察—肃清—推进”的小循环走，而不是一路小跑。

::: takeaway
丛林作战的难点不是看不见敌人，而是看不见队友；先解决队形和通信，再谈开火。
:::

## 短视线下的队形收紧

丛林地图的视线被树线、灌木和起伏地形切碎，常见交战距离只有三十到一百五十米。视线越短，队形越要收紧，否则一个转弯队伍就断成两截；但收得太紧，一梭子子弹就能放倒两三个人。

| 地形 | 典型视线 | 队距 | 队形 |
|---|---|---|---|
| 极密灌木 | 十到三十米 | 三到五米 | 单列纵队，肩距跟进 |
| 密林 | 三十到八十米 | 五到十米 | 楔形或单列 |
| 疏林 | 八十到一百五十米 | 十五到二十五米 | 楔形，两翼略展开 |
| 林间空地边缘 | 一百五十米以上 | 三十米以上 | 一字展开，贴树线 |

判断队距是否合适，有一个简单标准：一梭子自动火力能不能同时打到两个人。能，就说明太密；如果转弯时看不到前一个人，就说明太稀。理想状态是每个人都能看见前一人和后一人的轮廓，但不在同一条直线上。

尖兵每推进一百五十到两百米，或者每次交火后轮换一次。走在最前面的人注意力消耗最大，反应会变慢，固定一个人当尖兵，最先出事的往往就是他。换尖兵时全队停十秒，交接方向感和可疑位置，再继续走。

::: figure 图 28-1：队距随视线变化。密林五到十米，疏林十五到二十五米，空地边缘三十米以上。
![丛林队距示意图](../../assets/images/g5-jungle-spacing.svg)
:::

::: takeaway
队距跟着视线走，密则三五米、疏则二三十米；标准是一梭子打不到两个人，同时看得见前后队友。
:::

## 安全三环与光影伪装

同一片林子，从外往里看和从里往外看，是两张不同的地图。可以把一块林地想成三个同心圈：外圈靠近林缘，信息最多，也最容易被看见；中圈是次外圈，能看到林外，又不至于把整个轮廓交出去；内圈最安全，但基本看不到外面。

| 圈层 | 能看到什么 | 暴露程度 | 用途 |
|---|---|---|---|
| 外圈 | 林外开阔地、道路、敌人动向 | 最高，轮廓、颜色反差都明显 | 只快速通过，不长时间停留 |
| 次外圈 | 林外大部分区域，林内情况也看得到 | 中等 | 观察位、peek、短暂开镜 |
| 内圈 | 几乎只能看林内 | 最低 | 行军、集结、伤员、等待 |

观察时站在次外圈，用树干、灌木边缘遮住身体，只露头和枪口，看几秒就缩回。不要站在外圈的空地边缘反复探头，那里是敌人预瞄的位置；也不要缩在最内圈等敌人进来，你看不见他，他却能顺着声音摸到你。

光影和颜色同样会出卖你。林地里有明显的明暗交界：林缘的逆光会把人的轮廓勾成一条黑边，浅色树干前的深色衣服会“跳”出来，阳光斑驳处站久了，移动时反而更显眼。选位时优先站在阴影里、深色背景前，避免站在林缘逆光和浅色树干前。通过明暗交界前先停一下，让眼睛适应，再快速穿过，不要在交界线上站着观察。

移动时尽量让树木挡住你的轮廓，而不是只挡住脚。蹲在矮灌木后面，上半身仍然是一个完整的剪影；正确做法是让树干、土坡或灌木的高处挡住头肩，从侧面露头观察。队伍里每个人的衣服颜色不同，走在浅色背景前的人要主动换到深色一侧，不要全队排成一条颜色鲜明的线。

::: figure 图 28-2：安全三环。外圈信息最多也最危险，观察位选次外圈。
![安全三环示意图](../../assets/images/g5-jungle-rings.svg)
:::

::: takeaway
外圈看信息、内圈藏人，观察站次外圈；别站林缘逆光，别在浅色树干前露轮廓。
:::

## 侧翼与节点控制

丛林里没有唯一的路，敌人可以从任何方向摸过来。控制节点的目的不是占住它，而是提前知道谁在接近它。关键节点包括小径交叉口、桥梁、涉水点、林间空地边缘、山脊线和高地反斜面。

| 节点 | 为什么重要 | 观察位放哪 |
|---|---|---|
| 小径交叉口 | 敌人行军最常走 | 路口侧方三十到五十米，不站路口 |
| 桥梁与涉水点 | 过河必经，通道收窄 | 下游侧高地，能看两岸 |
| 林间空地 | 穿越时最暴露 | 空地边缘树线内，不进入空地 |
| 山脊线 | 视野好，也容易被看见 | 反斜面或脊线侧方，不站脊线正中 |

观察位放在节点侧方三十到五十米，而不是节点上。站在路口的人，视野被四周树线挡住，反而最先被摸掉；站在侧方的人能看到路口，也能看到接近路口的两条路。

林地行进的观察节奏是：每十到十五秒侧看一次，每二十到三十秒回头一次。侧看负责左右两翼，回头负责身后。队伍最容易被从后方包抄，因为所有人都在看前面。走在最后的人要定期转身走几步，确认来路没有尾巴。

接近林间空地时，不要直接走出去。先在树线内停十秒，看对面树线的轮廓、鸟的活动、草丛的晃动，再决定是一次快速通过，还是沿边缘绕行。空地里没有掩体，停留越久越危险。

::: takeaway
节点侧方三十到五十米设观察位，不站节点本身；十秒侧看、二十秒回头，空地先看十秒再穿。
:::

## 低频通信与手势

渗透阶段尽量不开无线电。无线电的声音、按键声和耳机线都会暴露位置，而且一次通话会让全队停下来等。近距离协作用手势，中距离用低声短词，无线电只留给楼外或跨组联络。

| 手势 | 含义 | 使用场景 |
|---|---|---|
| 握拳举起 | 全体停止 | 发现声响或轮廓 |
| 手掌下压 | 蹲下或就地隐蔽 | 需要立即降低轮廓 |
| 两指指眼再指方向 | 注意该方向 | 交接观察扇区 |
| 拍头顶 | 发现敌军 | 需要全组进入战斗准备 |
| 手臂向前挥 | 开始推进 | 确认安全后恢复行军 |
| 手指画圈 | 到此集合 | 收拢或变更路线 |
| 指耳再指地面 | 停下听 | 听到可疑声音 |

手势要沿着队伍逐个回传，不能只做给身边一个人看。队伍拉长时，中间的人负责重复动作，直到最后一人确认。回传时动作要夸张、慢，不要做一半就收手。

低声短词只用几个："停""前""左""右""后""等"。说的时候贴近队友耳朵，不要隔着头盔喊。无线电的使用原则是能不用就不用，必须用时控制在十秒内，报位置和意图，不描述过程。

哨声可以作为手势的补充：短哨一声是停，两声是集合，三声是撤离。约定好之后不要临时改，改了必须全组确认。

::: figure 图 28-3：常用手势。动作要夸张、慢，沿队伍逐个回传。
![丛林手势示意图](../../assets/images/g5-jungle-signals.svg)
:::

::: takeaway
手势沿队伍逐个回传，短词贴耳说，无线电能不用就不用；信号一旦约定就不临时改。
:::

## 渗透与反渗透

渗透的核心是"不被发现地到达位置"，不是"一路杀过去"。路线选地形褶皱、溪沟、林下阴影，避开小径、村道和明显的高地脊线。每推进一百到一百五十米，停三十秒听一次：听脚步、听树枝折断、听无线电杂音、听鸟被惊起的方向。

| 阶段 | 要做的事 | 不能做的事 |
|---|---|---|
| 出发 | 确认罗盘方位、集结点、失联预案 | 边走边找路 |
| 接敌前 | 尖兵在前，队距收紧，关闭电台提示音 | 大声交谈、开手电 |
| 接近目标 | 最后一次静默停顿，分配突击与支援 | 直接走上小径 |
| 撤离 | 换路线，留观察哨断后 | 原路返回 |

反渗透是另一面：预判敌人会从哪里摸过来，在侧方设观察哨或短伏击。观察哨放在敌人必经路线的侧方三十到五十米，不放在路线上。发现敌人侦察兵，不要立刻追。追出去的人会离开队形，把侧翼让开；正确做法是报点、标记方向、让全组收紧，再决定是绕开还是设伏。

被跟踪的迹象包括：同一个方向反复传来脚步声、鸟群突然从某片树线惊起、身后有树枝折断但看不到人、无线电里出现不属于本组的杂音。发现这些迹象，先停、先听、先换路线，不要加速跑，跑步的声音会盖住追兵的位置。

::: takeaway
渗透靠绕和停，不靠跑；发现尾巴先停听、再换路线，追侦察兵等于自己让开侧翼。
:::

## 投掷物探路与肃清循环

丛林里没有“清完一条街”这种明确节点。敌人可能蹲在任意一丛灌木后，所以推进不是一直走，而是一个小循环：观察、肃清、推进，再观察。每推进十到二十米，就停下来把这个小循环重做一遍。

| 步骤 | 动作 | 目的 |
|---|---|---|
| 观察 | 看树线、草丛、地面痕迹，听声音 | 找出“不自然”的地方 |
| 探路 | 向可疑掩体投手雷、榴弹或烟 | 逼敌人移动或暴露 |
| 肃清 | 两人一组切角接近，确认掩体后 | 确认近处安全 |
| 推进 | 全组前移十到二十米，重新展开 | 把安全区往前挪一段 |

投掷物是丛林里最好用的“问路棍”。看到一片可疑灌木，先扔一颗手雷或榴弹进去，不要自己走进去看。爆炸后不要立刻冲，等一两秒，听有没有移动声、看有没有人从侧面跑出来；如果敌人被逼出来，先由后面的队友打，投弹的人不要探头追。

手雷也能“逼走位”。敌人躲在树后或土坡后，你扔一颗雷到他侧后，他只有两个选择：往外跑，或者被炸。往外跑就会进入你队友的枪线。扔雷前喊一声“雷”，让两侧的人知道你要扔，避免炸到自己人。烟雾弹则用来切断敌人增援的视线，或者掩护自己从一片空地撤到另一片树线。

肃清时不要一个人绕到掩体后面看。两个人一组：一人贴树或土坡切角，另一人保持两到三米距离，枪口对着掩体另一侧；第一个人确认近处，第二个人看远处和侧后。三个人时，第三个人专门看身后，防止敌人从来的方向摸上来。

肃清完一个点，不要马上收枪。先问一句“敌人会从哪反扑”，把下一双眼睛放到那个方向；很多小队不是死在正面，而是死在清完点后所有人同时低头换弹的那几秒。

开火后必须换位置。你在原地的枪声、枪口焰和倒下的敌人，都会告诉对面你在哪。打完一个点射，沿树线横移十五到三十米，或者退到下一棵树后，再重新观察。不要在原地换弹，也不要在同一个树后反复露头。

::: takeaway
观察、探路、肃清、推进，四步一小循环；可疑掩体先投雷再接近，开火后横移十五到三十米。
:::

## 丛林中的火力与机动配合

丛林交火的距离短，谁先展开火力、谁先占住侧翼，谁就占主动。基本分工是：支援组在原地架枪压制，突击组从侧翼绕五十到一百米，用手雷和近战火力解决目标。

| 角色 | 位置 | 任务 |
|---|---|---|
| 支援组 | 目标正面偏侧三十到五十米 | 压制窗口、树线、掩体 |
| 突击组 | 从侧翼绕五十到一百米 | 接近后投雷、突入 |
| 预备组 | 支援组后方 | 补位、救伤员、封退路 |

支援组和突击组不能挤在一起。挤在一起，一梭子子弹同时打到两组，压制也变成所有人对射。支援组开火时要报"压制中"，突击组开始移动时报"移动"，支援组听到后把射界向目标纵深延伸，避免打到自己人。

突击组进入目标前三十米，支援组必须停火或把火力转到目标另一侧。这条线要事先说死，不能靠临场判断。手雷投出前喊"雷"，投出后喊"炸"，突击组等爆再进。

遭遇伏击时按距离处理：近距离伏击，直接向伏击方向突击，穿过火力线，不要在空地上卧倒；远距离伏击，先还击、投烟、沿侧翼脱离，再重新组织。两种情况都忌讳原地趴着不动，趴下只会让敌人从容瞄准。

### 载具在丛林边缘

丛林里载具不是主角，但用对了能省很多事。载具应该停在林线外、土路上或林间空地的边缘，不要开进树冠下面：树干会挡住炮塔和车门，车组看不到两侧，履带还可能被树根和沟坎卡住。车头朝撤离方向，车身藏在树线或土坡后，只露出炮管和观察镜。

步兵在车前三十到五十米走，替车看两侧和车头前的死角；车用机枪或机炮打树线后和空地对面的目标，替步兵压住正面。车载机枪的声音会盖住脚步，所以车一开火，步兵要格外注意侧翼——敌人很可能趁着枪声从侧面摸过来。

载具还能当临时救护点和补给点。伤员抬到车侧掩体后，弹药从车上补，但人要散在车侧五到十米，不要挤在车尾。车被击中时，先远离十到十五米，再救人；丛林里第二发火箭往往跟着第一发来。

如果任务只需要渗透，不要带车。车的引擎声在密林里能传很远，等于一路告诉敌人“我们来了”。宁可靠两条腿多走十分钟，也不要把整队的路线交给一条只能走大路的车。

## 迷路与分散后的收拢

丛林里走散很常见，原因通常不是方向感差，而是队伍拉太长、转弯时没人回头确认。走散后的第一原则是停，不是找。人在紧张时会越走越快，越走越偏，最后离队伍越来越远。

| 情形 | 动作 | 时间限制 |
|---|---|---|
| 发现看不到队友 | 就地停，蹲下听三十秒 | 不要立刻喊 |
| 确认走散 | 退回最后一个转弯或明显地标 | 不超过两分钟 |
| 找不到原路 | 用罗盘朝最后集结点或目标方向移动 | 每五十米停一次 |
| 听到交火 | 判断方向，从侧方接近，不穿火线 | 先观察再动 |
| 完全失联 | 到最近的集结点等，吹两声哨 | 等五分钟再决定 |

走散的人最容易犯的错是边走边喊队友名字。声音会把位置送给敌人，也会盖住队友的回哨。正确顺序是蹲下、听、看，再决定吹哨；哨声只在确认周围相对安全时使用。沿途留标记同样有用：在转弯处折一根树枝、在泥地踩出明显脚印，后来的人能顺着标记追上，不必全队回头找。

每次行动前约定三个集结点：出发点、中途、目标附近。走散的人优先去最近的一个，而不是猜大部队去哪。集结点要选有掩体、能观察到接近路线的地方，不要选在路口正中。

收拢信号用短哨两声，间隔十秒重复。听到回应后不要互相跑，先确认方向，再由位置较低或较安全的一方移动。两个人同时跑，容易在中间撞上敌人。

如果全组被打散、无法收拢，剩下的人应该向目标或最近的己方据点移动，沿途留下标记，不要单独回头找人。单人回头搜索，既救不了人，也容易把自己搭进去。

::: takeaway
走散先停后听、退到最后一个转弯；集结点事先约定，收拢时只让一方移动。
:::

## 决策速查

| 情形 | 先做什么 | 再做什么 |
|---|---|---|
| 进入密林 | 收队距到五到十米 | 尖兵在前，两翼分配观察 |
| 听到可疑声响 | 握拳停下 | 蹲听三十秒再判断 |
| 接近空地 | 树线内停十秒 | 快速通过或沿边缘绕 |
| 发现敌人侦察兵 | 报点、收紧队形 | 绕开或设伏，不追 |
| 遭近距伏击 | 向伏击方向突击 | 穿过火力线再收拢 |
| 有人走散 | 原地停、吹两声哨 | 退到最后一个转弯 |
| 可疑灌木/掩体 | 先投雷或榴弹 | 爆后等一两秒再接近 |
| 观察林外 | 站次外圈，只露头几秒 | 看完缩回，换位置 |
| 载具要进林 | 停林线外 | 步兵前出三十到五十米看两侧 |

- 队距跟视线走，密林五到十米，疏林十五到二十五米。
- 观察站次外圈，避开林缘逆光和浅色树干。
- 可疑掩体先投雷，观察、肃清、推进四步一循环。
- 开火后横移十五到三十米，不在原地换弹。
- 三人分三向，侧翼和身后都要有人看。
- 手势逐个回传，无线电能不用就不用。
- 支援组压正面，突击组绕侧翼，进目标三十米前停火。
- 走散先停后听，去最近集结点，不单独回头找。

::: takeaway
速查表按"先保队形、再找信息、最后开火"排列；顺序反了，人越多越乱。
:::

## 实战案例

地图是 Belaya，我方三人小组沿林间小径向目标侧翼渗透。尖兵走在前方略偏左，观察手在右后，组长在最后，队距约八米。

推进到一片空地边缘时，尖兵握拳停下。全组蹲下，静听三十秒，听到空地对面树线有树枝折断声。观察手用两指指眼、再指对面树线，组长回传"拍头顶"，全组进入战斗准备。

轮廓出现：两名敌方步兵，一人蹲姿架枪，一人站立观察，距离约一百米。组长决定不打正面：支援手在空地边缘架枪，尖兵和组长从右侧树线绕行约六十米。支援手报"压制中"，两发点射打在树线附近，敌方蹲姿者趴下。

突击组从侧翼接近到三十米，支援手停止射击。手雷投出，报"雷"，爆后报"炸"，两人突入，击倒一人，另一人向后撤退。组长没有追，报"停止追击，收拢"，全组沿另一条树线后撤，转移到预设集结点。

复盘：尖兵先停、全组先听，避免了直接走进空地；支援组压正面、突击组绕侧翼，没有挤在一起；进目标前三十米停火，没有误伤；打完不追，换路线撤离。如果三个人一起看正面，侧翼的敌人就会先开火；如果追击撤退者，队伍会拉散，正好撞上增援。

::: takeaway
案例的关键动作是"停、听、绕、压、停火、撤"；丛林里多停十秒，往往比多跑一百米有用。
:::

## 常见错误

| 症状 | 原因 | 改法 |
|---|---|---|
| 队伍转弯后断成两截 | 队距过大或没人回头确认 | 密林收到五到十米，转弯处停一下 |
| 一梭子放倒两三个人 | 队形太密，站在同一直线 | 拉开间隔，错开站位 |
| 被侧翼敌人先手 | 三个人都盯正面 | 固定一人看侧翼、一人看身后 |
| 渗透时被提前发现 | 走小径、开电台、大声说话 | 走地形褶皱，手势为主，电台静默 |
| 支援组打到突击组 | 没有停火线 | 进目标三十米前支援组停火或延伸 |
| 遭伏击后全员趴下 | 误以为趴下就是隐蔽 | 近距直接突击穿过，远距投烟脱离 |
| 走散后越找越远 | 边跑边喊，没有集结点 | 先停听，退到最后一个转弯或集结点 |
| 站在林缘逆光观察 | 不知道轮廓会暴露 | 退到次外圈，站阴影和深色背景前 |
| 直接走进可疑灌木 | 把“没动静”当安全 | 先投雷、再切角接近 |
| 开火后原地换弹 | 位置已暴露 | 横移十五到三十米再装填 |
| 载具开进树冠下 | 把车当坦克 | 停林线外，步兵前出看两侧 |

最容易被忽略的是"回头"。队伍拉长后，第二个人以为第三个人跟着，第三个人以为第二个人在，实际上中间已经断了一个转弯。每隔二十到三十秒回头一次，只需要一秒钟，却能避免整组走散。

::: takeaway
丛林里多数减员不是枪法输，而是队形散、侧翼空、伏击时趴着不动、走散后乱找。
:::

## 实战练习

找一局丛林或复杂地形图，完成三项练习。

1. 三人小组按视线调整队距，密林段保持五到十米，疏林段拉开到十五到二十五米，全组转弯后必须能立刻看到前一人。
2. 全程只用握手势和低声短词完成一次渗透，从出发到接近目标不开无线电，记录有几次信息传错。
3. 设计一次侧翼机动：支援组压正面，突击组绕五十到一百米，进目标三十米前支援组停火，记录两组有没有互相打到。
4. 练一次“观察—肃清—推进”循环：每推进二十米停一次，可疑掩体先投雷，确认后再走，记录一轮用了多少投掷物、有没有人直接走进可疑点。

完成标准：队距随地形变化，手势回传无遗漏，侧翼机动有明确停火线。练完回答：这一局里，哪一次停顿其实救了你？

::: takeaway
练队距练的是不散，练手势练的是不吵，练侧翼练的是不挤；三样都做到，丛林才谈得上协同。
:::

## 自检 3 问

1. 密林和疏林的标准队距分别是多少，判断队距是否合适的简单标准是什么？
2. 渗透时发现敌人侦察兵，为什么不能追？正确动作是什么？
3. 与队伍走散后，第一步应该做什么，为什么不是立刻寻找？

::: takeaway
三问答得出来，说明你在丛林里先想的是队形、信息和收拢，而不是先想开枪。
:::
