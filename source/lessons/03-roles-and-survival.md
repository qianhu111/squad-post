## 学完能做到什么

- 知道新人优先选步枪兵，也说得清医疗兵、机枪兵、筒子和特射的门槛。
- 能按“子弹、手雷、筒子、爆炸物”四级判断手里的武器能不能伤到目标。
- 掌握医疗兵四条铁律，并能按“止血带 → 医疗包 → 转移”的顺序救人和自救。
- 理解步枪兵的五件事：补弹、报点、掩护、跟队、不独狼。
- 在一局里能正确判断自己该什么时候冲、什么时候退。

::: takeaway
兵种没有高低，只有位置对不对。新人先把步枪兵打稳，再谈医疗兵和专业兵种。
:::

## 新人选兵种的优先级

步兵兵种多，装备、职责和难度不同。新人第一局固定步枪兵：自带步枪、手枪、弹药包、手雷和绷带，不依赖队友，容错率最高。

| 兵种 | 定位 | 新人什么时候能选 | 关键限制 |
|---|---|---|---|
| 步枪兵 | 小队底盘，能打、能补、能自保 | 第一局就选 | 光瞄步枪通常限 2 名 |
| 医疗兵 | 全队第二条命，救人、止血、回血 | 打稳 5–10 局后 | 每队通常限 2 名，6 条绷带加医疗包 |
| 机枪兵 | 架枪压制、封锁街道 | 熟悉架点和换位后 | 离开架设点很脆弱，需要副手 |
| 榴弹兵 | 清掩体、封烟、逼走位 | 练熟 50、100、150 米落点后 | 近距离会伤到自己 |
| 精确射手 | 远距离观察和点名 | 有地图理解后 | 近战能力弱，被贴脸基本必死 |
| 轻筒 / 重筒 | 反载具 | 认得车型和弱点后 | 轻筒每队约 2 名，重筒全阵营约 1 名 |


先步枪兵，打稳 5–10 局再试医疗兵，再往后才考虑专业兵种。工兵和载具兵要专门练，新人不要占位。不会反载具的筒子比没有筒子更伤，因为队友会以为那边有反装甲能力。

::: takeaway
新人优先步枪兵：装备全、容错高、不依赖队友。医疗兵和专业兵种在掌握基础后再选，不占自己用不了的位置。
:::

## 装备与伤害分级

Squad 里的武器不是“伤害高低”一条线，而是分层的。拿错层级去打目标，除了暴露位置，没有别的作用。

| 层级 | 代表装备 | 能打什么 | 打不了什么 |
|---|---|---|---|
| 子弹 | 步枪、手枪、机枪 | 步兵、暴露乘员、轻掩体后的敌人 | 装甲载具、加固工事 |
| 手雷 / 榴弹 | 破片手雷、枪挂榴弹 | 掩体后步兵、轻工事 | 装甲载具 |
| 轻筒 / 重筒 | LAT、HAT | 轻装甲、履带、发动机、侧面和后部 | 正面硬刚主战坦克 |
| 爆炸物 / 重火力 | C4、IED、载具炮、迫击炮、空袭 | 电台、兵站、工事、集群步兵 | 分散隐蔽的单兵 |

由此得出两条步兵原则。

第一，除特射以外，不要做超出武器精度的远距离点射。打不中还会暴露自己，不如把目标交给特射或机枪。

第二，除机枪和筒子外，不要主动射击攻击型载具和直升机。步枪打不穿装甲，开火只会暴露位置。正确动作是躲、报点，交给筒子或己方载具。打履带载具先断履、打发动机，让它停下来，再谈击毁。

能伤 FOB 的手段：工兵铲、手雷、C4、IED、轻筒、重筒、载具武器、重机枪和指挥官技能。步枪子弹打不掉电台，别对天线浪费弹匣。

::: takeaway
先问“我手里的东西属于哪一级”，再问“目标属于哪一级”。打不动就躲、就报，不要用步枪挑衅装甲车。
:::

## 医疗兵四条铁律

即使不玩医疗兵，也要懂这四条铁律：它们决定队友愿不愿意跟你走，也决定你倒地时能不能被救。

**第一条：先保自己，再救队友。** 看到队友倒地，先确认周围没有敌人和火力覆盖，再施救。医疗兵不要当排头兵，走在队伍中间偏后。死掉的医疗兵救不了任何人。

**第二条：倒地先呼救。** 按呼救键（默认 `5`），让队友知道位置和状态。不要静默倒地，也不要乱爬，让救援者按最后看到的位置找到你。

**第三条：不在枪林弹雨中贸然救人。** 倒地点在敌方火力下，救人会变成双杀。先封烟、压制，或等队友清掉最近威胁，再靠近。烟要挡敌人视线，不是把自己埋进去。

**第四条：优先救关键角色。** 先救医疗兵、队长、机枪和筒子，再救普通步枪兵。多人同时倒地时，先救最近、最安全的那一个，不要围着危险倒地点打转。

四条铁律适用于所有兵种。懂这些，你倒地时也更容易被救起。

::: takeaway
医疗四铁律：自保优先、倒地呼救、不盲目施救、优先救关键角色。医疗兵活着，全队才有第二次机会。
:::

## 医疗兵怎么救：从止血带到医疗包

医疗兵的操作分两件东西：止血带只止血，医疗包才回血，顺序不能反。

按 `5` 取出医疗用品：左键对队友，右键对自己。医疗兵有 6 条止血带和一个医疗包，打止血带速度约为普通兵种的两倍。普通兵种没有医疗包，只能止血，不能把血补满。

救人分三步：

1. **先止血**：按住左键用止血带止住流血，他会从“倒地”变成“缺血”。
2. **再回血**：换医疗包按住左键治疗，把血补到安全线。只止血不补血，起来也是残血。
3. **一起转移**：立刻扶他进掩体，被救起的人先恢复，不要马上开火。

没法原地施救时可以拖人：对着倒地队友的头或脚按 `F`，拖到掩体后再止血、回血。拖行慢、暴露久，只适合短距离。

倒地的人有约 60 秒黑白屏，期间再中弹会直接死亡。救援的第一件事是让这个位置不再挨打。被救起不扣票；流血致死或放弃，扣 1 票。

![伤情分级与医疗流程](../../assets/images/g1-medic-flow.svg)
:::

::: takeaway
止血带止血，医疗包回血，左键队友、右键自己；先止血再回血，救完立刻转移。
:::

## 步枪兵的五件事

步枪兵是最普通的兵种，却是小队的作战单元。新人要做好五件事。

**第一件是补弹。** 交火后找弹药箱、步枪兵或医疗兵补弹，不等空枪。步枪兵自带弹药包，可以分给队友，优先给机枪、筒子和医疗。

**第二件是报点。** 先按住 `B` 说清方向、距离、目标、数量、动作；队长或火力组长再用 `T` 补标记。报点比开枪重要，一个敌人可以被多人集火。

**第三件是掩护。** 队友前进或开火时，你观察另一个方向，防包抄。队员之间保持 10–15 米（巷内 5–10 米），走不同路线。队友倒下后立刻补枪，不给敌人换弹机会。

**第四件是跟队。** 跟队长或老队员走，不独自前进。跟队不是贴身，而是保持视觉联系和可支援距离，队长变向时及时跟上。

**第五件是不独狼。** 独狼是新人最常见的死因。冲锋前先问：有队友吗？有掩护吗？能撤退吗？没有三个“能”就不要单独行动。

::: takeaway
步枪兵五件事：补弹、报点、掩护、跟队、不独狼。做到这五条，就是一名合格步兵。
:::

## 什么时候该冲，什么时候该退

新人最容易犯的错误是不知道何时撤退。冲和退都不是凭感觉，而是看三个条件：有没有命令、有没有火力优势、有没有退路。

该冲的情况：队长下达进攻命令、我方有压制火力、敌方人数劣势、你有掩护且队友在附近。冲锋时不贪多，掩体到掩体地移动，不要直线冲向敌人。冲锋的目标是占位，不是杀敌。

该退的情况：兵站被压制无法复活、队长下令撤退、弹药耗尽且无法补给、周围没有队友且被敌人包围、倒计时接近结束还没被救。退时沿原路或掩体撤退，不要背对敌人直线逃跑。撤退不是懦弱，是保存战力。

不确定时先保守：如果不确定要不要冲，先不冲。观察队友动作，听队长指挥，等更清晰的信息再决定。新人多死在“硬拼”，少死在“保守”。

开枪前先想“我打完往哪退”，答不上来就先别打；暴露一个还没被发现的火力组，不值得。

::: takeaway
有命令、有压制、有掩护才冲；无队友、无弹药、被包围就退。不确定时先保守，别硬拼。
:::

## 伤救与撤退流程

受伤后先找掩体，按 `5` 取出止血带，按住右键给自己止血；有医疗包再回血。止血期间不要移动或开火。血量仍低或已经倒地，就按呼救键等医疗兵，等待时保持低姿。

撤退时不要独自跑图，跟最近的队友沿掩体走，不要背对敌人直线跑。有人倒地先判断能不能安全救；不能救就记住位置，等安全后再回来，或者直接放弃。

::: takeaway
受伤先找掩体、止血、回血、呼救；撤退不独跑，跟队沿掩体移动。救不了的人不要硬救。
:::

## 决策速查

- 新人第一局固定步枪兵，不选医疗兵和专业兵种。
- 先判断武器层级：打不动的目标就躲、就报，不用步枪挑衅装甲车。
- 倒地后先按呼救键，不静默等待。
- 救人前先确认周围安全，先止血再回血，避免双杀。
- 每次交火后补弹，不等空枪。
- 不确定时先保守，不要硬拼。
- 受伤先找掩体，不带伤继续战斗。

::: takeaway
速查表先解决“我该不该打、该不该救、该不该冲”三个问题，再谈具体操作。
:::

## 实战案例

::: case 占着筒子却打不中
一局在纳尔瓦，新人 E 开局抢了重筒，看到 300 米外一辆步战车，站着打了一发没中；原地换弹时被机炮扫倒。小队失去唯一的重筒，那辆步战车压了二十分钟街道。

复盘：重筒全阵营通常只有 1 个，是团队资源。不会认车型、不会打侧面和履带、不会打完就藏，就不要占位；拿步枪兵至少能补枪、补弹、跟队。
:::

::: case 冲退判断的差异
小队被压制在房子里，弹药剩一半，队长还没下命令。F 认为“不能一直待”，擅自冲出房子，被外围机枪扫倒。G 留在房里等撤退命令，全队沿掩体撤出，无人伤亡。

复盘：不确定时先保守，等命令比擅自行动更安全。冲退不是凭感觉，是听命令和看形势。
:::

::: takeaway
选错兵种会浪费团队资源，擅自冲锋会送票；先保自己、再保队友、最后才谈击杀。
:::

## 常见错误

::: mistake 症状—原因—改法
- 症状：选医疗兵但不会救人。原因：不懂医疗顺序。改法：先玩步枪兵，练熟止血带和医疗包。
- 症状：倒地不呼救。原因：不懂呼救键。改法：倒地第一时间按 `5`。
- 症状：冲去救倒地队友，两人都倒。原因：不看周围安全。改法：先封烟、清威胁。
- 症状：只止血不回血，队友起来又倒。原因：把止血当治疗。改法：止血后用医疗包补血。
- 症状：独自前进，遇敌无人支援。原因：独狼。改法：至少和一名队友保持视觉距离。
- 症状：受伤不自疗，继续战斗到倒地。原因：不懂止血优先。改法：先找掩体按 `5`。
- 症状：用步枪打步战车，暴露全队。原因：不懂伤害分级。改法：躲、报点，交给筒子。
- 症状：占着特射或重筒却不会用。原因：只看装备强度。改法：让位给会用的人。
:::

::: takeaway
常见错误源于“只管自己”或“占着位置不干活”。先保自己，再救别人，选自己能胜任的兵种，生存率会明显提高。
:::

## 实战练习

::: drill 步枪兵一局五件事
- 进服固定步枪兵，不换兵种。
- 每次交火后补弹，把弹药包丢给机枪或筒子一次。
- 按住 `B` 报点至少 3 次，说清方向和距离；队长/火力组长用 `T` 补标记。
- 跟队长或队友移动，不独自脱离视线超过 30 秒。
- 遇到倒地队友，先看安全，先止血再回血；不安全就只报点。
- 完成标准：补弹及时，报点 3 次以上，不独狼，施救不盲目。
:::

::: takeaway
把五件事做成条件反射，步枪兵就能成为小队的可靠成员。
:::
