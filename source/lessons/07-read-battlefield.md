## 学完能做到什么

- 看到地图上的红点或载具图标，能在心里画出它的威胁圈，判断自己是不是已经站进了圈里。
- 能说清锋线为什么不在两军标记的中点、而在更靠近己方的一侧，并据此选站位。
- 能把眼前地形分成明区、控制区、盲区、非战斗区四类，分别决定观察、架枪、补位、行军。
- 能按锋线长度判断双方展开程度，知道自己该补线、另开侧翼还是收拢。
- 能按"能不能挡爆炸"筛选掩体，不再把草丛、沙袋当成可以长期依赖的东西。

::: takeaway
读懂战场不是背地图，而是把"谁看得到谁、谁能打到谁"换成一个具体的站位决定。
:::

## 威胁范围与锋线腰线

### 每个单位都是一个圆

把每个作战单位想成一个圆：以他为圆心，以最远有效射击距离为半径。常见兵种的半径大致如下。

| 单位 | 有效半径 | 说明 |
|---|---|---|
| 步枪兵 | 视野好约 200 米，视野差约 50 米 | 有光瞄和无光瞄差距很大 |
| 特射 | 约 300–400 米 | 近战能力弱，被贴脸基本必死 |
| 机枪 | 架起后封锁一条街 | 火力持续但转移慢 |
| 载具 | 比步兵大得多 | 复杂地形里会被绕后 |

地图上出现一个红头盔、一个载具图标，就要在心里画一个圆。你走进这个圆，就意味着可能有一个你还没看见的人正看着你。减小威胁范围只有两个办法：利用掩体，或者利用视野盲区。烟雾能制造短暂盲区，但步战车的机枪子弹和高爆弹并不在乎烟里有没有人。

### 锋线不在中点

两个人对枪，最危险的位置不是地图上两个标记的中点，而是更靠近自己这一侧的那条线。因为对方的有效射程已经越过中点，伸到了你这边。你以为"离标记还有一段距离"，其实已经进了对方的火力圈。双方火力范围交叠的最前沿才是真正的锋线。站在锋线上最危险，正确做法是站在锋线己方一侧，让自己的射击半径越过锋线。

与两军连线垂直的方向叫腰线。当双方注意力集中在正面约 60–90 度时，沿腰线移动最不容易被发现。但腰线成立有前提：敌人被正面牵制。敌人静止架枪时会左右观察，这时走腰线一样会被看到。

::: figure 图 07-1：威胁圈、锋线与腰线。站在锋线己方一侧，才能做到“能打能躲”。
![威胁圈与锋线腰线示意图](../../assets/images/threat-rings.svg)
:::

::: warn
不要在开阔地沿着两军连线正面推进。这条线上汇集了对方所有预先架好的枪线，你就是走在靶场的移动靶。
:::

### 锋线长度就是展开程度

锋线不只是一条位置线，它的长度还说明双方展开了多少。画法很直接：把我方进攻起点和敌方防御起点连成一条线，再看这条线中段友军密集倒地的位置，在倒地带两侧各取约 100 米，画两条相互对峙的横线，这两条线之间就是当前的火力锋线。锋线越长，说明双方投入的兵力越多、展开面越宽；只有一侧长、另一侧短，短的那一侧就容易被绕过端点包夹。

这条判断能直接指导决策。己方锋线明显短于对方时，不要再往正面填人，填进去的人只会挤在同一个火力扇面里；正确做法是用队包或载具在侧后方另开一个展开点，把锋线拉长，或者主动放弃一个暴露的复活点，把兵力收回到更短、更结实的线上。己方锋线更长时，可以从端点向对方侧后卷，但每卷一步都要补人守新暴露的侧面，否则长线自己也会断。

锋线还会移动。友军密集死亡的位置换了一段，锋线就跟着换；上一波在村口，这一波可能已经退到村后的矮墙。所以每次看地图都要重新找死亡带，不要拿上一波的位置继续套。

::: takeaway
红点先画圈，进圈前先问有没有掩体、有没有队友看着侧面；锋线靠己侧，腰线只在正面被牵制时才成立；线短就另开侧翼，别往正面继续填人。
:::

## 四类区域

按"谁能看到谁"，而不是"有没有掩体"，把地形分成四类，每类的行动原则完全不同。

| 区域 | 谁能看到谁 | 该做什么 | 不该做什么 |
|---|---|---|---|
| 明区 | 敌我都能看到 | 观察、收集信息，必要时快速通过 | 长时间停留、站着对枪 |
| 控制区 | 我方能看，敌方看不到 | 架枪、打贸然进入的敌人 | 轻易放弃、暴露枪线 |
| 盲区 | 敌方能看，我方看不到 | 呼叫队友补位、用交叉火力压缩 | 单人盲目前出 |
| 非战斗区 | 双方都看不到 | 行军、绕侧、放队包 | 当成绝对安全区长期逗留 |

四个区域会随着人员移动变化。你往前推一步，原来的盲区可能变成控制区；你退一步，控制区又变回盲区。所以区域控制不是占住一个点不动，而是不断把非战斗区变成控制区、把盲区压缩掉。

举个例子说明区域怎么随人变化：一条街对面的窗口，你躲在墙后时是控制区（你看得到窗口，窗口里的人看不到你）；你探头开了一枪，对方转过来架住你的位置，这块地方就变成了盲区（他看得到你，你看不到他）；等队友从侧面把窗口里的人打掉，这里又变回控制区。同一个位置，三秒钟内可以换两次属性，所以判断要跟着战况走，不要贴一张固定标签。

再看非战斗区。它是双方都看不到的地方，适合行军、绕侧、放队包，但绝不意味着可以松懈。非战斗区往往紧挨着盲区，敌人的巡逻队可能正在里面穿行。正确的用法是：快速通过、保持队形、随时准备开火，而不是卸下装备原地休息。

::: tip
在明区只需要做两件事：看清楚，然后尽快离开。想在明区站住对枪，等于把自己的位置免费送给对方。进非战斗区要快进快出，把它当中转站，不要当营地。
:::

::: takeaway
明区观察、控制区架枪、盲区补位、非战斗区行军；四句话能解决大部分"我现在该干嘛"的困惑，但每句话都要按最新战况重新判断。
:::

## 安全包线与区域扩散

### 安全包线

每块区域都有安全包线：越靠外围，视野越大、信息越多，但风险也越大；越靠中心，视野越小、风险越小，但你也越难发现外面的敌人。观察位通常选在次外圈——既能看出去，又不太容易被发现。最外圈信息最多但最危险，最内圈最安全却等于蒙住自己的眼睛。

### 占了就要扩散

区域之间是相连的。只占住一块区域、周围相邻区域却在敌人手里，就会被包夹。所以占下一块区域后，应当分出兵力向周围扩散，常用的方式有三种。

1. **分散兵力**：把人撒到相邻房屋或掩体，而不是全挤在点位中心。
2. **队包防控**：用小队包覆盖后方区域，敌人摸进来会先撞上复活点附近的防守。
3. **远点支援**：用特射、机枪或载具从远处看住一片区域。

::: case 纳尔瓦火车站的占楼思路
- **局面**：进攻方兵站刚在火车站建好，队友习惯性全部缩在站内等拉点。
- **判断**：站长在车站里只能看到站台，四周房屋的窗口都能俯视车站，这块区域是被包夹的。
- **动作**：队长分出两组占住西侧两栋楼，用窗口架住车站和进出道路，站内只留拉点的人。
- **结果**：防守方无法在站内展开，一露面就被窗口火力打退，进攻方用很小的代价拿下车站周边。
- **复盘**：真正的控制不是人挤在点里，而是占住点周围能看见它的楼。
:::

::: takeaway
区域控制的关键是占下之后往外扩散；只守一个点、不管相邻区域，等于把自己送进包夹。
:::

## 掩体八类：先问能不能挡爆炸

"有掩体"不等于"安全"。掩体要按两个维度看：能不能挡住视线（完全/不完全），能不能挡住子弹和爆炸（实际/视觉）。两个维度交叉，得到八类。

| 类型 | 例子 | 能挡什么 | 怎么用 |
|---|---|---|---|
| 自然完全实际 | 水泥楼、大石块、地下室 | 子弹、手雷、迫击炮 | 长期架枪、救治、放兵站 |
| 人工完全实际 | 防爆墙、HESCO | 爆炸、直射 | 保护兵站、封缺口 |
| 自然不完全实际 | 木板墙、铁皮墙、树干 | 部分子弹，不挡爆炸 | 短暂躲避、偷袭后转移 |
| 人工不完全实际 | 沙袋墙、带孔沙袋 | 大部分子弹，不挡爆炸 | 临时架枪、封走位 |
| 自然完全视觉 | 高树丛、芦苇 | 只挡视线 | 埋伏、观察，开火后必须转移 |
| 人工完全视觉 | 伪装网、轮胎火堆 | 只挡视线 | 制造错觉、掩护转移 |
| 自然不完全视觉 | 矮花丛、麦田 | 几乎不挡 | 匍匐接近，别久留 |
| 人工不完全视觉 | 铁丝网、带孔沙袋 | 阻碍移动、报警 | 封走位、当警报器 |

真正能长期依赖的只有"完全实际掩体"。视觉掩体一旦被发现，作用立刻归零；不完全实际掩体被爆炸一碰就露馅。兵站和电台要放地下室或坚固建筑里，不是为了藏起来，而是为了就算被看见也炸不掉。

### 一张对照表记住怎么选

| 你的目的 | 该选的掩体 | 不该选的 |
|---|---|---|
| 架枪守一条路 | 水泥墙、防爆墙、楼体 | 树干、沙袋墙 |
| 救人、止血 | 地下室、完整房间 | 草丛、铁皮棚 |
| 放兵站、电台 | 有顶坚固建筑 | 树林、反斜坡（只能临时） |
| 打完就撤的偷袭 | 高树丛、伪装网 | 任何固定点位 |
| 长时间观察 | 有遮蔽的高点、次外圈 | 天际线、窗口正中 |

这里有一个容易混淆的地方：树干属于"自然不完全实际掩体"，它能挡住一部分子弹，但挡不住爆炸；高树丛属于"自然完全视觉掩体"，它能彻底挡住视线，却完全不挡子弹。两者看着都是"树"，用途天差地别。记住区分的口诀：先问挡不挡爆炸，再问挡不挡视线。

掩体够不够，还要看对手是谁。同一堵墙，对步枪是硬掩体，对步战车可能只是纸板：防爆墙能挡重机枪，却挡不住车载榴弹的溅射；沙袋能挡弹片，却挡不住坦克主炮的冲击波。听到履带声，先别问"这墙厚不厚"，先问"对面是什么车"，再决定是进地下室、下反斜面，还是放弃这个位置。车型与掩体的对应关系，第 10 课会展开。

::: takeaway
先问这掩体能不能挡爆炸，再问能不能挡视线；能挡爆炸的才配叫长期掩体，遇到载具还要按车型重新判断。
:::

## 决策速查

::: rule 站位判断口径
- 地图上出现红点，先按兵种画威胁圆，再决定是否进入。
- 推进时站在锋线己方一侧，不站在锋线上，更不冲过中点。
- 想绕侧先确认敌人正面被牵制；敌人静止架枪时不要走腰线。
- 明区只看不停，控制区架枪守，盲区喊人补，非战斗区赶路。
- 选停留点先筛"完全实际掩体"，筛不到就换个地方，不要将就。
:::

::: takeaway
这五条口径按"画圈—站位—绕侧—分区—选掩体"的顺序用，遇到情况先从第一条往下过一遍。
:::

## 实战案例

::: case 林地空降后的观察位取舍
- **局面**：小队乘直升机空降到一片林地花园，第一波被东侧树林的火力打掉大半。
- **判断**：队包消失说明 30 米内进了敌人，友军成片死亡的方向指向东侧树林；唯一活下来的机枪原本准备向南撤退。
- **动作**：机枪改成撤到能继续看住东侧树林的高点，先用附近语音报出方向，等第二波队友从侧翼落地，而不是让第二波从同一个点再降一次。
- **结果**：第二波落地就有人架着东侧树林，找到了对方火力点，没再重复团灭。
- **代价与复盘**：第一波损失的票换来的信息是"威胁来自东侧"；守住观察位才让这份信息没有白费。撤退方向要优先保证还能看见威胁，而不是单纯远离枪声。
:::

::: case 盲区硬冲的四人队
- **局面**：小队推进到一处村口，前方一排房屋敌方能看、我方看不到，属于盲区。
- **判断**：队长急于抢点，命令四人并排冲过去；盲区里至少有一个预先架好的机枪位。
- **动作**：四人进入后两人瞬间倒地，剩下两人贴在矮墙后无法还击，呼叫支援已来不及。
- **结果**：小队减员一半，进攻节奏中断，复活点还要重新组织。
- **复盘**：盲区不能单人盲目前出，更不能整队并排通过。正确做法是先用烟或投掷物探路、用交叉火力压住可疑窗口，把盲区压成控制区再过。
:::

::: case 明区站桩对枪的机枪手
- **局面**：开阔地中央有一道矮墙，机枪手觉得架在这里视野好，可以封锁整条路。
- **判断**：矮墙是人工不完全实际掩体，只挡一部分子弹不挡爆炸；四周没有任何能挡炮弹的东西，这块明区双方都看得到。
- **动作**：机枪手在矮墙后连续射击，暴露了枪线；对方先用榴弹覆盖矮墙，再让一名特射从侧面的次外圈点名。
- **结果**：机枪被炸毁、射手倒地，全队失去持续火力，进攻被迫停下。
- **复盘**：视野好的位置往往也是最显眼的位置。架枪点必须优先满足"能挡爆炸、有退路"，其次才是视野；打完一轮就换位置，别在一个明区站到被锁定。
:::

::: takeaway
两个案例的共同点是：先判断区域和威胁方向，再决定动谁、往哪动；信息没用上，人数优势就会变成送票。
:::

## 常见错误

::: mistake 把地图中点当安全线
- **症状**：总觉得"还没走到标记点"，就一路直着推进，在半路被击倒。
- **原因**：用中点代替了锋线，忽略了对方射程已经越过中点。
- **改法**：把锋线画在更靠近己方的一侧，推进时站在锋线己方，让枪口先越过锋线，而不是人先越过去。
:::

::: mistake 把草丛和沙袋当防弹掩体
- **症状**：躲在高树丛或沙袋墙后就以为安全，被手雷或迫击炮一发带走。
- **原因**：把视觉掩体和不完全实际掩体当成了完全实际掩体。
- **改法**：开火前先确认身后有能挡爆炸的东西；找不到就打完转移，不要在草丛里久留换弹。
:::

::: mistake 沿腰线一路直线跑
- **症状**：看到队友在正面交火，就贴着侧面一路小跑想绕后，结果半路被静止架枪的敌人发现。
- **原因**：腰线成立的前提是敌人注意力被正面牵制约 60–90 度；对方一旦左右观察，腰线就不是盲区。
- **改法**：绕侧前先确认正面确实咬住敌人；沿腰线时压低身形、利用地形断断续续移动，经过每个拐角都先观察再过。
:::

::: takeaway
反复出现的错误只有两类：站位踩进对方射程，掩体挡不住爆炸。改这两类比多记一个技巧更有用。
:::

## 实战练习

::: drill 三秒区域判断
- **怎么练**：一局里每次准备前进前，花三秒判断接下来要进入哪种区域（明/控制/盲/非战斗），并选好一个能挡爆炸的停留点。
- **完成标准**：一局至少做 15 次判断，其中误把视觉掩体当选定点不超过 2 次；每次进盲区前都喊了队友补位或先探路。
- **复盘方式**：死亡后回看自己站的位置，写一句"当时属于哪类区域、掩体能不能挡爆炸"。
:::

::: takeaway
把四类区域和掩体分类变成每次移动前的固定三秒，判断才会从"知道"变成"做到"。
:::

## 自检 3 问

1. 地图上出现一个特射红点，你为什么不能按 200 米步枪兵的威胁圈来处理？
2. 锋线为什么在更靠近己方的一侧，站在锋线上会发生什么？
3. 高树丛和水泥楼分别属于哪类掩体，哪种能用来长期架枪？

::: takeaway
三问分别对应画圈、站位、选掩体；答不上来就回到对应小节再读一遍，然后下一局只练那一个动作。
:::
