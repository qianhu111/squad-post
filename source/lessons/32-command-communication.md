## 学完能做到什么

- 说清队员、班长、小队长、指挥官四层的信息流向与决策权。
- 用“任务、地点、时间、目的”四要素下命令。
- 用回声确认避免命令失真，知道什么该复述。
- 用“点位、状态、敌情、需求、时间”报清拉点、防守和接敌状态。
- 在频道拥堵时按优先级让路，处理重复和无效通话。
- 与相邻小队约定分界线、支援格式和友军位置通报。

通信的目标不是把话说出去，而是让正确的人在正确的时间做同一个动作。

::: takeaway
指挥效率取决于信息走最短的路、命令说最少的字，而不是频道里声音最大的人。
:::

## 命令链的四个层级

小队内三级：队员报班长，班长整理态势，小队长下命令；小队外一级：小队长在指挥频道与指挥官、相邻小队长协调。

频道分三层：局部语音给身边十几米内的人；小队频道给队长和班长；指挥频道只给各小队长和指挥官。把局部内容塞进指挥频道，是最常见的拥堵来源。

不越级是默认规则。队员绕过班长，小队长会被细节淹没；小队长绕过指挥官调别的队，容易两队撞在同一条路。紧急情况可越级报警，如“敌方载具从北面进点”，但随后要补报直接上级。

| 层级 | 主要频道 | 职责 | 不应做 |
|---|---|---|---|
| 队员 | 局部语音、小队频道 | 报点、确认命令、执行 | 直接指挥其他队员 |
| 班长 | 小队频道 | 过滤信息、带班行动 | 绕过小队长接外部任务 |
| 小队长 | 小队频道、指挥频道 | 决策、分配任务、协调 | 在频道里讲细节 |
| 指挥官 | 指挥频道 | 定优先级、协调小队 | 替小队长指挥单兵 |

同一时间、同一空间只能有一个指挥声源。友队队长可以给建议，但不能直接点名指挥你的队员；你需要协调，就找他的队长或指挥官。两个队长同时给同一个组下不同的命令，比没人指挥更危险，因为组员会各自挑一个听起来更顺耳的去做。

统一指挥不等于队长一个人说完所有话。它指的是：一个目标在同一时刻只有一个负责人，其他人可以补充信息，但不能另开一条命令线。队长阵亡后也一样，接任者宣布接管之前，其他人只报情况，不下命令。

::: figure 图 32-1：命令链与频道。命令向下、信息向上，紧急越级后必须补报。
![命令链与频道示意图](../../assets/images/g6-command-chain.svg)
:::

::: takeaway
命令链不是官僚层级，而是信息的过滤器和决策的分工：越级一次，两个层级同时失去判断依据。
:::

## 命令四要素：任务、地点、时间、目的

一条能执行的命令至少包含四件事：做什么、在哪做、什么时候做、为什么做。缺任务，不知道动什么；缺地点，全队往不同方向；缺时间，行动不同步；缺目的，遇到变化不会变通。

任务用动词开头：“压制”“占领”“护送”“封锁”“撤退”，不要用“注意一下”。地点用网格或固定地标加方位：“红车后”“教堂北侧矮墙”“C 点西南 50 米”。

时间用绝对或相对节点：“现在”“30 秒后”“烟幕落下后”“一班到位后”。目的最容易被省略、也最值钱，它让下属在计划失效时自己判断。

完整示例：“二班，现在，沿西侧矮墙到红车后，压住二楼两个窗口，让一班能过街。”任务是压窗口，地点是红车后，时间是现在，目的是掩护一班。二班发现窗口没人，就知道把火力转向一楼门口，而不是原地等命令。

| 错误命令 | 问题 | 改写 |
|---|---|---|
| “大家注意点” | 无任务、无地点 | “二班看西侧矮墙，一班看路口” |
| “去那边压一下” | 地点模糊 | “到红车后，压二楼窗口” |
| “等会儿再动” | 时间模糊 | “烟幕落下后 5 秒动” |

::: takeaway
命令四要素缺一项，执行就会多一次追问；把“目的”说出来，下属才能在计划失效时做出你想要的选择。
:::

## 回声确认与执行确认

命令发出后，接收方要复述关键要素，而不是只回“收到”。复述只抓任务、地点、时间：“二班收到，红车后，压二楼，现在动。”发起方回“正确”或“更正：一楼，不是二楼”。

频道里有枪声、引擎声、多人同时说话，“收到”只能证明耳朵响了一下，不能证明信息进门。坐标、楼层、左右方向必须复述。

执行确认按节点来：出发、到位、接敌、清除、需要支援、完成。队长不需要听全过程，但必须知道每个节点有没有发生。

没有回应时，5 秒后重呼一次，仍无回应就派传令或看地图标记，不要连续喊十遍。两次无回应通常意味着对方阵亡、掉线或换了频道。

| 场景 | 错误回应 | 正确回应 |
|---|---|---|
| 收到进攻命令 | “收到” | “二班收到，西侧矮墙，30 秒后动” |
| 命令听不清 | 沉默或猜着做 | “重复地点，西侧还是北侧” |
| 到位 | 不说话 | “二班到位，红车后” |
| 任务完成 | “搞定了” | “二楼清除，二班在楼梯口” |

::: takeaway
回声确认是把命令从“我说过”变成“他理解了”，执行确认是把行动从“应该在做”变成“确实到位”。
:::

## 战况报告：拉点、防守、接敌各一句话

报点回答“敌人在哪”，战况报告回答“这个点现在怎么样、你需不需要帮助”。队长在指挥频道最想听到的不是过程，而是状态和需求：点能不能拉动、你还剩几个人、需不需要另一个组。

| 场景 | 一句话模板 | 必须包含 |
|---|---|---|
| 进攻拉点 | “A 队进 C 点，能拉动，已拉 40%，约 30 秒” | 点位、能否拉、进度、预计时间 |
| 被反拉 | “C 点被反拉，点内步兵至少四人，我在西门” | 点位、状态、敌情、自己的位置 |
| 拉不动 | “C 点拉不动，敌人至少半队，需要一班从东侧进” | 状态、敌情、需求、进入方向 |
| 防守接敌 | “D 点北侧接敌，步兵约半队，无载具，能撑住，不需要支援” | 方位、敌情、能否撑、需求 |
| 点将失守 | “D 点被拉，剩两人，30 秒内要支援，否则撤到南墙” | 状态、剩余人数、时限、预案 |
| 点已丢失 | “C 点丢了，我们退到南侧砖厂，三人存活” | 结果、位置、人数 |

报告顺序固定为：**点位 → 状态 → 敌情 → 需求 → 时间**。不要从“刚才我们看到”讲起，队长需要先知道结论，再决定要不要听细节。

拉点进度用百分比和秒，不用“快好了”。说“已拉 60%，还要 20 秒”，队长能判断是再投一个组，还是让现有的人先守住外围。说“快好了”，队长只能反复追问，频道就被占住了。

报忧也要报喜。点拉下来、载具退走、通道打开，都要用一句收尾；否则队长会一直以为你还在打，不敢把预备组调走。战况报告的最后一句，应该是“现在需要什么”或者“这里不用管了”。

::: takeaway
战况报告按“点位、状态、敌情、需求、时间”说，拉点报百分比和秒数。队长要的是结论和需求，不是过程。
:::

## 频道分工与拥堵时的优先级

频道拥堵时，不是所有信息都值得开口。优先级从高到低：敌方载具、空袭、迫击炮落点；己方倒地、需要医疗；目标点状态；移动、补给、路线；最后是闲聊和复盘。

紧急信息用固定前缀“紧急”或“break”，说完立刻让出频道，例如“紧急，B 点北侧步战车一辆”。非紧急信息压后，或直接在地图上标记。

发言前先听 3–5 秒，确认没人在报紧急信息。指挥频道同一时间只允许一个主讲，其他人用“待命”“收到”回应；补充时等主讲停顿，用“补充”开头。

拥堵严重时，小队长下“静默”指令：“除紧急情况，小队频道静默 20 秒。”静默是把频道留给医疗、反载具和队长。

| 信息 | 优先级 | 走哪个频道 | 建议时长 |
|---|---|---|---|
| 敌方载具逼近 | 1 | 指挥频道加小队频道 | 5 秒内 |
| 己方倒地、需要医疗 | 1 | 小队频道、局部语音 | 3 秒内 |
| 点内敌人数量变化 | 2 | 小队频道 | 5 秒内 |
| 复盘、抱怨、闲聊 | 4 | 战斗结束后 | 不占战斗频道 |

能用标记说清的，不要用嘴说。一个带类型的敌方载具标记，比十秒的口头描述有效；语音只补充标记上没有的信息——数量、动向、威胁。标记和语音同时进行时，先说“我标了”，再说“补充：车上有两人下车”。这样听的人先看到图，再听到变化，理解成本最低。

::: takeaway
频道是共享带宽，优先级就是“谁先说话”的规则；紧急信息短、非紧急信息等，静默指令是队长的刹车。
:::

## 重复汇报与无效通话的处理

同一条信息第二个人再报时，不要整段重复，用“确认”加新要素：“确认，另有一辆从北面来。”队长由此知道不是两个目标，而是同一目标有了新情况。

无效通话有四类：没有方位（“这边有人”）、没有目标（“有情况”）、没有需求（“我们被打惨了”）、情绪宣泄（“怎么没人来”）。共同问题是只传情绪，不传可行动的信息。

队长纠正时给模板，不骂人：“报方位、人数、威胁，重说。”连续无效通话可临时禁言，指定他只用局部语音向班长报。

死亡后报一次就闭嘴：“我倒了，C 点南侧墙后。”让医疗判断是否来救；不要持续喊“救我”，也不要替活着的队友指挥，死者的信息可能已经过期。

| 无效通话 | 问题 | 替换说法 |
|---|---|---|
| “这边有人！” | 无方位、无数量 | “C 点南侧，步兵两人，正靠近” |
| “我们被打死了” | 无位置、无需求 | “二班在桥头倒地两人，需要医疗” |
| “敌人好多” | 无数量、无方位 | “北侧路口步兵至少四人，一挺机枪” |
| “我倒了救我” | 无位置 | “我倒在红车后，敌方火力来自西侧” |

::: takeaway
重复汇报要加新信息，无效通话要给模板；频道里每多一句废话，紧急信息就晚到一秒。
:::

## 跨小队协调

相邻小队先约定分界线：道路、河流、建筑排或网格线。两侧各自负责，火力不越线；越线追击或射击前先报“我队要过界，到教堂北侧”，避免友军把你当目标。

请求支援用五要素：谁在请求、在哪里、需要什么、什么时候、从哪里进。“A 队，C 点南侧，需要一班和烟幕，30 秒后，从东侧巷子进。”对方能直接判断能不能来、怎么来。

友军位置要在开火前通报，尤其是火力支援、载具主炮和迫击炮。报“友军在目标南侧 50 米”比“别打南边”有效。烟幕、信号弹和地图标记要同步，颜色和位置提前约定。

指挥频道礼仪：开口先报“A 队请求”，说完让出频道；别人报紧急信息时等他说完；不要直接点别的队队员，走他们队长。

| 场景 | 标准说法 | 目的 |
|---|---|---|
| 越过分界线 | “A 队过界，到教堂北侧” | 防止友军误判 |
| 请求支援 | “A 队，C 点南，要一班加烟，30 秒，东侧进” | 让对方能直接执行 |
| 通报友军位置 | “友军在南侧矮墙后 50 米” | 防止火力误伤 |
| 请求停火 | “停火，友军在你前方” | 立即中断射击 |

::: takeaway
跨小队协调靠三件事：分界线说清、支援请求说全、友军位置先说；三件事做到，友军火力就不会落在自己人头上。
:::

## 命令链断裂与重建

命令链会断：队长阵亡、掉线、频道被占、队伍被火力隔开。断开后最危险的是两个人同时下令，队伍分成两半各打各的。

继任顺序战前指定：副队长接队长，一班班长接副队长，资深队员接班长。队长阵亡后，接任者立刻宣布“我接管，所有人听我”，重复两遍，直到有人回应。

接管后三步：收拢点名，确认还剩几人；定位置，告诉每个人守哪、往哪撤；分配下一任务，拉点、撤退还是等增援。三步做完再处理细节，不要一上来就复盘对错。

频道本身断了，就用地图标记、局部语音和传令兵重建联系。小队之间约定备用集合点，如“教堂后墙”，失联后各自往那里靠。

| 断裂情形 | 第一动作 | 恢复动作 |
|---|---|---|
| 队长阵亡 | 副队长宣布接管 | 收拢点名、重新分配 |
| 队长掉线 | 班长暂代，报指挥官 | 指挥官指定新队长 |
| 频道拥堵 | 下静默指令 | 只留紧急信息 |
| 队伍被隔开 | 各自找掩体，报位置 | 约定集合点重组 |

::: takeaway
指挥链断裂不可避免，重建靠预先指定的继任顺序和一句明确的“我接管”，最怕的是沉默和双头指挥。
:::

## 决策速查

- 信息流向：队员→班长→小队长→指挥官，紧急可越级但随后补报。
- 命令四要素：任务、地点、时间、目的，缺一项就会多一次追问。
- 回声确认复述关键要素，执行确认按出发、到位、接敌、清除、完成报。
- 战况报告按“点位、状态、敌情、需求、时间”说，拉点报百分比和秒数。
- 频道优先级：载具与医疗最高，路线补给其次，闲聊不占频道。
- 重复汇报加“确认”和新要素，无效通话用“方位、人数、威胁”模板纠正。
- 跨小队先约定分界线，支援请求说清谁、哪、什么、何时、从哪进。
- 队长阵亡后立即宣布接管，收拢、定位置、分配任务三步重建。

::: takeaway
速查表背下来只是底线，真正要练的是在枪声里仍然按这个顺序说话，让命令链在压力下不断。
:::

## 实战案例

Al Basrah 城区推进。小队沿主干道向 C 点移动，队长在路口被狙击手击倒。副队长立即喊“我接管，所有人停火找掩体”，连喊两遍。一班报“正前方 150 米，二楼窗口，狙击手一人”；二班报“左巷步兵三人，正往侧翼走”。

副队长先让一班压住二楼窗口，二班退到巷口矮墙防侧翼，医疗去拉队长。确认人数后下令：“一班压窗口 10 秒，二班跟我从右巷绕到楼后，烟幕落在路口，30 秒后动。”一班复述“压窗口 10 秒”，二班复述“右巷，楼后，30 秒”。两队同时行动，狙击手被压制后撤，小队从楼后进入 C 点。

同一局里，B 队在 C 点北侧推进，双方的分界线是东西向主路。A 队追击时准备越过主路，副队长先在指挥频道报“A 队过界，到路北药店”，B 队回“收到，路北归你，我在路南”。两队没有互相误射，C 点被夹击拿下。

复盘：接管及时避免了指挥真空；命令四要素齐全，两个班都能复述；跨小队过界提前通报，避免友军火力交叉。若副队长上来就喊“给我打”，队伍会各自开火，既压不住狙击手，也会和 B 队撞线。

::: takeaway
案例里没有神奇操作，只有“先接管、再报点、后下令、过界先说”的顺序；顺序对了，混乱就被切成一段段可处理的小问题。
:::

## 常见错误

- 症状：队长阵亡后没人说话，各自为战。原因：没有继任顺序。改法：战前指定副队长，阵亡后立即接管。
- 症状：命令只有“打”没有地点，队员走散。原因：缺地点和目的。改法：按四要素重说。
- 症状：只回“收到”，结果打错楼层。原因：没有回声确认。改法：复述任务、地点、时间。
- 症状：三人同时讲话，医疗请求听不见。原因：没有优先级和静默规则。改法：紧急前缀加静默，非紧急押后。
- 症状：两个小队在同一路口互射。原因：没有分界线和友军位置通报。改法：过界前报，开火前报友军位置。
- 症状：死亡后持续喊“救我”，占住频道。原因：不懂死亡通信纪律。改法：报一次位置和威胁方向，然后闭嘴。

::: takeaway
这些错误都能用一句话预防：先说清谁指挥、再说清做什么、最后才说怎么做；顺序反了，频道越热闹，队伍越乱。
:::

## 实战练习

四要素命令：一局中下达至少 5 条命令，每条都包含任务、地点、时间和目的，并要求接收方复述。

频道优先级：一次交火中，记录自己报出的信息属于哪一级，看有没有把情绪类信息放在紧急信息之前。

跨小队协调：与相邻小队约定分界线，越界前通报，请求支援时用“谁、哪、什么、何时、从哪进”五要素说一次。

完成标准：四要素命令 5 条、优先级自检 1 次、跨小队通报 1 次，并能指出一条被队友复述纠正过的命令。

::: takeaway
练习通信不需要打满一局，抓住“下命令、报紧急、过边界”三个瞬间各练一次，就足够暴露大部分坏习惯。
:::

## 自检 3 问

1. 命令链有哪几层，信息和命令各往哪个方向走？
2. 一条完整命令包含哪四个要素，为什么“目的”不能省？
3. 频道拥堵时哪些信息优先？拉点状态和重复汇报各怎么报？

::: takeaway
能答出层级、要素和优先级，说明通信已经能支撑小队行动，而不只是“会说话”。
:::
