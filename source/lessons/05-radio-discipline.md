## 学完能做到什么

- 按听众选对三个语音频道，知道每个频道的按键、范围和边界。
- 把命令拆成“谁、做什么、去哪、何时”，缺项当场追问。
- 用接敌、状态、载具、死亡、支援五套模板报点，每条不超过八秒。
- 按 P1–P4 让出话权，有令必复述、完成必回报。
- 在九人小队里通过火力组转达信息，不把小队频道塞满。

::: takeaway
通话的目标不是“说过了”，而是“对方听懂了并且能照做”。判断标准是队友的下一步动作。
:::

## 三个语音频道的分工

Squad 的语音是按住说话，不是切换频道。三个主频道各有明确按键和覆盖范围。

| 频道 | 按键 | 覆盖范围 | 典型内容 | 禁区 |
|---|---|---|---|---|
| 附近语音 | 按住 `V` | 身边约 25–50 米内的队友 | 三秒警告、掩护请求、“扔雷了” | 长战术、整队路线 |
| 小队语音 | 按住 `B` | 本小队全员，无视距离 | 报点、复述、物资请求、汇报 | 闲聊、和别队争论 |
| 指挥频道 | 按住 `G` | 所有小队长和指挥官 | 跨队协同、资源申请 | 队员发言、本队琐事 |

附近语音只传给同队玩家，敌方听不到，但不代表可以随便喊：枪声和动作会暴露位置。它的价值是“三秒内要发生的事”：门前有人、掩护我、别过去。距离有限，不能代替小队汇报。

`B` 是主工作频道：命令、报点、补给、复述和回报都走这里。`G` 只有小队长和指挥官能发言；队长在 `G` 通话时，小队语音安静。

小键盘 `1`–`9` 是队长单独通话，按几呼叫几队。能私聊就不要占 `G`。

跨队走“队员 → 本队队长 → 指挥频道 → 对方队长”，队员不直接喊别队。同一信息只在一个频道说完整：附近喊“门口有人”，小队补方向和数量。

![通话闭环与频道分工](../../assets/images/g1-comms-loop.svg)
:::

::: takeaway
先问“这句话需要谁听到”，再选频道：`V` 管三秒内的安危，`B` 管整队协作，`G` 只留给队长。
:::

## 命令四要素：谁、做什么、去哪、何时

一条能执行的命令至少包含四项：谁执行、做什么动作、去哪个位置、什么时间或条件下做。少一项，执行者就只能猜。

| 要素 | 要回答的问题 | 合格示例 | 缺项后果 |
|---|---|---|---|
| 谁 | 哪个小队、火力组或个人 | “二队”“机枪组” | 所有人等别人先动 |
| 做什么 | 推进、守住、包抄、架枪、撤退 | “沿西侧围墙推进” | 听成散步或原地待命 |
| 去哪 | 网格、建筑、路口、地标 | “C3 仓库北门” | 走错楼、进错点 |
| 何时 | 现在、倒计时、信号、条件后 | “我数到三”“烟落地后” | 提前暴露或错过窗口 |

示例：“二队，现在沿西侧围墙推进到 C3 仓库北门，到墙根停，等我掷烟再进门。”四要素齐全，还加了约束。

缺项当场补问：“去那边”缺方向，“包抄”缺路线和时间，“等会儿打”缺触发条件。“马上”不算时间，换成“十秒后”“烟落地后”。复述时确认：“二队收到，等烟落地再从北门进，对吗？”不走大路、无线电静默这类约束也要复述。

命令里带可验证的地标：“门口有蓝色集装箱的三层楼”比“那栋楼”清楚。

::: takeaway
听到命令先找四个空位：谁、做什么、去哪、何时。任何一格是空的，就用一句话追问，不要靠猜。
:::

## 回声确认与闭环

回声确认是把“我说了”变成“他懂了”。完整闭环四步：听命令、复述、执行、回报。

队长：“二队，三十秒后从南侧楼梯上二楼，清掉东侧房间。”

队员：“二队收到，三十秒后南侧楼梯上二楼，清东侧房间。”

三十秒后，队员：“二队已上二楼，东侧房间清空，一人轻伤。”

复述要覆盖四要素，不是只说“收到”。只回“收到”只证明麦克风工作。发现矛盾当场提：“南侧有铁丝网，改走北侧可以吗？”任务较长要有中间回报，结束带结果：已到达、已占领、已撤离或无法完成及原因。

只回“好”“OK”不算确认，长时间静默也不算配合。复述、报节点、报结果三段都不能省。频道忙可说“收到，执行中，三十秒后回报”，但四要素要先听全。

通话开头先“提醒与识别”：用一句“二队注意”把注意力拉过来，再说明你是在对谁说。不要一开口就讲细节，队友还没切换到你的频道，前半句已经丢了。

::: takeaway
命令只有走完“复述—执行—回报”才算闭环。只回“收到”不叫确认，任务完成不吭声等于没完成。
:::

## 通话短句与优先级

频道是单声道资源，同时只能有一个人说清楚。优先级决定撞车时谁的话必须留下。

| 级别 | 内容 | 允许延迟 | 典型短句 |
|---|---|---|---|
| P1 | 生死与接敌 | 立刻，可打断任何人 | “接敌！”“倒下！” |
| P2 | 战术指令与报点 | 三到十秒 | “两人，2 点，100 米。” |
| P3 | 后勤与状态 | 十到三十秒，等空白 | “缺弹”“需要医疗” |
| P4 | 闲聊与复盘 | 战斗结束后 | “刚才那波不错。” |

判断标准：会改变队友三秒内动作的是 P1；只影响三十秒后安排的是 P3；不影响行动的是 P4，战斗中不说。

短句固定：接敌、压制、换弹、倒下、安全、停火、撤。“我扔手雷了”“封烟了”“筒子尾焰”要在动作前说。

一条不超过八秒；内容多先说“长报，给我十秒”。P1 三秒没回应，缩短重复并加“重复”：“接敌！重复，西门两人！”不要用情绪词代替信息。

::: takeaway
先分级再开口。P1 打断，P2 排队，P3 等空档，P4 打完再说；短句固定，队友才能秒懂。
:::

## 报点模板

报点不是即兴描述，而是填空。五套模板覆盖大多数情况。

**接敌报点**：“位置 + 方向 + 距离 + 目标 + 数量 + 动作 + 意图”。示例：“二队，C4 路口，西北 2 点，150 米，敌方步兵三人，沿墙根向东，我准备开火，谁看侧翼？”

**状态报点**一句话即可：“二队，C3 北门，两人，弹药一半，能守。”

**载具报点**：“车型 + 方向 + 距离 + 运动状态 + 威胁”。示例：“敌方 BTR，东侧公路，300 米，向南，速度不快，可能去 B 点。”

**死亡报点**：“我在哪 + 被什么打 + 敌人大概在哪 + 别怎么救”。示例：“东侧墙角，被窗口机枪打倒，敌人在二楼西侧，别走正面，走地下室。”

**请求支援**：“谁 + 做什么 + 为什么安全 + 对你有什么好处”。示例：“三队，帮我们在远处架一下马路，你们不用动，过街的人头归你们。”

方向用时钟加网格，并说明基准：“以我为基准，2 点”。说“左边”没意义。距离按 50、150、300 米分档：近报房间，中报人数方向，远报“至少几人”或载具。

数量不确定就说下限，“至少三人”比“正好四个”可信。动作要有战术意义：观察、沿墙移动、架枪、修电台。载具先看履带、轮子和炮塔，别一律喊“坦克”。

### 九人小队怎么分工

满编小队可拆成两到三个火力组，常见 3-3-3 或 1-4-4。组长能独立带人绕侧、架枪、侦察和标记。组内用 `V`，组长用 `B` 向队长汇报；情况紧急可直接用 `B` 越级。

目的是减少噪音：三个人看到同一目标，不要同时向队长喊，由组长汇总成一条。队长只听“哪个组、什么目标、什么位置、要什么支援”。

::: takeaway
报点就是填空：位置、方向、距离、目标、数量、动作；死亡报点加一句“别怎么救”，请求支援加一句“对你有什么好处”。
:::

## 频道拥堵时谁该闭嘴

激烈交火时频道里常有三个人同时说话。没有人让路，关键信息就会互相抵消。

第一，`G` 有人通话时，小队语音静默，例外是 P1：敌人已进门、载具已贴脸。

第二，第一个报点的人有话权，后来者只补差异：“补充：多了一辆卡车”“更正：是五个”。“我也看到了”没有价值。

第三，离目标最近的人优先报。倒下和读秒的人少说话，只报关键一句：“他们从北门上来了。”

第四，后勤和争议等交火结束。缺弹、缺医疗、路线分歧都不在枪声中解决，先执行当前命令。

不要替别人报点。看到二队方向有人，先说“二队注意，你们西北 50 米有人”，把信息交给能看到的人。

::: takeaway
频道拥堵时，规则比嗓门有用：队长通话时静默，第一报点人拥有话权，后来者只补差异，争议留到战斗后。
:::

## 决策速查

| 场景 | 快速做法 |
|---|---|
| 身边突然出现敌人 | 按 `V` 喊短句，随即在 `B` 补完整报点 |
| 收到命令 | 先复述四要素，再执行；缺项当场追问 |
| 队长在指挥频道 | 小队语音静默，P1 才打断 |
| 两人同时报同一点 | 最近者说完，另一人只补差异 |
| 要跨队协调 | 报给本队队长，由队长按 `G` 进指挥频道 |
| 听不清命令 | 立刻要求重复，不猜 |
| 自己要换弹或救人 | 先说“换弹”“救人中” |

::: takeaway
速查表解决“先做什么”：先选频道，再套模板，最后确认闭环，顺序不要反。
:::

## 实战案例

::: case 无回声导致的阵地丢失
队长下令：“三队，守住 B 点南侧窗口。”三名队员没有复述就散开：一人去了楼梯，一人上了屋顶，只有一人到南侧窗口。敌人翻窗进入，先打倒窗口的人，再从背后清掉另外两人，B 点两分钟丢失。

复盘时才发现，队长说的是二楼最东侧那扇窗，队员理解成“南侧所有窗口”。若有人复述“守二楼东侧窗口”，歧义当场就会暴露。
:::

::: takeaway
信息要完整、命令要闭环。少一句复述或一个坐标，战术就会变形。
:::

## 常见错误

::: mistake 症状—原因—改法
- 症状：发现敌人只喊“有人”。原因：没有报点模板。改法：按位置、方向、距离、目标、数量、动作填空。
- 症状：收到命令只回“收到”。原因：把确认当礼貌。改法：复述四要素，尤其位置和时间。
- 症状：在附近语音安排整队路线。原因：混淆频道范围。改法：路线进小队语音，附近只喊即时警告。
- 症状：按 `V` 找远处队长，队长没反应。原因：把附近语音当小队语音。改法：远处用 `B`，身边才用 `V`。
- 症状：队长通话时插话。原因：不懂优先级。改法：等转述，除非 P1。
- 症状：听不清却点头。原因：怕显得不懂。改法：说“请重复位置”。
- 症状：把“坦克”挂嘴边，实际是步战车。原因：不认车型。改法：先看履带、轮子和炮塔。
- 症状：三个人同时向队长报同一目标。原因：没有火力组汇总。改法：组内 `V`，组长 `B` 汇报。
:::

::: takeaway
通话错误几乎都能归到三类：信息缺项、频道选错、闭环断掉。改法也固定：套模板、选频道、要回声。
:::

## 实战练习

::: drill 三频道通话一局达标
- 开局按住 `B` 做通话检查：“二队通话检查，收到请复述。”
- 附近语音只说十秒内的事；扔雷、封烟、筒子发射前必须报。
- 收到命令用四要素复述，模糊时间追问成条件。
- 完成 3 次接敌报点，含方向、距离、目标、数量、动作。
- 完成 1 次死亡报点，含“我在哪、被什么打、敌人在哪、别怎么救”。
- 结束或转移时回报：位置加结果加人员状态。

完成标准：命令复述率 100%，没有一次只回“收到”；三次报点至少两次五要素齐全；附近语音没有超过十秒的战术讨论；一次跨队请求由队长转达。局后按“项目、次数、合格次数、改法”记一行。
:::

::: takeaway
练习时不要追求说得更多，而要追求每条都完整、每次都知道谁该说。把让路也当成一项技能来练。
:::
