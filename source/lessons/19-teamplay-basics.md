## 学完能做到什么

- 跟住队长的节奏，保持视觉跟随和合理间距，不挡枪线、不堵门、不脱队。
- 说清自己的掩护方位、距离和负责扇区，让队友知道哪一边有人看。
- 交火时先补火力、再补倒地敌人，不在犹豫中让对手先开枪。
- 按“安全、分类、分工”的顺序救人，避免救援变双杀。
- 在四人小队里知道自己站哪、看哪、倒下后谁来补位。
- 识别协同失败的早期症状，用一句短报把队伍拉回同一节奏。
- 按距离分层保持间距：野外拉开、室内收拢，掩护时从掩体侧面观察。

::: takeaway
协同不是站在一起，而是每个人都知道自己负责哪一段威胁。位置、射界、救援顺序对上了，四个人才像一个整体。
:::

## 跟队：跟的是决策，不是脚印

跟队长的目的，是让队长的决定随时有人接得上：他要停，你停；他要转，你补上新方向的射界；他被击倒，你立刻知道下一步该守哪。单纯踩着队长的脚印走，既挡枪线，也会在遇敌时挤成一团。

基本原则：

- **跟队长距离**：野外和街道保持在队长侧后 5–10 米，室内和门口缩到 2–3 米；始终能看见队长，也让他能用余光看见你。
- **位置**：站在队长侧后方的四点到五点或七点到八点方向，不要正后方贴背，不要走到他枪口正前方。
- **队员之间间距**：野外和街道 10–15 米，城区巷内 5–10 米，室内和门口 2–3 米。手雷杀伤半径 5–7 米，低于 10 米容易被一雷多杀；但也不要拉开到听不见口令、看不见手势。3–5 米只适用于室内贴墙和过门，不是野外默认值。
- **节奏**：队长停，你找掩体并看相反方向；队长转向，你先补扇区再移动，不要同时转身。

过门是跟队最容易出问题的地方。第一人贴墙开门或进角，第二人不要贴着第一人的背挤进门框，应在门外侧后方一步，负责看门内远端和另一个角；第三人看街面，最后一人看背后。门框是火力聚焦点，两个人同时卡在门口，既进不去也退不出来。

队长倒下了，跟队不是原地发呆。第二人立刻接管最近的安全方向，第三人报“队长倒地”，医疗兵根据掩护情况决定是否救。队伍还在，只是指挥换人；队伍散了，才是真的输。

跟队时眼睛还要领先脚步一个掩体：每到一个掩体，先扫下一段的路面、窗口和反斜面，确认“下一脚踩哪”再动。转移时按“头—身—武器”的顺序，头先转向威胁，身体再转成战斗姿势，枪口最后跟上；任何时候枪口都不扫过队友。最常见的倒地不是跑得慢，而是跑到一半才发现前面没有掩体。

![跟队位置与扇区分配示意图](../../assets/images/g4-team-follow.svg)
:::

::: takeaway
跟队要跟住“停、转、看”三个动作，不是跟住脚印。侧后站位、不挡枪线、不堵门，眼睛领先脚步一个掩体，队长倒下也有人接管。
:::

## 掩护：方位、距离、射界

掩护不是“我站在你后面”，而是“我站在能打到威胁、又不挡你枪线的位置”。位置错了，队友不敢开枪；射界没说清，两个人会盯着同一个窗口，背后却没人看。

| 位置 | 与队伍距离 | 负责扇区 | 主要任务 | 常见错误 |
|---|---:|---|---|---|
| 尖兵 | 队首 3–5 米 | 12 点及正前方 | 发现接触、选择掩体 | 走太快，脱离支援 |
| 第二人 | 尖兵侧后 3–5 米 | 2–4 点或 8–10 点 | 补尖兵盲区、准备进门 | 与尖兵看同一方向 |
| 第三人 | 队伍中段 | 另一侧 8–10 点 | 看侧翼、接手伤员 | 挤在中间挡枪线 |
| 后卫 | 队尾 5–10 米 | 6 点及后方 | 防包抄、报背后接触 | 边走边看手机地图 |
| 支援火力 | 侧后 10–20 米 | 10–2 点 | 压制窗口、屋顶、远点 | 站得比尖兵还前 |

表中距离是城区和掩体后的参考值；野外开阔地整体放大到 10–15 米，避免一发迫击炮或手雷同时覆盖两个人。

掩护距离要看武器和地形。步枪手在 3–8 米内能及时补位；机枪或精确射手可以拉开到 10–20 米，用火力覆盖整个正面，但必须有人替他看近距离死角。城市里不要站在队友正后方的门洞里，枪口一摆就挡住；野外不要并排站在同一道矮墙后，敌人一发榴弹就能同时压制两个人。

报掩护要带三件事：我的位置、我负责的扇区、我看到的目标。例如“我在你左后，看二楼左窗，窗内一人”。队友听到这句话，才知道自己可以专心看右边，不必反复回头确认。

掩护不只是站位，还包括“怎么看”和“怎么挪”。观察时从掩体侧面探头，不要从沙袋上沿露出整个头；换位置前先选好下一个掩体，别跑到一半才找墙。掩护者要能看见被掩护者的侧后，而不是贴着他的背——贴背看似亲密，实际既挡退路，也让两个人被同一梭子同时覆盖。

::: takeaway
掩护要报“我在哪、看哪、看到谁”。站侧后、留射界、分扇区，比单纯跟得紧更有用。
:::

## 补枪：先压住，再补掉

交火开始的几秒，最贵的不是枪法，是不犹豫。谁先形成火力，谁就先拿到主动权；全队都等“确认一下”，敌人就已经瞄准好了。

“补枪”有两层：

1. **补火力**：队友开火或换弹时，你立刻接上，不让敌方有抬头窗口。听到“换弹”就接火，不要等队友喊第二遍。
2. **补倒地敌人**：敌人倒地后仍可能被救起，确认没有站立威胁时，补掉他能减少下一次交火的压力。

正确的优先级是：**先打还在开火的威胁，再处理倒地目标，最后才考虑追击**。如果倒地敌人旁边还有一个站着的敌人，先打站着的；为了补一个倒地目标越过掩体，通常是用自己的命换一票。

多人目标同时出现时，顺序不是按远近，而是按威胁：先打正在压制的机枪手，再打医疗兵和队长，最后打普通步枪手。打掉机枪，全组才抬得起头；打掉医疗，倒地的敌人才真正变成减员。

| 场景 | 先做什么 | 不做什么 |
|---|---|---|
| 队友开火后换弹 | 立刻接火，报“我接上” | 等队友被压制才开枪 |
| 敌人倒地，窗口还有一人 | 先压窗口，再补倒地 | 探头越过掩体补人 |
| 敌人倒地，周围无站立威胁 | 快速补掉，防救援 | 站着看，给医疗兵机会 |
| 弹药只剩半个弹匣 | 点射压制，报“弹少” | 继续扫射把弹打空 |
| 敌人正在救倒地队友 | 追两步到掩体边即可 | 全队追进未知走廊 |

补枪也要报结果。“倒了”“补了”“窗口还有一个”比“打中了”有用得多。队友根据这三句话决定是否推进、是否救人、是否需要换弹掩护。

::: takeaway
补枪优先于犹豫：先接火，再补倒地的，别越过掩体追人头。交火里最贵的两秒，就是所有人都在等别人先开枪。
:::

## 救人：安全、分类、分工

救人不是冲过去按互动键，而是一次小型战术动作。顺序错了，救一个倒两个，票数和战斗力一起亏。

**第一步，建立安全。** 先确认还有没有站立敌人在开火、有没有第二个角度没清。有人压制窗口，有人看侧翼，医疗兵才动。没有安全，就先打威胁或投烟，不要用身体去试。

**第二步，分类。** 多人倒地时，按“能恢复队伍能力”排序：

| 倒地人员 | 优先级 | 理由 |
|---|---|---|
| 医疗兵（队里还有第二名医疗兵时） | 最高 | 救起后能继续救别人 |
| 队长 / 通信位 | 高 | 恢复指挥与标记 |
| 反装甲手 | 高 | 敌方载具还在时不可替代 |
| 普通步枪手 | 常规 | 恢复火力与人数 |
| 倒在完全开阔地的人 | 先等火力优势 | 救援路线本身可能送票 |

**第三步，分工。** 一人救，一人看。救人者背对伤员、面向威胁方向蹲下；警戒者站在 3–5 米外，看救人者看不到的那一侧。两个人不要同时挤在伤员身上，既挡枪线，也会被同一发子弹双杀。

只有医疗兵能完成复活，其他兵种能做的是：还击、投烟、报点、把伤员周围的威胁清掉、在安全后帮包扎。不要对着倒地队友按半天互动键，先确认自己是不是能救的人。

成功救起一个人，等于把一次 −1 票改回 0，还多回一杆枪。这个收益比多杀一个敌人更稳定，但前提是救援动作本身不亏票。

::: takeaway
救人的顺序是“先安全、再分类、后分工”。一人救、一人看，医疗兵不排头；没有安全，烟和火力比勇气有用。
:::

## 避免双杀：别让救援变成第二张票

双杀最常见的画面：队友倒在街心，第二个人冲出去拉人，刚蹲下就被同一个窗口打倒；第三个人再去救，第三票也没了。敌人只换了一个弹匣，队伍少了三个人。

避免双杀，记住三句话：

- **先打后救**：能把威胁打哑，就先打；打不哑，就先烟。
- **先掩后救**：伤员在开阔地，先制造遮蔽或换角度，不要沿原路直线冲。
- **先报后救**：喊“H 倒地，街心，窗口还有一人”，让队友知道该压哪、该封哪。

具体动作可以拆成四步：一人持续压制威胁窗口；一人投烟遮断敌人视线；第三人贴掩体接近伤员；第四人留在侧翼看反包抄。人不够时，优先做前两步，等威胁被清掉再救，不要一个人同时干四件事。

还有一种隐性的双杀：救人者蹲在伤员身上，警戒者站在他正后方，两个人重叠成一条线。敌人不需要精准，一梭子就能同时命中。正确站位是救人者与警戒者错开 3–5 米，警戒者能看到救人者的侧后，而不是贴着他的背。

如果伤员倒在敌方火力完全覆盖、没有任何掩体可借的位置，最理性的选择可能是放弃，先撤退重整。听起来冷，但救一个必死的人再赔两个，只会让下一波更打不了。

::: takeaway
双杀不是运气差，是救援路线、站位和顺序同时出错。先压制、再遮断、错开站位，救不了就撤，别用三票证明勇敢。
:::

## 分工与补位：四个人也要有结构

满编小队有分工，四人小队同样要有结构。没有固定岗位，遇敌就会所有人看同一个方向，或者所有人都想当尖兵。

| 岗位 | 谁适合 | 主要职责 | 倒下后谁补 |
|---|---|---|---|
| 队长 / 尖兵 | 熟悉路线、会报点的人 | 选路、下令、第一个进角 | 第二人接管方向，第三人报点 |
| 支援手 | 机枪、自动步枪、弹药足 | 压制窗口和远点，替队伍争取移动时间 | 步枪手接火，别让正面安静 |
| 医疗兵 | 有医疗包、会看伤员位置 | 复活、包扎、投烟 | 其他人先警戒，等第二名医疗兵 |
| 后卫 / 侧翼 | 观察细、耐心的人 | 看背后和侧街，防包抄 | 队尾前一人回头看，别全员转背 |

补位不是抢位置，而是补职责。尖兵倒下，第二人先接正面，不是先跑去救人；医疗兵倒下，最近的人先建立安全，再等另一名医疗兵；队长倒下，事先指定的副手接管报点和路线，其他人继续看自己的扇区。每个人在出发前都该知道“我前面的人倒了，我做什么”。

分工还要和装备匹配。反装甲手不要排第一个进门，医疗兵不要走在队首，机枪手不要挤进最窄的走廊。把合适的人放在合适的位置，比让所有人全能更现实。

::: takeaway
四个人也要有“尖兵、支援、医疗、后卫”的结构。补位补的是职责，不是脚印；先接方向和火力，再谈救人。
:::

## 协同失败：六个常见断点

协同崩掉通常不是因为枪法差，而是某个交接点没人接上。下面六种症状，出现一个就要立刻修正。

| 症状 | 真正原因 | 当场改法 |
|---|---|---|
| 全队盯着同一个窗口 | 没有分扇区 | 指定“你看左窗、我看右窗、后卫看街口” |
| 人越走越挤 | 跟队变成贴背 | 拉开到 3–5 米，门口留出退路 |
| 交火时没人开枪 | 都在等别人先动 | 发现即报，最近的人先压制，其他人接火 |
| 救人变成连续倒地 | 没有安全评估和分工 | 先压制或投烟，一人救一人看 |
| 打到一半全队没弹 | 交火后不补弹 | 每次交火结束先报弹药，再移动 |
| 队长倒地后队伍停摆 | 没有指定副手 | 出发前定好第二指挥，倒地即接管 |

通信也会制造断点。三个人同时讲话，队长什么都听不清；正确的短报是“名字 + 方位 + 情况”，例如“阿明，左后，一人靠近”。报点不要讲故事，先给队伍能行动的信息。

还有一种断点发生在胜利之后：敌人被打退，全队站着换弹、聊天、看击杀，没人看侧翼，结果被绕后一波带走。交火结束不是安全，交火结束只是下一波准备开始。

::: takeaway
协同失败先查三个交接：谁看哪个方向、谁接火力、谁在救人时看背后。三个都有人答，队伍就不会散。
:::

## 从发现到重整：一套可重复的流程

把协同固定成顺序，遇敌时就不需要临场开会。顺序是：发现 → 报点 → 决定 → 掩护 → 交火 → 补枪 → 救人 → 重整。

| 阶段 | 动作 | 完成标准 |
|---|---|---|
| 发现 | 看到人先蹲低、找掩体，不站着确认 | 自己不被第一时间打中 |
| 报点 | 方位、距离、目标、数量、动作 | 五秒内让队友知道威胁在哪 |
| 决定 | 打、藏、绕，三选一 | 三秒内有人给出明确动作 |
| 掩护 | 一人压制，其他人分扇区 | 正面有火，侧翼有人看 |
| 交火 | 短点射，换弹前报“换弹” | 火力不断档，不集体探头 |
| 补枪 | 先站立威胁，再倒地目标 | 没有为了人头越过掩体 |
| 救人 | 安全、分类、一人救一人看 | 救援路线有遮蔽、有警戒 |
| 重整 | 报人数、报弹药、报方向 | 三十秒内恢复可行动状态 |

重整是最容易省略的一步。打完一波，至少做三件事：点人数，确认谁倒了、谁还在；补弹和绷带，别带着空枪走；定方向，下一站去哪、谁走前、谁看后。三十秒能做完，不要拖成三分钟，敌方可能已经在另一个角度架好枪。

流程不是死板套路。敌人已经在十米内，发现和交火可以同时发生；但“报点、掩护、救人、重整”不能全省。省掉哪一个，后面就会用票来补。

::: takeaway
把交火拆成“发现、报点、决定、掩护、交火、补枪、救人、重整”八步。每一步有人负责，协同就从运气变成流程。
:::

## 决策速查

| 场景 | 默认动作 |
|---|---|
| 跟队长移动 | 侧后 3–5 米，能看见队长和被队长看见 |
| 开阔地 | 分批通过，人与人 3–5 米，不整队直线跑 |
| 过门 | 第一人进角，第二人不贴背，最后一人看背后 |
| 队友开火 | 立刻接火或看相反扇区，不站着围观 |
| 敌人倒地 | 先确认站立威胁，再补枪 |
| 队友倒地 | 先安全、再分类、后救人；一人救一人看 |
| 救人路线暴露 | 先烟或压制，救不了就撤 |
| 交火结束 | 补弹、点人、定方向，三十秒重整 |

- 掩护要报位置、扇区、目标三件事。
- 补枪优先于犹豫，但不越过掩体追人头。
- 双杀的解药是错开站位和先打后救。

::: takeaway
速查表解决“下一步做什么”。真正常用的只有三句：我看哪、谁接火、救人时谁看背后。
:::

## 实战案例

四人小队沿村道搜索，队长阿明在队首，支援手小周在其左后，医疗兵阿杰在中间，后卫老陈看背后。走到一处院墙缺口，院内突然开火：队员小周被击倒在街心，敌方一人躲在矮墙后倒地，另一人仍在二楼窗口点射。

第一秒，阿杰没有冲出去。他贴墙报：“小周倒地，院口 15 米，二楼窗口一人，矮墙后一人倒地。”老陈立刻转身看后街，防止这是诱敌。阿明根据弹道判断出窗口位置，短点射压住二楼，阿杰投烟遮断院内视线。

第三秒，二楼敌人换弹，火力停顿。阿明报“敌换弹”，继续压住窗口；老陈报“后街清”，转看院墙缺口。阿杰贴墙移动到矮墙侧，先确认倒地敌人没有威胁，再补掉，防止敌方医疗兵救人。整个过程中，没有人越过院口去追二楼。

第八秒，烟幕展开，阿杰贴墙移动到小周身边，在墙后死角开始复活；老陈移到阿杰侧后警戒；阿明继续看二楼楼梯口。敌方投来手雷，落在院口，没人受伤，因为队伍没有挤在门口。

第十五秒，小周被救起，立刻报“还有半血、没绷带”。阿杰给他包扎，阿明报“窗口安静，院内可能还有一人”。全队没有急着进院，先补弹、点人数，再决定从侧墙缺口进，而不是从敌人预设的正面门口进。

复盘：如果阿杰第一秒冲出去救，二楼窗口还在开火，他会在街心成为第二个倒地目标；如果老陈跟着去看窗口，后街无人，敌方绕后就是第三个。真正救下小周的，不是医疗包，而是“阿明压制、阿杰投烟、老陈看后、没有人挤在门口”这四件事同时发生。

票账也清楚：小周被救起，−1 票没有发生；补掉倒地敌人，减少一次被救起的可能；全队零阵亡完成救援，比“冲过去换一个敌人”更赚。

::: takeaway
救人成功靠的是先建立火力优势，再让医疗兵在遮蔽下动手。四个人各看一段，救援才不会变成连续倒地。
:::

## 常见错误

| 症状 | 原因 | 改法 |
|---|---|---|
| 贴着队长背走，队长一停就撞上 | 把跟随当成贴人 | 退到侧后 3–5 米，留出枪线和退路 |
| 遇敌后全队看同一个方向 | 没有分扇区 | 出发前指定左右与后方负责人 |
| 队友换弹时正面突然安静 | 没人接火 | 听到“换弹”立即接上，报“我接” |
| 为了补倒地敌人越过掩体 | 只想着人头 | 先打站立威胁，补枪不离开掩体 |
| 救人时两个人叠在一起 | 没有分工 | 一人救一人看，警戒者错开 3–5 米 |
| 救不了还继续派人 | 沉没成本与面子 | 先烟、先压制，仍不安全就撤 |
| 交火后原地聊天 | 把停火当安全 | 三十秒内补弹、点人、定方向 |
| 队长倒地后全员停摆 | 没有指定副手 | 出发前定第二指挥，倒地即接管 |

::: takeaway
这些错误的共同点是“所有人做同一件事”。协同要的是分工：有人打、有人看、有人救、有人准备下一步。
:::

## 实战练习

**练习一：跟队不挡线。** 选一局，全程跟在队长侧后 3–5 米，做到三次：队长停你找掩体、队长转你补扇区、过门不贴背。结束后让队长评价一次“有没有挡枪线”。被指出一次就重练一局。

**练习二：扇区报点。** 每次进入新地形，主动报一句“我看右前，谁看左后”。一局至少报五次，确保每个方向都有人认领。队友重复或漏报，当场修正。

**练习三：补枪与换弹。** 交火中至少三次在队友换弹时接火，并报“我接上”；至少两次在确认安全后补掉倒地敌人。记录有没有因为补枪越过掩体而倒地。

**练习四：安全救人。** 完成三次救援，每次都做全四步：报点、建立安全、一人救一人看、救后补弹。三次里不允许出现救援者倒地；出现一次，下一次先投烟再动。

**练习五：三十秒重整。** 每波交火后计时三十秒，完成点人数、补弹、定方向三件事。一局至少做四次，超时或漏项就记下来，下一波改进。

完成标准：跟队评价无挡线，扇区报点 5 次，换弹接火 3 次，安全救援 3 次且救援者零倒地，三十秒重整 4 次。

::: takeaway
协同是练出来的动作序列，不是喊出来的态度。每次只盯一个环节，练到不用想，再叠加下一个。
:::

## 自检 3 问

1. 跟队长时站什么位置、保持多远？过门时第二个人应该做什么？
2. 队友开火后换弹、敌人倒地、队友倒地同时发生，你的动作优先级是什么？
3. 救人前必须确认哪三件事？怎样站位才能避免双杀？

::: takeaway
三问能答且能在实战里做出来，说明你已经具备基础协同：跟得住、看得住、救得稳，可以进入小队长职责的学习。
:::
