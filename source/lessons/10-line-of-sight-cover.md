## 学完能做到什么

- 分清视线、射线和爆炸掩护，知道什么能挡眼睛、什么能挡子弹、什么能挡破片。
- 按材质判断一堵墙到底能挡什么，不再把木板、铁皮、树丛当成万能掩体。
- 识别窗口、墙角、山脊的剪影风险，知道站哪里、露多少、待多久。
- 区分观察位与射击位，打完就换，不在同一个位置连续开火。
- 用主威胁方向管理路线，让掩体始终挡在你和敌人之间。
- 在任何位置停留前，用三问快速判断“我会不会被看见、有没有退路”。

::: takeaway
掩护不是“有东西挡着”这么简单，而是同时算清视线、弹道和爆炸三条线，再决定站哪、露多少、待多久。
:::

## 视线、射线与爆炸掩护的区别

新人常把“挡住视线”和“挡住子弹”混为一谈，这是被击毙的主要原因。三件事要分开看：

视线是一条双向的线。你能看见敌人，敌人通常也能看见你；你躲在树丛后看不见敌人，敌人也可能看不见你。视线被挡住，只说明“看不见”，不说明“打不到”。

射线是子弹实际飞过的路径。它只认物理遮挡：混凝土、砖石、厚土、载具车体挡得住，木板、铁皮、灌木挡不住。敌人看不见你，仍然可以朝你大致所在的位置扫射，子弹会穿过视觉掩体。

爆炸是另一套逻辑。手雷、迫击炮、火箭弹的伤害来自破片和冲击波，会从上方落下、从侧面绕进掩体，也会把墙后的空间变成杀伤区。能挡直射的矮墙，未必能挡落在背后的迫击炮；能挡视线的树冠，更挡不住空爆。

| 掩护类型 | 挡什么 | 典型例子 | 挡不住什么 | 正确用法 |
|---|---|---|---|---|
| 视线掩护 | 遮挡观察 | 树丛、高草、伪装网、薄帘 | 子弹、爆炸 | 临时隐蔽、转移前遮蔽 |
| 射线掩护 | 挡直射弹道 | 混凝土墙、砖墙、土坡、载具 | 绕后火力、爆炸破片 | 架枪、救治、长期停留 |
| 爆炸掩护 | 挡破片与冲击 | 地下室、厚建筑底层、深沟 | 直射、空爆、灌入 | 防炮、防手雷、集结 |
| 完全掩护 | 三者都挡 | 厚混凝土楼、地下工事、大土丘 | 被绕后、被包围 | 兵站、电台、指挥位 |

判断顺序是：先问“敌人能不能看见我”，再问“看见之后子弹能不能打到我”，最后问“如果挨炸，我有没有地方躲”。三个问题都过关，才算真正安全。只过第一关，是“看不见但打得着”；只过第二关，是“打得着但看得见”；只过第三关，是“防炮但不防枪”。

爆炸还有三条进入路径，选位置时要分别堵住。第一条是上方：迫击炮、空爆弹从头顶落下，屋顶和树冠挡不住，只有坚固的楼层或地下空间能接住。第二条是侧面：手雷从门洞、窗口、墙角滚进来或弹进来，贴墙站反而容易被破片扫到。第三条是地面：手雷落地后滚动，站在开阔地面的人没有遮挡。对付这三条，最实用的顺序是先进室内、再离开门口和窗口、最后找有顶且能转身的位置。

![视线射线与爆炸掩护](../../assets/images/los-cover.svg)

::: takeaway
视线掩护挡看不挡枪，射线掩护挡枪不挡绕后，爆炸掩护挡破片不挡直射；三关都过才算安全，爆炸还要分别防上方、侧面和地面。
:::

## 一堵墙到底能挡什么

同样是“墙”，材质不同，效果差很远。判断一堵墙，看三点：材料密度、厚度、有没有缝隙。密度越高、越厚、越完整，越接近完全掩护。

| 材质 | 挡视线 | 挡直射 | 挡爆炸 | 备注 |
|---|---|---|---|---|
| 混凝土承重墙 | 是 | 是 | 是 | 最可靠，优先选 |
| 砖石墙 | 是 | 是 | 部分 | 薄墙可能被重武器打穿 |
| 沙袋、HESCO | 是 | 是 | 部分 | 沙袋挡弹不挡破片，HESCO 更完整 |
| 载具车体 | 是 | 是 | 部分 | 挡小口径，反坦克武器可击穿 |
| 土坡、岩石 | 是 | 是 | 是 | 厚度足够时最稳，注意头顶 |
| 木板、铁皮 | 部分 | 否 | 否 | 只能遮蔽视线，别当掩体 |
| 树丛、高草 | 是 | 否 | 否 | 埋伏可以，对枪不行 |
| 矮墙 | 蹲下是 | 蹲下是 | 否 | 站起就露上半身，手雷能越过 |

几个容易忽略的细节：

第一，墙有“遮挡角”。一堵两米高的墙，只有紧贴它的一小片区域被完全遮住；离墙越远，敌人越能从侧面看到你。贴墙不等于安全，站在墙后 1 米左右、利用墙角或墙垛，通常比整个人贴上去更好。

第二，墙上的洞会漏视线。门洞、窗口、弹孔、墙根缝隙，都是敌人观察你的通道。你躲在墙后，不代表墙后是黑的；敌人可能正通过一个拳头大的洞看着你。

第三，墙会被炸开。可破坏的墙体被坦克炮、火箭弹、C4 打中后会开出通道，原来的射线掩护立刻失效。长期据点要选不可破坏的厚建筑，临时掩体要准备备用位置。

第四，矮墙只挡下半身。蹲在矮墙后，头和高位射击的子弹仍然够得到你；站起来开枪，上半身全部暴露。矮墙适合蹲姿短停，不适合长时间架枪。

### 面对载具，墙要升几级

上面的材质表只对步兵轻武器成立。同一个位置，面对载具时可能要连升两级，甚至完全不能待。

| 对手 | 主要威胁 | 还能用的位置 | 已经没用的位置 |
|---|---|---|---|
| 电摇侦察车 | 重机枪 | 防爆墙、水泥墙、HESCO、厚土坡、车体 | 木板、铁皮、树丛、普通矮墙 |
| 轮式步战车 | 榴弹、破甲弹 | 全封闭厚建筑、地下室、深沟 | 沙袋、矮墙、窗口、门洞 |
| 履带式步战车 | 机炮、榴弹、反坦克导弹 | 厚建筑地下层、反斜面、坚固地形 | 普通砖墙、屋顶、载具后方 |
| 坦克 | 主炮、同轴机枪 | 厚土工事、地下层、反斜面 | 任何临时工事、薄墙、街垒 |

差别不只在“穿不穿”，还在“炸不炸”。重机枪只认遮挡，你躲在防爆墙后就能活；车载榴弹会把破片从窗口、门洞和墙角灌进来，沙袋后面并不安全；坦克主炮即使没打穿墙，震塌和冲击波也能杀伤墙后的人。听到履带声，先别问“这墙厚不厚”，先问“对面是什么车”，再决定是进地下室、下反斜面，还是干脆放弃这个位置。

::: takeaway
墙要按“密度、厚度、缝隙”三项检查；贴墙不如离墙一米用角，矮墙只护下半身；面对载具还要按车型升级掩体，别拿步枪掩体挡车载榴弹。
:::

## 窗口、墙角、山脊的角度风险

### 窗口：站在内侧，不站边缘

窗口是高风险位置，因为窗口边缘就是剪影线。站在窗边，你的头和肩膀会在外部背景上勾出清晰轮廓，远处的敌人很容易捕捉。正确做法是站在窗口内侧 1 米以外，用侧墙挡住身体，只伸出枪口观察和开火。

窗口越宽，你能看到的角度越大，敌人能看见你的角度也越大。宽窗适合快速扫一眼，不适合久留；窄窗或半掩窗更安全。观察时用“切角”：从窗框一侧开始，每次横移 10–15 度，逐步扩大视野，不要一次把整个头探到窗口正中。

开火后立刻后撤 1–2 步，离开窗口线。敌人会根据枪口火光和弹道反推你的位置，下一发可能就打在你刚才站的地方。同一个窗口最多打两轮，第三轮要换窗口或换楼层。

### 墙角：探头不超过两秒

墙角是双刃剑。贴着墙角可以保护身体，但探头的一瞬间就是剪影。正确做法是离墙 0.5–1 米，用“切角”逐步绕出：先露眼睛，再露肩，最后露枪，每一步都确认没有敌人盯着这个角。

每次探头控制在 2 秒以内，看完就回。不要在同一个墙角连续探头三次以上；敌人会预瞄你的出现位置，第三次探头往往就是挨枪的时候。枪口不要先伸出去，枪管和火光会提前暴露你的意图。

墙角还有“死亡角”：贴墙太近，视野被墙挡住一大半；离墙稍远，视野变大，但暴露面也变大。折中位置是离墙约一个身位，既能用墙挡身体，又能看到墙外的两侧。

### 山脊：站在脊线下方

山脊是天然剪影位。站在脊线上，你的身体会在天际线上清晰可见，另一侧的敌人不需要精确瞄准就能击中。正确位置是山脊下方 10–20 米的肩部或反斜面，身体低于脊线，只把头探到刚好能观察的高度。

越脊之前先低姿观察，不要站着走过去。可以蹲在脊线下方，慢慢抬头，直到眼睛刚好看过脊线；发现目标后不要站起来，保持低姿报点或开火。需要转移时，沿脊线平行方向移动，不要直接翻过脊线。

山脊上的孤树、大石头、围墙会吸引火力，敌人会默认有人躲在那里。不要选这些“显眼地标”当观察位，选它们侧后方 10–20 米、地形略有起伏的位置。

屋顶和二楼窗口同理：有掩体的内侧可以待，开阔的屋顶边缘、没有遮挡的窗边不要久留。

::: takeaway
窗口站内侧一米、墙角探头不过两秒、山脊不过脊线；三个位置共同的风险都是“轮廓被背景衬出来”。
:::

## 硬掩体与软掩体怎么选

硬掩体挡子弹，软掩体只挡视线。选择哪一种，先问“我要在这里待多久”。

| 停留时间 | 任务 | 需要什么 | 例子 |
|---|---|---|---|
| 3 秒以内 | 快速通过 | 软掩体即可 | 树丛、墙角、矮墙后 |
| 3–10 秒 | 短暂观察、报点 | 硬掩体边缘 | 砖墙转角、载具侧后 |
| 10 秒以上 | 架枪、救治、装弹 | 硬掩体加退路 | 混凝土墙后、土坡后 |
| 数分钟 | 放兵站、电台、指挥 | 完全掩护加室内 | 地下室、厚建筑底层 |

软掩体的价值在于“不被看见”，不在于“不被击中”。用它完成转移、接近、埋伏可以；用它架枪、救治、久留不行。敌人一旦发现软掩体后面有人，直接穿射就能解决。

硬掩体也不是360度安全。它只挡住一个方向，侧翼和背后仍然开放。选硬掩体时同时看三件事：正面能不能挡住已知威胁、侧面有没有敌人能绕、背后有没有退路。三者缺一，这个掩体就只能短停。

还有一个常见误区：把“子弹打不穿”当成“爆炸也炸不到”。沙袋、矮墙、载具挡得住直射，却挡不住落在背后的迫击炮和滚进来的手雷。防炮要另找地下室、厚建筑底层或深沟，别指望沙袋。

::: takeaway
按停留时间选掩体：三秒内软掩体够用，十秒以上必须硬掩体加退路；硬掩体只护一个方向，侧后要自己看。
:::

## 观察位与射击位必须分开

观察位和射击位是两个不同的位置，混在一起用，等于把自己的眼睛和枪口同时卖给敌人。

观察位在掩体后 2–5 米，利用缝隙、侧向角度或潜望观察。它的任务只有一个：看。观察位尽量不露枪口、不开火，暴露的只有一小部分头部。发现目标后，先用语音报点，再决定要不要打。

观察位选址看三个条件：看得见、藏得住、退得快。看得见是指视野覆盖主威胁方向；藏得住是指从敌人方向看过来，你不在剪影上；退得快是指被发现后能在三秒内换到下一个位置。三个条件通常不能同时满足，次外圈往往是最平衡的选择：比最外圈少一点视野，但不容易被第一时间发现；比最内圈多一点信息，不会把自己关成瞎子。观察位也不要正对窗口或门口，用墙缝、窗框侧角和阴影，露出的面积越小越好。

射击位在掩体边缘，有射界、有依托。它的任务是短促输出：开火 3–5 发，或 2–3 个点射，然后立刻退回观察位或横向换位。同一个射击位不要连续使用超过 10 秒，尤其不要在同一位置打完整一梭子。

两个位置之间相距 3–10 米，形成“观察—射击—转移”的循环：

1. 在观察位发现目标，报点，判断威胁。
2. 横移到射击位，短点射，打掉或压制目标。
3. 立刻退回观察位，或换到下一个射击位。
4. 如果目标没死，换角度再打，不回到刚才的射击位。

机枪和狙击手更需要备用射击位。打一梭子换一个位置，敌人就很难用反狙击或迫击炮锁定你。反过来，如果你在同一个窗口打了半分钟，敌人就算没看见你，也能根据弹道和火光把炮弹送到窗口。

::: takeaway
观察位只用眼睛，射击位只短促开火；两个位置隔 3–10 米，打几发就换，别让一个洞同时承担看和打。
:::

## 用威胁方向管理行进路线

行进时不要平均地防四面，而是先定主威胁方向，再把大部分注意力、掩体和队形朝向它。

把周围分成三个扇区：

- 主威胁扇区：已知敌人、敌方占点、最近交火方向，约 60–90 度。大部分枪口和观察都朝这里。
- 次威胁扇区：可能出现绕后或增援的方向，约 120 度。安排一人或余光兼顾。
- 安全区：背后和侧后，通常是自己来的方向。仍需偶尔回头看，但不能因此忽略主威胁。

路线选择遵循一条原则：让掩体始终位于你和主威胁之间。沿建筑背向敌人的一侧走，沿山脊的反斜面走，沿林线远离敌方的一侧走。不要沿着敌人可能观察的正面街道平行移动，那等于在枪线旁边散步。

过开阔地时，路线尽量垂直于敌方枪线，用最短的暴露距离穿过去。平行于枪线跑，敌人有更长的射击窗口；垂直于枪线跑，敌人需要不断修正提前量。跑之前选定下一个掩体，跑的过程中不观察、不开枪，到了再停。

遇袭时的顺序是：先退到掩体，再还击，最后报点。原地趴下只在完全没有掩体时使用，趴下能降低剪影，但不能替代掩体。如果敌人已经锁定你的位置，趴着不动只会等来手雷。

小队行进时给每个人分扇区：尖兵看前，队长看全局，后卫看侧后。不要所有人都盯着同一个方向，也不要所有人都低头看地图。载具行进时车体朝向主威胁，下车后以车体为掩体，别站在车头前方。

::: takeaway
先定主威胁，再让掩体挡在你和它之间；过开阔地垂直于枪线，遇袭先退再打，队形按扇区分工。
:::

## 我能被看见吗：快速自检

在任何位置停留前，问自己三个问题：

第一，我处于剪影位置吗？天际线、窗口边缘、山脊顶部、开阔地带中央，都是背景会把轮廓衬出来的地方。站上去之前先想：从敌人方向看，我的头是不是高过周围地形。

第二，敌人有没有视线直通我？已知敌人位置、敌方占点、可能有人观察的高地，只要有一处能直接看到你，你就在危险中。要么移动，要么用硬掩体断绝视线。

第三，我有退路吗？如果现在被发现，能不能在三秒内退到下一个掩体？没有退路的位置不要长期占据，尤其是单出口建筑、死胡同、桥中央。

三个问题答案都是否定的，这个位置可以短暂停留；任何一个答案是肯定的，立即调整。如果必须停留超过 10 秒，再加一问：这里是硬掩体吗？软掩体只适合三秒以内的通过，不适合久留。

::: takeaway
停留前问三句：是不是剪影、敌人有没有视线、有没有退路；要待超过十秒，再确认是不是硬掩体。
:::

## 隐蔽不是躲起来：降低与背景的差异

伪装的目标不是“看不见”，而是“看起来不像目标”。人眼先抓的是差异：颜色不一样、亮度不一样、在动、形状太规则、有反光。你不需要把自己变成隐形人，只需要把这几项差异一项项压下去。

| 差异 | 你身上的表现 | 怎么降低 |
|---|---|---|
| 颜色 | 深色衣服贴在浅色墙上、迷彩与地面不搭 | 站到同色背景前，利用阴影和背光 |
| 亮度 | 站在明亮的窗口、雪地、天空前 | 退到暗处，别让自己成为剪影 |
| 活动 | 匀速跑、频繁探头、原地转身 | 在掩体之间短促移动，到了就停 |
| 形状 | 枪管、天线、背包、头盔轮廓伸出掩体 | 收枪、压低、只露必要部分 |
| 反光 | 瞄具、车窗、金属件反光 | 避免正对阳光，别在窗口正中架枪 |

最容易被忽略的是“活动”。一个站着不动的人，在远处比一个跑动的人更难发现；但一个站在开阔地不动的人，轮廓仍然会被背景衬出来。所以正确做法不是“一直不动”，而是“在该动的时候快速动，在该停的时候完全停”：从一块阴影冲到下一块阴影，到了就贴住、收枪、观察，不要一边走一边看地图。

伪装也不是一劳永逸。你开一枪，枪口火光和弹道就把位置卖了；你跑过一片空地，草地和尘土也会留下痕迹。视觉掩体能争取的是几秒钟，不是永久安全。开火后要转移，转移后要重新伪装，别在同一个“看起来很适合藏”的位置连续使用。

更高一层的用法是制造假目标。在显眼的窗口、路口或高地放一顶头盔、一段伪装网、一堆轮胎，让敌人把注意力放在那里；真观察位放在侧后方十到二十米，利用敌人“先看显眼处”的习惯。假目标不需要复杂，只要比真位置更像有人就行。

::: takeaway
伪装是压差异：颜色、亮度、活动、形状、反光，一项项降低；视觉掩体只争取几秒，开火后必须转移，显眼处可以放假目标。
:::

## 决策速查

- 视线掩护挡看不挡枪，射线掩护挡枪不挡绕后，爆炸掩护挡破片不挡直射。
- 墙看密度、厚度、缝隙；贴墙不如离墙一米用角。
- 窗口站内侧一米，墙角探头不过两秒，山脊不过脊线。
- 三秒内通过用软掩体，十秒以上用硬掩体加退路。
- 观察位只看不打，射击位打几发就换，两者隔 3–10 米。
- 行进让掩体挡在主威胁和你之间，过开阔地垂直于枪线。
- 停留三问：剪影吗、有视线吗、有退路吗。

::: takeaway
速查的关键不是背句子，而是养成顺序：先定威胁方向，再选掩体，最后决定露多少、待多久。
:::

## 实战案例

::: case 窗口边缘的剪影
- **局面**：阿拉曼一栋二层楼，小队需要观察街对面的敌人动向。
- **判断**：一名队员站在二楼窗口边缘，身体整个露在窗框外，背景是明亮的天空。
- **动作**：敌方狙击手从远处一枪击中他的头部；另一名队友站在窗口内侧约 1 米处，只把枪口和半个头探出，始终没被击中。
- **结果**：小队失去一人，但其余人靠内侧观察位继续报点，直到烟雾掩护转移。
- **复盘**：窗口边缘是剪影线，站内侧、只露枪口，才能把“观察”变成“安全观察”。
:::

::: case 同一个墙角探头三次
- **局面**：城市巷战，队员在十字路口墙角与对面二楼敌人对枪。
- **判断**：前两次探头都只看到一眼就缩回，队员认为“敌人没发现我”，第三次从同一位置探出。
- **动作**：敌人早已预瞄墙角，第三次探头时直接命中；队员倒地后，队友不得不冒险救人。
- **结果**：一个墙角换掉两条命，进攻节奏被打断。
- **复盘**：同一位置重复探头，等于告诉敌人你下一次会从哪里出现；两次不成就换角或换楼。
:::

::: case 沙袋后面的迫击炮
- **局面**：小队在村口用沙袋堆了一个机枪位，压制对面步兵，效果很好。
- **判断**：大家认为沙袋能挡子弹，就把它当成固定阵地，连续待了三四分钟。
- **动作**：敌方观察员报出位置，迫击炮两发落点修正后命中沙袋后方，机枪手和弹药手一起倒地。
- **结果**：阵地丢失，村口火力出现空缺，敌人趁机推进。
- **复盘**：沙袋挡直射，不挡落在背后的破片；固定火力点最多打一轮就要换，防炮要另找厚建筑或地下室。
:::

::: takeaway
三个案例对应三种误判：把窗口边缘当观察位、把同一墙角当安全角、把沙袋当防炮工事；改法都是“换位置、换角度、换掩体类型”。
:::

## 常见错误

| 症状 | 原因 | 改法 |
|---|---|---|
| 躲在树丛后被子弹打穿 | 把视线掩护当射线掩护 | 树丛只用于隐蔽，交火必须找硬掩体 |
| 站在窗口边缘观察被狙 | 身体高出窗框形成剪影 | 站到窗口内侧 1 米，只露枪口 |
| 在山脊线上架枪被远处击中 | 身体超过脊线，背景干净 | 下移到肩部或反斜面，保持低姿 |
| 同一墙角连续探头三次被预瞄 | 位置固定、节奏可预测 | 两次不成就换角、换楼或换窗口 |
| 在开阔地直线跑 100 米被载具扫死 | 暴露时间太长、路线平行枪线 | 拆成 20–50 米一段，垂直于枪线穿越 |
| 沙袋后久留被迫击炮覆盖 | 把挡弹掩体当防炮掩体 | 打一轮就换，防炮找地下室或厚建筑 |
| 观察位开枪后不换位 | 看和打混在一个点 | 观察位只看，射击位打几发就撤 |

这些错误的共同点是“只算了一条线”：只算视线，或只算弹道，或只算爆炸。三线同时算，再决定站哪里，生存率会明显提高。

::: takeaway
错误看似五花八门，根源都是漏算：漏算弹道就信树丛，漏算剪影就站窗口，漏算爆炸就守沙袋。
:::

## 实战练习

::: drill 单局掩护与角度达标
- 一局内识别并使用至少 3 个硬掩体：混凝土墙、砖墙、土坡、载具车体。
- 在窗口、墙角、山脊三类位置各做一次正确示范：窗口站内侧、墙角探头不超过两秒、山脊不过脊线。
- 每次开火后转移到另一个位置，同一个射击位不连续使用超过 10 秒。
- 每次停留前默念三问，至少记录两次“因为答案肯定而放弃的位置”。
- 完成标准：硬掩体 3 个以上，三类位置各示范一次，开火后转移 3 次以上。
:::

::: drill 威胁方向行军
- 选一段 200 米以上的路线，出发前在地图上标出主威胁扇区和次威胁扇区。
- 全程让掩体位于自己和主威胁之间，遇到开阔地垂直于枪线通过。
- 每到一个掩体，用 3 秒确认正面、侧面、背后三个方向，再继续。
- 中途让队友故意从一个侧翼方向接近，检验你是否注意到次威胁扇区。
- 完成标准：路线全程有掩体可依，开阔地暴露不超过 3 秒，侧翼接近能在 5 秒内被发现。
:::

::: takeaway
练习不是找“最硬的墙”，而是练“看多久、露多少、什么时候换”；把这三个量控制住，掩护才有意义。
:::

## 自检 3 问

1. 视线掩护、射线掩护、爆炸掩护分别能挡什么，各举一个例子？
2. 窗口、墙角、山脊的角度风险分别是什么，正确的站法是什么？
3. 观察位和射击位有什么区别，为什么要相隔 3–10 米？

::: takeaway
三问答得出来，说明你已经在用“视线、弹道、爆炸”三条线判断位置，而不是只看眼前有没有东西挡着。
:::
