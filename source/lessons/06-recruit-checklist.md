## 学完能做到什么

- 用六类基础动作的及格线找出最不稳的一项。
- 按“一局一个主题”训练，把动作重复到不用想。
- 用次数、秒数、米数判断达标，并知道下一课补什么。
- 能通过新兵营五个站点的考核，也能答出常考的机制数字。
- 知道哪些服务器规矩和社区底线不能碰。

::: takeaway
训练不是把每局都打满，而是每局留下一个能复用的动作。清单只是帮你找到下一个缺口。
:::

## 基础动作清单：六类动作的及格线

第一阶要稳的不是枪法上限，而是六类动作的下限。

| 类别 | 及格线 | 不合格表现 |
|---|---|---|
| 移动 | 掩体间冲刺不超过 5 秒，跟队长不超过 15 米 | 横穿 30 米开阔地，脱离队伍 30 秒 |
| 射击 | 100 米人形靶 5 发 3 中，用 3–5 发点射 | 全程扫射，移动中乱扣扳机 |
| 换弹 | 弹匣剩三分之一就换，在掩体后完成 | 打空才换，站在开阔地换弹 |
| 医疗 | 受伤先找掩体再按 `5`，止血后才移动 | 原地站着包扎，血没止就冲锋 |
| 报点 | 8 秒内说出方向、距离、目标、数量、动作 | 只喊“有人”，不说位置 |
| 复活 | 只选绿色复活点，复活后 15 秒内归队 | 点红色兵站，复活后独自乱走 |

移动和复活决定能不能留在场上，射击和换弹决定交火效率，医疗决定有没有下一回合，报点决定小队能不能共享信息。任何一项掉链子，其他项的优势都会被抵消。

先测再练：打一局按表打勾，找出没做到的两项，不要六项一起改。

::: takeaway
六类动作各有一条最低线。先找出掉链子的那一项，再决定这周练什么，不要平均用力。
:::

## 一局只练一个动作

每局都想把所有动作做好，结果每个动作只做一两次，这是最常见的失败。正确做法是给每局设一个主题。

| 局次 | 主题 | 本局唯一指标 | 暂时不管 |
|---|---|---|---|
| 1 | 报点 | 发现敌人必报，五要素齐全 | 击杀数、占点 |
| 2 | 复活 | 只选绿色点，15 秒归队 | 战绩 |
| 3 | 换弹 | 空枪次数为零 | 命中率 |
| 4 | 跟队 | 脱离队长不超过 15 米 | 个人击杀 |
| 5 | 复述 | 每条命令都复述 | 推进速度 |

一个主题重复 5–10 局，动作才会进入下意识。主题最多两个，且要分主次：报点为主，换弹顺带检查。三个以上同时练，注意力会被撕碎。

训练局不追击杀、不抢点、不为输赢换兵种，只记录主题动作做了几次、哪次失败。局后一分钟回答：练了什么、做到几次、下次改哪个细节。

![新兵训练闭环](../../assets/images/g1-training-loop.svg)
:::

::: takeaway
一局一个主题，重复 5–10 局。训练局只看主题动作的次数和质量，不用击杀数打分。
:::

## 可观察的完成标准

“我感觉做到了”不能作为依据。标准要能被计数、计时或由队友验证。

| 动作 | 指标 | 达标线 | 验证 |
|---|---|---|---|
| 报点 | 五要素是否齐全 | 3 次中至少 2 次 | 队友复述确认 |
| 换弹 | 交火中空枪次数 | 0 次 | 自己数，队友提醒 |
| 复活 | 选红色点次数 | 0 次 | 部署界面记忆 |
| 跟队 | 脱离超过 15 秒次数 | 每局不超过 2 次 | 小地图观察 |
| 复述 | 收到命令后复述比例 | 100% | 队长确认 |

判定写成“合格次数除以总次数”，例如“报点 4 次，齐全 3 次，达标线 2 次，合格”。不要写“报点还行”，那无法比较下一局。

时间和距离用可感知的参照：5 秒大约是从掩体冲到下一个墙角，15 米大约是两辆并排卡车，8 秒大约是一句完整报点加一次呼吸。

::: takeaway
标准要能被数出来：几次、几秒、多少米、是否 100%。写成“合格次数除以总次数”，下一局才有比较。
:::

## 自检表怎么填

每局结束填一行，不要攒到周末。表格只留五列。

| 项目 | 目标 | 本局结果 | 判定 | 下局改法 |
|---|---|---|---|---|
| 报点 | 3 次五要素 | 4 次，齐全 2 次 | 不合格 | 报前默念方向距离数量 |
| 换弹 | 空枪 0 次 | 空枪 2 次 | 不合格 | 弹匣过半就找掩体换 |
| 复活 | 全绿色 | 3 次全绿 | 合格 | 保持，复活先看队长位置 |
| 复述 | 100% | 3 条中 2 条 | 不合格 | 先按语音键再想内容 |

判定用三档：2 分稳定做到，1 分做过但不稳，0 分没做到。一周统计，总分 30 分以上基础扎实，20–29 分还有明显短板，20 分以下先把主题减到一个。

只写事实，不写情绪。“队友太菜”不是结果，“报点 2 次、齐全 0 次”才是结果。某项连续三局 0 分，回对应课程重学动作要领，不要靠场次硬堆。

::: takeaway
每局一行，只写事实和三档判定。连续三局 0 分的项目回课程重学，不靠场次硬堆。
:::

## 新兵营考核要点

考核不是选拔，而是确认六类动作能在压力下做出来。五个站点，每站只考一件事。

| 站点 | 内容 | 合格线 | 常见扣分 |
|---|---|---|---|
| 集结 | 部署后到队长 20 米内 | 90 秒内 | 选错复活点、路上捡装备 |
| 射击 | 100 米人形靶点射 | 5 发 3 中，换弹 2 秒内 | 扫射、站着换弹 |
| 医疗 | 止血、自救、救队友 | 30 秒内自救，先清场 | 不找掩体、原地拉人 |
| 通话 | 报 3 个点、复述 2 条命令 | 2 条齐全，复述全对 | 只说“有人”、漏位置 |
| 复活 | 连续三次部署 | 3 次全绿，20 秒归队 | 点红色兵站、复活单走 |

考核官只看行为，不听解释。射击两次机会，医疗一次，因为实战救人没有重来。通话随机指方向，要求 8 秒内说完。

三项不合格回训练局；两项不合格可带练，下周复测。标准不是卡人，而是避免带着短板进第二阶。

### 笔试常考的十二个数

| 项目 | 数值 |
|---|---|
| FOB 电台被毁 | −20 票；自己拆不扣 |
| FOB 电台间距 / 建造半径 | 400 米 / 150 米 |
| HAB 兵站造价 | 500 建材 |
| HAB 基础复活 / 建好或修复后 | 45 秒 / 30 秒 |
| HAB 压制起点 | 2 名敌人 20 米；每多 1 人加 10 米，最高 9 人 90 米 |
| HAB 解除压制后恢复 | 30 秒 |
| 队包被踩 / 禁放 | 敌人 30 米消失 / 50 米放不下来（失败冷却 120 秒） |
| 队包波次 / 基础复活 | 60 秒一波 / 30 秒 |
| 队包放置冷却 | 150 秒 |
| FOB 流血 | 75 秒，修复到 50 HP 可救回 |
| 倒地黑白屏 | 约 60 秒，再中弹直接死亡 |
| 票数 | 步兵 1、指挥官 2、轻车 5、APC/IFV 10、坦克 15、电台 20 |

占点票数单独记：抢占敌方已占点，我方 +30、敌方 −30，净摆动 60；占领中立点通常 +20；拉白本身不加分，成功占领才结算。

占点人数：中立点 1 人起，敌方点 3 人起，拉白后 2 人起；点内人数还要压过对方。队伍名前缀也要认得：ZSJ 是直升机队、PJP 是迫击炮队、ZCC 是侦察车队、APC 是装甲运兵车队、IFV 是步战车队。

放电台的条件：队长装、身边至少 1 名本队队员（载具或飞行员队长 3 名）、30 米内有带建材的补给车，并与友军电台至少间隔 400 米。

### 暖服期与社区底线

暖服期（人数低于 40）常见规则：禁压家、禁靠近敌方第二个点、禁压兵站、禁铲 FOB、禁迫击炮、陶和机枪堡。违反可能直接被踢。

底线：不开挂、不骂人、不TK报复、不抢别人认领的载具、不单人开走补给卡或直升机。误杀后公屏说“sorry”，有争议录屏找 OP。

::: takeaway
考核只考五件小事：按时集结、能打中、会自救、说得清、复活不选错；笔试的数字和服务器规矩，都是为了让你在压力下不犯低级错。
:::

## 第一阶能力串联流程

单个动作练稳后，要串成一局的固定流程。流程断了，通常不是不会，而是忘了下一步。

进服 → 选低延迟服务器 → 加有队长的小队 → 报到 → 部署 → 选步枪兵 → 跟随队长 → 按 `M` 看地图 → 报点 → 交火后补弹 → 受伤自疗 → 倒地呼救 → 复述命令 → 完成回报 → 选绿色复活点 → 复活后找队长。

| 阶段 | 关键动作 | 检查点 | 对应课 |
|---|---|---|---|
| 入场 | 选服、加队、报到 | 3 分钟内报“几队、什么兵种” | 01 |
| 部署 | 看状态条、选绿色点 | 90 秒内到队长身边 | 02 |
| 接敌 | 报点、点射、补弹 | 每次交火后弹匣满 | 05 |
| 伤救 | 掩体自疗、呼救 | 不在开阔地包扎 | 04 |
| 循环 | 复述、回报、再部署 | 死亡后 20 秒归队 | 05 |

第一周做到入场、部署、跟队，第二周加报点、补弹，第三周加复述、回报。每加一段，先确认上一段不用想。

::: takeaway
把六类动作串成一条局内流程，按周逐段加。流程在哪一步断，就回对应课补那一步。
:::

## 根据自检结果决定下一课

自检的终点不是分数，而是下一步。把未达标项对应到课程和加练动作。

| 未达标项 | 回看课程 | 加练动作 | 验收 |
|---|---|---|---|
| 加队、报到、部署 | 第 01 课 | 开局 3 分钟内报到 | 连续 3 局不迟到 |
| 地图、键位、标记 | 第 02 课 | 每局按 `M` 说两个网格 | 3 次报点带网格 |
| 兵种、装备 | 第 03 课 | 固定步枪兵打 3 局 | 不跟风换兵种 |
| 止血、救人、撤退 | 第 04 课 | 受伤先掩体再按 `5` | 10 次受伤 10 次先掩体 |
| 报点、复述、频道 | 第 05 课 | 每局 3 次完整报点 | 五要素齐全 2 次 |
| 复活点选择 | 第 04 课、第 13 课预习 | 死亡后先看状态条 | 连续 3 次全绿 |
| 听声、观察 | 第 08 课预习 | 每局停下来定位 3 次 | 能说出声音方向 |

一次只补一个短板；同时补三个，等于三个都只碰表面。顺序是“重读 → 三局专项 → 验收 → 下一项”。

全部达标后不要停在第一阶反复刷，进入第 07 课“读懂战场”，把注意力从自己的动作转到整个战场。

::: takeaway
未达标项对应哪课就回哪课，一次补一个，三局一验收。全绿后进入第 07 课。
:::

## 决策速查

| 场景 | 快速做法 |
|---|---|
| 不知道怎么练 | 先打一局自检，找最低的一项 |
| 想同时改几个毛病 | 只留一个主题，其余保持 |
| 判断是否达标 | 用次数、秒数、米数，不用感觉 |
| 某项连续三局 0 分 | 回课程重学要领 |
| 交火后总空枪 | 弹匣过半就找掩体换 |
| 复活总选错 | 先看状态条，只点绿色 |
| 全部达标 | 进入第 07 课，不重复刷 |

::: takeaway
速查表只回答一个问题：现在最该练哪一项。答案来自最近一局的事实，不来自情绪。
:::

## 实战案例

::: case 十局之后的差距
两个新人各打十局。A 每局只想打得好，十局里报点 2 次、复活点选错 5 次、复述 1 次。B 每局只练一项：报点、复活、换弹依次轮换，六类动作都练过一轮，其中四项连续三局达标。

复盘：A 的十局是十次重复，B 的十局是十次针对性练习。差距不在天赋，而在每局有没有主题。
:::

::: takeaway
十次重复不等于十次训练。每局有主题，场次才会变成进度。
:::

## 常见错误

::: mistake 症状—原因—改法
- 症状：每局想练所有动作。原因：贪多求快。改法：一局只留一个主题。
- 症状：自检表从不填。原因：觉得麻烦。改法：每局一分钟，只填五列。
- 症状：弱项明显还跳下一课。原因：不按前置顺序。改法：哪课弱回哪课。
- 症状：连续失败就换主题。原因：遇到瓶颈就逃。改法：同一主题坚持 5 局再判断。
- 症状：考核前临时背数字，实战不会用。原因：只记结论不记场景。改法：把每个数字配一个局内动作，例如“兵站 45 秒”配“复活前先看状态条”。
:::

::: takeaway
训练错误的根源通常不是不努力，而是目标太多、标准太虚、复盘太少。收窄目标，写清标准。
:::

## 实战练习

::: drill 三局一个主题
- 第一局前选一项主题，写下本局唯一指标。
- 第一局正常打，只记录主题动作的次数和失败原因。
- 局后填一行：目标、结果、判定、下局改法。
- 第二局只改一个细节，例如换弹阈值或报点顺序。
- 第三局不提醒自己，复测动作是否稳定。
- 第四局换主题前，先确认上一项连续两局达标。

完成标准：三局主题一致；至少两局达标；能说出一个失败原因和改法；下周主题已选定。三局都不达标就拆小动作，例如先练“报点先说方向”，再补距离和数量。
:::

::: takeaway
三局一个主题，第一局测、第二局改、第三局复测。拆小动作比换主题更快见效。
:::
