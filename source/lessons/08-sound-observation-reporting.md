## 学完能做到什么

- 把枪声、脚步、换弹、载具声当成状态提示。
- 按慢扫、停顿、侧看、回头循环观察。
- 用五要素在八秒内报点，语音与标记互相补位，并先报清身份和频道。
- 知道报点何时更新、何时取消。
- 能从固定设施和载具的声音里读出编制，而不只是听出“有人有车”。

::: takeaway
声音负责提前预警，观察负责确认，报点负责让全队行动。三件事连起来，信息才有价值。
:::

## 把声音当成状态提示

Squad 的声音不是背景，是早期预警。先记住五类：脚步、枪声、换弹、爆炸、载具。

| 声音 | 距离线索 | 状态含义 | 第一反应 |
|---|---|---|---|
| 枪声 | 近处清脆，远处发闷 | 连续自动射击多为机枪压制，单发间隔多为狙击或精确射手 | 停下定位，判断方向与距离 |
| 脚步 | 约 30–50 米内可闻 | 跑步、走路、蹲伏的节奏不同；木板、碎石、金属声不同 | 停止移动，转向声源 |
| 换弹 | 约 10–15 米内可闻 | 敌人换弹是推进窗口，自己换弹是火力空窗 | 敌人换弹则准备推进，自己换弹先报 |
| 载具 | 数百米外可闻 | 引擎声变大表示接近；履带与轮式声音不同 | 立刻找掩体，报车型和方向 |
| 爆炸 | 远近都能听到 | 单响多为手雷，连续多响多为炮击 | 先卧倒或进掩体 |

脚步不能单独分敌我，队友也会跑、也会踩木板。听到脚步先停，结合小地图队友位置和门口方向判断；拿不准就当敌人报。声音的价值在于“早”：还没看到人，引擎声已经告诉你三百米外有车。

枪声还有一个实用刻度：70 米。70 米以内声音清脆，能听出枪机、换弹和弹壳落地的细节；70 米以外声音发闷，只剩节奏和方向。用这个刻度校正自己对“远”和“近”的感觉，比只看小地图上的距离准。

### 载具声能听出编制

载具不只会告诉你“有车”，还会告诉你对面打算怎么打。战斗载具按火力从低到高大致是：电摇侦察车、轮式步战车、履带式步战车、坦克。声音越重、履带声越明显，你能依赖的掩体就越少。非战斗载具则暴露编制：直升机和补给卡通常伴随 FOB 与兵站，意味着对方准备长期、成批地送人；手摇侦察车和运兵卡通常伴随队包，意味着小股精锐要来摸点或绕后。

听到载具声，第一反应是找掩体，第二反应才是报。报的时候带上车型、方向、距离和状态：是在赶路、在巡逻、在警戒，还是在维修。车型报错比不报更糟，队友的反坦克手会按错误级别选择位置。

::: takeaway
声音是战场早期预警系统。听到异常先停、再定位、再报点，不要听到声音就扣扳机；载具声还要听出车型和它背后的编制。
:::

## 声音定位的四步：停、转、数、对照

听到声音后，最常见的错误是立刻追过去。正确顺序是停、转、数，再加一步对照。

停：停止移动和射击一到两秒，让自己的脚步和枪声先安静。

转：身体转向声源，直到左右耳音量平衡。人对前后方向不敏感，必要时左右转头两次。不要把“左声道响”直接当成左边有人。

数：等声音重复两到三次，记住间隔和音量变化。音量变大表示接近，间隔变短表示射速提高或目标靠近。

前三步之后再加一步对照：看地图、队友位置和附近掩体，用时约两秒，排除队友和回声。

墙壁会产生反射，室内枪声可能听起来在另一个房间。遇到回声，优先相信地图上的队友位置和门口方向，再用第二次声音修正。

定位后先报点，不要独自追声。声音只是线索，追过去可能进入对方的火力口。

## 固定设施的声音：顺着电流声找 FOB

有些声音不是人发出来的，而是设施在“自报位置”。这类声音距离短，但信息量大，听到一次就可能顺藤摸瓜找到对方的复活点。

| 声音 | 听辨距离 | 说明 | 能推出什么 |
|---|---|---|---|
| FOB 电流声 | 约 20 米内，隔几堵墙也能听到 | 低频嗡嗡声，靠近更明显 | 附近有敌方电台，沿声源三角定位 |
| 维修站 | 数十米内 | 持续运转声 | 附近有受损载具会来修，周围通常有 FOB |
| 固定武器 | 数十米内 | 重机枪、机炮的待机或射击声 | 附近有 FOB，且这条路被对方看住 |
| 反坦克导弹 | 数十米内 | 发射架待机、发射声 | 载具和直升机不要经过，周围通常有 FOB |
| 迫击炮阵地 | 数百米内 | 炮口闷响、连续装填声 | 附近有 FOB 或兵站，优先报给队长 |

听到 FOB 电流声后，不要直线冲过去。用三角定位：在第一个点记住声音强弱，横向移动十几米到第二个点再听一次，两次方向线的交点就是大概位置。只有一次方向时，只能报“疑似 FOB，在某方向”，不要报精确坐标。

固定武器和反坦克导弹的优先级高于普通步兵。它们周围往往有一个需要保护的东西，打掉操作员只是第一步，真正有价值的是顺着它找到 FOB、兵站或补给线。但这类目标通常有观察哨，单人摸过去容易被反杀，至少两人配合，一人压制、一人接近。

::: takeaway
FOB 电流声、维修站、固定武器和反坦克导弹都在提示“附近有 FOB”；听到先三角定位，再报疑似位置，不要直线追声。
:::

## 声音里的两种状态：没在打仗，还是已经抬枪

同一种声音，出现在不同状态的人身上，价值完全不同。判断标准不是“声音大小”，而是“对方有没有把注意力放在作战上”。

| 状态 | 典型声音 | 含义 | 你能做什么 |
|---|---|---|---|
| 非战斗准备 | 跑步、掏铲子、拔雷、长撕绷带、换弹、装卸弹药、架支脚 | 对方暂时无法瞬间开枪 | 这是推进和抓人的窗口 |
| 战斗准备 | 蹲走、爬行、左右徘徊、短点射 | 对方已经警戒，随时能抬枪 | 不要强行对枪，先架住或绕开 |

这里有两个容易上当的地方。第一，短撕绷带可能只是快速止血，也可能是故意做的假动作；长撕绷带才是较长的空窗。第二，敌人换弹不等于你可以无脑冲，附近可能还有第三个人在架枪。

更关键的是任务优先。小队是来偷 FOB 的，路过一个背对你的散兵、或者一个正在补给卡上卸货的敌人，不一定要开枪。枪声一响，整条街的注意力都会转过来，任务就从“偷”变成“打”。先问自己：打掉这个人，对当前任务有没有帮助？没有帮助就放他过去，把信息记下来。

::: takeaway
声音分两种状态：没在打仗是窗口，已经抬枪是警告；打不打由任务决定，不要为了一个人暴露整队。
:::

## 观察四步法：慢扫、停顿、侧看、回头

只盯正前方，是新人漏看的主要原因。观察要按固定节奏循环。

慢扫：视线从左到右缓慢移动，把正面分成三个扇区，每区停 1–2 秒。快速甩视角只能看到大块移动，看不到静止的人形轮廓。

停顿：看到疑似目标，停下来盯 3–5 秒。敌人常静止、蹲在窗后或只露出枪管，停顿能分清树丛、阴影和人。

侧看：每 10–15 秒向左、向右各看一眼，身体也要转。正面安全不代表侧翼安全。

回头：每 20–30 秒看一次身后和侧后方。被背刺，多半是推进时只看前面。

| 步骤 | 频率 | 看什么 | 目的 |
|---|---|---|---|
| 慢扫 | 持续 | 扇区边缘、窗口、屋顶、阴影 | 找到异常轮廓 |
| 停顿 | 发现疑似目标时 | 同一位置 3–5 秒 | 分清目标与背景 |
| 侧看 | 每 10–15 秒 | 左右侧翼、路口 | 防包抄 |
| 回头 | 每 20–30 秒 | 身后、来路、高处 | 防背刺 |

四步扫的不是“人”，而是“不自然”：一条太直的边、一个方块状的色块、一根从树线里伸出来的枪管、一片草丛里突然停住的轮廓、一个窗口里多出来的黑影。人眼对移动和反差最敏感，对静止的人形反而迟钝，所以先找“和背景不一样”，再确认“是不是人”。

颜色和亮度也是线索。林地地图里，深色衣服在浅色树干前会跳出来；城区地图里，站在窗口中央的人就是一个黑色剪影；逆光的高处，人只剩一个轮廓。你可以用这些反差找敌人，也要避免自己成为那个反差：别站在纯色墙面的正中间，别把枪管伸到窗外，别在逆光的门口停住。

四步是循环，不是做一遍就结束。移动时也要保持，尤其是穿门、翻墙、进楼前先停一下。优先看枪口火光、异常阴影和与背景不一致的轮廓。

::: takeaway
观察不是“看前面”，而是按节奏扫、停、侧、回。每 20 秒回头一次，能挡掉大多数背刺。
:::

## 报点五要素

报点要让队友能立刻行动，不是描述你看到了什么。五要素是方向、距离、目标、数量、动作。

| 要素 | 说明 | 示例 |
|---|---|---|
| 方向 | 时钟方向加基准，或地图网格 | “以我为基准，2 点，D4 格” |
| 距离 | 用米数或地标估算 | “150 米，仓库北墙前” |
| 目标 | 步兵、载具、机枪、电台、FOB | “敌方步兵，有一挺机枪” |
| 数量 | 确认人数或给下限 | “至少三人” |
| 动作 | 静止、移动、架枪、修电台 | “正沿墙根向东移动” |

完整示例：“二队，我在 C4 路口，西北 2 点方向，150 米，敌方步兵三人，正沿墙根向东移动。”八个字的方向、一个数字的距离、明确的目标和动作，队友听完就能转向。

不完整示例：“前面有人！”缺方向、距离、数量和动作，队友只能干看。

方向必须带基准。“左边”没有意义，每个人面朝的方向不同。用“以我为基准的 2 点”或“以 A 点为基准的东北”，能加网格更好。

距离按三档估：50 米内看面部和武器，50–150 米看人形和是否持枪，150 米以上只看移动的点或枪口火光。看不清就说“至少三人”，不要编数字。

动作决定优先级。静止观察可以等，架机枪、修电台、上车的目标要立刻处理。报“他在那儿”没有意义，报“他正在架枪”才有。

::: takeaway
报点就是五格填空：方向、距离、目标、数量、动作。方向带基准，数量不确定就说下限。
:::

## 报点前先报身份与频道

五要素解决“报什么”，还有两件事决定“这条报点有没有人听得懂”：你是谁，以及这条信息该走哪个频道。

小队满编时，三四个人可能同时看到同一个目标，各自报的方位都不一样。队长听到三条互相矛盾的方位，很难判断它们说的是不是同一个东西。报点前先报身份，队长才能把信息归到人头上：“A 组步枪，C4 东侧路口，两名步兵往北。”一句话里，谁在说、在哪、看到什么，全都清楚了。

| 顺序 | 内容 | 示例 |
|---|---|---|
| 我是谁 | 小队、火力组、兵种 | “B 组医疗” |
| 发现什么 | 目标类型与数量 | “两名步兵” |
| 方位参照 | 参照物加方位，或网格 | “C4 东侧路口，往北移动” |
| 补充 | 状态、威胁、要谁处理 | “可能需要机枪转东” |

频道也要用对。V 是周围约 50 米的语音，适合组内短报；B 是小队频道，队长和全队都在；G 是指挥官频道，只有小队长之间用，数字键盘 1–9 可以单独呼叫对应小队。火力组拆分后，组员用 V 报给组长，组长再用 B 报给队长；距离太远或情况紧急时，组员可以直接用 B 报，但报完要说明自己是哪个组。

最常见的错误是“我被打了”连喊三遍，没有身份、没有方位、没有人数。队长只能从声音判断你在挨打，却不知道该把枪口转向哪。正确说法是：“B 组医疗，C4 东侧被步枪打，至少两人，我在墙后。”先给身份和位置，再给状态和需求。

还有一条纪律：战斗频道不闲聊，也不重复报同一个没有变化的目标。三四个人看到同一个目标时，由离得最近、看得最清的人报一次，其他人补一句“确认”就够了。

::: takeaway
报点先报“我是谁”，再报“看到什么、在哪、要谁处理”；V 报组内、B 报小队、G 报队间，别让队长猜这条信息是谁说的。
:::

## 语音报点与地图标记配合

语音和标记各有短板。语音有细节但容易忘，标记有位置但没有数量和动作。两者一起用，队友既听得到又看得到。

推荐顺序：先说一句最短的接触报告，让队友抬头；两秒内在地图上标记；八秒内补距离、目标、数量、动作；目标移动后五秒内改标记。不要先沉默五秒找标记，敌人已经换位置了。

标记不能代替语音。队友可能正在看枪口，不会一直盯地图；标记也不会告诉他“三个人正往东走”。语音也不能代替标记，复杂地形里光靠“仓库左边”很难找。

没有标记权限时，用网格加地标：“D4 格，白色卡车车头，两个步兵”。标记不要刷屏，同一目标标一次，移动后再更新。

::: takeaway
先开口、再标记、后补细节。标记给位置，语音给数量和动作，两者缺一，队友都只能猜。
:::

## 报点过时与更新

报点有保质期。目标移动、被击倒或确认是队友后，旧报点就从信息变成误导。

一条接敌报点的有效期大约 10–15 秒。超过这个时间，目标可能已经换了位置。此时不要重复旧内容，要报变化：“更新，原 2 点方向的目标已移到 3 点。”目标消失就报“失去视野，最后位置在仓库北角”；发现是自己人就喊“取消，是我方”。

| 情形 | 该说 | 不该说 |
|---|---|---|
| 目标移动 | “更新，目标移到 3 点，仍在移动” | 重复原来的 2 点 |
| 目标消失 | “失去视野，最后位置仓库北角” | 沉默，让队友继续找 |
| 确认是队友 | “取消，是我方” | 不吭声 |
| 目标被清除 | “该方向安全” | 继续报同一个点 |
| 目标数量变化 | “更正，不是三个，是五个” | 坚持旧数字 |

更新要带“更新”或“更正”开头，队友才知道这是新信息，不是重复。整队推进到目标附近后，旧报点要主动取消，否则后来的队友会对着空地警戒。

::: takeaway
报点有保质期，大约 10–15 秒。目标动了就报“更新”，消失就报“失去视野”，是自己人就喊“取消”。
:::

## 不开盲枪的原则

听到声音或看到模糊人影，不要立刻开枪。枪声会暴露位置，打不中还会把对方的注意力引过来。

开枪前确认三点：身份看有没有武器、制服或队友位置，拿不准就先报点；掩体看开火后能不能立刻缩回，不能就先换位置；把握看这一梭子能不能打中或压住，不能就等目标进入有效距离。三点缺一，先报点。

声音不等于目标。脚步可能是队友，枪声可能是远处另一队在交火。把声音直接当成开火理由，最常见的后果是打中队友或暴露整队位置。已经开火就打完一个点射换位置，不要站在原地等对方反应。

::: takeaway
开枪前过三关：确认身份、有掩体、有把握。任何一关过不了，就用报点代替扣扳机。
:::

## 决策速查

| 场景 | 快速做法 |
|---|---|
| 听到脚步 | 停下，转向声源，结合地图判断敌我 |
| 听到载具 | 先找掩体，再报车型、方向、距离 |
| 看到模糊人影 | 停顿 3–5 秒确认，不急着开枪 |
| 发现敌人 | 先开口给方向，再标记，最后补五要素 |
| 目标移动或消失 | 报“更新”或“失去视野”，给新位置 |
| 确认是队友 | 立刻喊“取消，是我方” |
| 想开火但没把握 | 先报点，让队友一起确认 |

::: takeaway
速查表只排顺序：先保命，再定位，再报点，最后才决定开不开火。
:::

## 实战案例

::: case 声音先于视线
一局在戈壁，新人 A 只看眼睛，敌方小队从侧翼接近，他没发现，被包抄击倒。新人 B 听到侧翼有轻微脚步声，立刻停下定位，报“四点钟方向，80 米，敌方步兵四人，正向我方侧翼移动”。全队转身迎击，敌人被击退。

复盘：B 没有看到敌人，但声音提示让全队提前十秒转向。十秒足够架枪，也足够让载具退到掩体后。
:::

::: case 过时报点引来友军火力
小队报“仓库北侧两名敌人”，随后目标撤走，无人更新。两分钟后另一队推进到仓库北侧，有人仍按旧报点开火，打伤友军。直到有人喊“取消，是我方”，射击才停止。

复盘：报点不更新，就从情报变成陷阱。目标离开后必须主动取消或更正。
:::

::: takeaway
两个案例说明：声音要提前用，报点要及时更新。信息的新鲜度和完整度同样重要。
:::

## 常见错误

| 症状 | 原因 | 改法 |
|---|---|---|
| 只盯前面，被侧翼和背后打倒 | 观察范围太窄 | 每 10–15 秒侧看，每 20–30 秒回头 |
| 发现敌人只说“有人” | 没有报点模板 | 按五要素填空 |
| 听到枪声立刻开盲枪 | 把声音当成开火理由 | 先定位、报点，确认三点再开火 |
| 快速甩视角，什么都没看清 | 扫视太快 | 每区停 1–2 秒，疑似目标停 3–5 秒 |
| 报点用“左边” | 没有共同基准 | 用带基准的时钟方向加网格 |
| 目标移动后不更新 | 以为报过一次就够 | 报“更新”或“取消” |

这些错误的共同点是“只做了一半”：看到了不确认，确认了不报全，报了一次不更新。

::: takeaway
观察和报点的错误，多半不是不会，而是少做一步。把“确认、报全、更新”当成固定收尾动作。
:::

## 实战练习

::: drill 听声报点一局达标
- 听到任何异常声音，先停 3 秒定位，再决定行动。
- 按 V 报点至少 3 次，每次含方向、距离、目标、数量、动作。
- 每次报点后 2 秒内补地图标记，目标移动则更新。
- 观察四步法：每 15 秒侧看，每 30 秒回头，进门前停 1 秒。
- 全程零盲枪：不确定目标时只报点，不开火。

完成标准：声音定位 3 次以上；三次报点至少两次五要素齐全；每次报点都有标记或网格；零盲枪；能说出一次“更新”或“取消”的具体场景。局后按“声音定位、五要素报点、标记配合、盲枪”四项各记一行。
:::

::: takeaway
练习时把“先停、再报、后开火”当成固定顺序。每次报点都配一个标记，更新一次信息，习惯就成形了。
:::

## 自检 3 问

1. 听到异常声音后，三个反应按什么顺序？
2. 报点五要素分别是什么，方向为什么要带基准？
3. 报点发出后目标移动或消失，应该怎么说？
