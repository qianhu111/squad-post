## 学完能做到什么

- 进入一栋楼后按"门外观察、投掷、近角、远角、报清"的固定顺序推进，不跳过任何一个房间。
- 在楼梯和楼层之间组织交替掩护，不在楼梯平台扎堆，也不整队同时上楼。
- 识别门口与窗口的剪影风险，站在墙内而不是窗框中央，打完就换位置。
- 用两栋以上建筑的交叉火力封锁街道，而不是全队趴在同一个窗口。
- 用手雷、烟雾和破门工具打开通道，减少正面冲门。
- 室内通信只用短词，保持"清一间、报一间"的节奏。
- 每次进出换路线，避免被敌人预判。
- 用“掩体群”看街区：先占外围楼、再封路、最后拉点，不把点当孤立的旗杆。
- 守楼时把主力放在二楼和楼梯口，提前留好撤退路线，不把自己堵在顶楼。

::: takeaway
城区作战的胜负往往在进门之前就定了：路线、剪影、火力分配做对，清房只是收尾。
:::

## 建筑是城区的基本单位

城市地图的控制权不在点中心，而在能看见点的那几栋楼。谁占住点周围的楼，谁就决定街道上的人能不能活。进攻时先占一栋能看住街道的外围楼，建立观察和火力点，再用烟雾遮断街道、分批过街，进入目标楼后逐层清理，最后才让队友拉点。

防守时不要把所有人塞进点里。占住点周围两到三栋楼，用窗口形成交叉火力封住街道，点内只留拉点的人和一名预备队员。敌人进楼时用榴弹和手雷清房间，不要一个接一个冲进去送。

| 建筑类型 | 价值 | 风险 | 用法 |
|---|---|---|---|
| 临街楼 | 控制街道和对面建筑 | 窗口多，剪影暴露 | 架交叉火力，不站窗中央 |
| 内部楼 | 隐蔽接近、设置集结点 | 视野差，易被隔墙炸 | 当通道和临时救护点 |
| 地下室 | 防炮击、存放兵站 | 只有一个出口，易被封死 | 放电台和兵站，留人守口 |
| 屋顶 | 视野最好 | 完全暴露，无退路 | 只在有掩体时短时观察 |

一栋楼的价值按"它能看见什么"算，不按"离点多近"算。离点最近却四面被更高建筑包围的楼，占它等于把自己关进盒子；选楼先看窗口朝向，再看退路，最后看距离。

::: takeaway
占楼先看它能看见什么、能不能退，再看离点多近；点中心只是拉点的地方。
:::

## 街区是掩体群，不是一条街

把点位周围画一圈：楼房、院墙、街垒是“有掩体”的岛，街道、广场、空地是“没掩体”的海。敌人从掩体群外往里打，子弹先打在墙上；你从掩体群里往外打，街道上的人没有遮挡。所以争夺点位，本质上是争夺点位周围的那一圈掩体群，而不是站在旗杆下面。

| 区域 | 特点 | 谁占便宜 |
|---|---|---|
| 掩体群内 | 墙、楼、院墙多，能藏能打 | 防守方、先占楼的一方 |
| 掩体群边缘 | 能看住出入口，退路短 | 双方争夺的焦点 |
| 掩体群外 | 街道、空地、桥面，无遮挡 | 有窗口火力的一方 |

进攻一个街区，顺序是“先占外围、再封路口、后清目标楼”。先占一栋能看住主街的楼，把敌人的增援路线看在眼里；再架住支路、桥头、巷口，让敌人不能轻易进出；最后才用烟幕过街，进目标楼逐层清。反过来，一上来就冲点，等于把自己放进掩体群外的那片“海”里。

防守时，如果人手够，占住点周围两到三栋楼，用窗口交叉火力封街道，点内只留拉点的人和预备队。如果人手不够，不要硬占每一栋楼，把枪线放在掩体群的出入口：敌人从哪条街进来，就先打哪条街。控制不了整个区域，至少要让敌人不能大摇大摆地进出。

街区还被街道和桥分成一块一块。桥头、十字路口、巷口是“门”，谁控制门，谁就控制人和补给的流动。进攻先清门两侧的楼，再让载具或步兵通过；防守把反载具火力放在门的一侧，不要正对门摆。

## 房间清理的顺序

房间清理最容易出错的地方不是枪法，而是门口。门口是整间房火力最集中的一条线，站在门口观察超过两秒，就等于把自己钉在靶心上。

固定顺序分五步：

| 步骤 | 动作 | 要点 |
|---|---|---|
| 1 门外集结 | 全组在门轴一侧靠墙 | 不站在门洞正中，不堵走廊 |
| 2 切角观察 | 从门轴一侧逐步扩大视角 | 身体不出门框，只看能看到的部分 |
| 3 投掷 | 手雷先入；要遮断就先投烟 | 投雷报"炸"，等爆再进 |
| 4 进入 | 第一人近角，第二人远角 | 两人错开，不并排挤门 |
| 5 报清 | 确认全房后报"房间清" | 未确认的死角不算清 |

进入房间后，第一人负责门后的近角，第二人负责对面的远角，第三人留在门口外侧控制走廊。近角和远角是大多数伏击发生的位置，先控制这两个点，再向纵深推进。房间中间、窗边、家具后面都要目视确认，不要凭"看起来很空"就报清。

长走廊按"门—门—尽头"的顺序推进，每到一个门口就重复一次五步。走廊尽头如果有拐角，先贴墙切角，不要直接走到拐角正面。双门房间从一侧进、另一侧留人封口，防止敌人从第二个门跑掉或反包。

### 特殊房间

普通方房间用五步就够，遇到套间、天井和拐角，要加一步“先看结构，再决定从哪进”。

| 房间类型 | 风险 | 做法 |
|---|---|---|
| 套间（里外两间） | 外间清完，里间门后还藏人 | 外间留一人封里门，其他人切角进里间 |
| 天井 / 中庭 | 上下左右都能来人 | 先看二层走廊和对面窗，再贴墙进 |
| 长走廊 | 一条线被打穿，手雷能滚很远 | 贴墙、分段、每段先看尽头 |
| 拐角 | 贴墙一侧有死角 | 先切角，身体不出墙，别直接拐 |
| 双门房间 | 敌人从第二个门跑或反包 | 一侧进、一侧留人封口 |

套间最容易被“清一半”。外间看起来空了，里间的门还关着，第一个人一转身，门后的人就开火。正确做法是外间清完后，留一个人枪口对着里门，其余人重新贴墙、切角、投雷，再进里间；不要因为“已经清了一间”就放松。

天井和中庭要把“头顶”算进去。二层走廊、对面窗口、楼梯口都能往天井里打，进天井前先让队友架住这些高处的射口，再贴墙快速通过。天井不是房间，是一个竖井，站在中间等于站在井底。

![房间清理顺序示意图](../../assets/images/room-clearing.svg)

::: takeaway
清房的骨架是五步：门外靠墙、切角、投掷、近角远角、报清；门口停留越短越好。

## 楼层与楼梯

楼梯间是整栋楼最危险的地方。楼梯口通常只有一条上下通道，敌人只要在转角架一挺机枪，就能把整队人堵在下面。上楼前先在楼梯口下方集结，不要把头探到转角上方。

| 情形 | 做法 | 原因 |
|---|---|---|
| 上楼 | 一人架住转角，一人快速通过并占平台 | 架枪的人不移动，移动的人不架枪 |
| 下楼 | 先向楼下投雷，再贴墙下行 | 楼下视野窄，敌人容易贴墙埋伏 |
| 楼梯平台 | 不在平台停留超过两秒 | 平台四面来火，没有掩体 |
| 地板破洞 | 先确认脚下，再移动 | 可透视上下层，也可能直接掉下去 |

楼层顺序按一楼、楼上、地下室的次序推进。先清一楼是为了拿到一个安全的立足点和出入口，再向上逐层压缩，最后处理地下室。地下室通常是死胡同，进去之前先投雷、先确认出口，不要在没清一楼的情况下直接下地下室。

楼板会传声。敌人在楼上跑动、换弹、倒地，声音都能提供位置。听到头顶有脚步，不要朝天花板盲目开枪，先报位置、等队友架住楼梯，再决定投雷还是绕上去。

### 什么时候自上而下

“一楼、楼上、地下室”是默认顺序，不是唯一顺序。三种情况可以从上往下清：

1. 一楼被敌人火力完全封死，从正门进就是送；改从相邻楼的屋顶、梯子或后窗进入高层。
2. 你已经占住屋顶，敌人在楼下，往下打比往上冲更稳。
3. 目标楼只有一个窄楼梯，从下往上会被一挺机枪堵死，从屋顶破口进入能绕开楼梯。

自上而下的代价是退路难。进去以后，楼梯在敌人手里，补给和伤员都下不来；所以进之前要先在屋顶留一个接应组，约定“打到哪一层、从哪个窗口撤”。每清一层，都要回头确认身后的楼梯口有人守，不然敌人会从下面跟上来。

不管从上还是从下，原则相同：先控制楼梯口，再清房间；不要在楼梯平台上停留；每层清完报一次，不要跳层。

楼梯口先架后动，平台不停留；楼层按一楼、楼上、地下室的次序清，地下室最后处理。

## 门口与窗口剪影

门口和窗口的共同问题是剪影：你站在光亮的门框或窗框里，外面的人看到的是一个完整轮廓，而你还没看清他。窗口的正确站位是墙内一米以外，只把枪口和半个头伸到窗边，身体留在墙后。打完立即收回，换到另一个窗口或另一个射孔。

| 位置 | 暴露程度 | 评价 |
|---|---|---|
| 窗框正中央 | 整个上半身成剪影 | 最差，禁止久站 |
| 窗边内侧一米 | 只露枪口和头部侧面 | 可用，打完就换 |
| 墙后射孔 | 几乎不露身形 | 最佳，但视野窄 |
| 屋顶边缘 | 全身轮廓对天空 | 极危险，只可短时观察 |

逆光会让剪影更明显。白天从暗室内向外看，你觉得自己藏在阴影里，外面的人却能看到一个清楚的黑色轮廓。室内开枪的枪口火光也会暴露位置，打完一梭子就换射孔，不要原地等敌人回火。

门口同理。进门之前不要站在门洞正中，靠门轴一侧、压低身体、快速通过。出门时先看对面窗口和街道两端，再决定是冲、是爬、还是等烟雾。

::: takeaway
窗口站内侧一米、只露枪口，门口靠门轴快速通过；剪影一旦形成，先挨枪的通常是你。
:::

## 街道交叉火力

街道是杀伤区，不是集结区。控制街道的办法不是派人站在街上，而是从两侧建筑形成交叉火力。两个窗口的射击线夹角越大，覆盖越完整，敌人从任何一端过街都会被至少一个火力点看到。

| 火力位置 | 覆盖 | 注意 |
|---|---|---|
| 临街二楼窗口 | 街道中段和对面门口 | 不与队友选同一扇窗 |
| 侧翼建筑窗口 | 街道纵向，打侧身 | 角度大，友军误伤风险也大 |
| 街垒或废弃载具 | 街道近端 | 只挡一个方向，别久留 |
| 高层屋顶 | 远端街道 | 剪影明显，打完就撤 |

分组时明确射界：一组负责街道东段，一组负责西段，中间用一辆烧毁的车或路障当分界。没有分界，两个人会同时打同一个目标，另一段街道就空了。交叉火力还要约定停火信号，队友过街时对应扇区必须停火，否则最危险的火力来自自己人。

过街用烟雾遮断，一次过两到三人，间隔五到十米，不要整队一起冲。第一组到位并架好枪，第二组再动。没有烟雾时，选有实体掩体的路线，沿着墙根、车体、路障逐段移动，不要在街道中央停留。

### 装甲车进街区

装甲车在街区里是“移动火力点”，不是“移动堡垒”。它能在街口用机炮封住对面整排窗口，掩护步兵过街；但一进窄巷，两侧楼上、地下室的筒子都能打它的侧面，车体转不过身，炮塔也压不下近距离的楼顶。

正确用法是车停在街口或街区边缘，车头朝撤离方向，炮手打街道尽头和对面高层，步兵在车前方五十米清一楼、地下室和巷口。车不进窄巷，步兵不贴车身；双方保持能互相看见的视线。车要前移时，先由步兵确认前方两侧的窗口和巷口没有反载具，再短句通知“前移五十”，不要鸣笛或闪灯。

车在街区里最怕三件事：楼上垂直投下的爆炸物、巷口侧面的火箭、退路被路障堵死。所以停车前先看“能不能倒出去”，步兵要主动替车看车顶和车后。烟幕可以把车和楼上观察手隔开，但烟也会挡住车组自己的视野，投烟前说清“烟在车前三十米，不要前移”。

街道用两侧窗口交叉封锁，先分射界再谈火力；过街靠烟雾和分批，不靠人多。

## 防守一栋楼：射界、陷阱与撤出

守楼不是把所有人塞进一楼对枪。楼的价值在垂直方向：一楼用来观察和迟滞，二楼用来打交叉火力，地下室放电台和伤员，屋顶只做短时观察。把所有人在一楼排一排，敌人一颗手雷就能清掉半个队。

| 楼层 | 作用 | 注意 |
|---|---|---|
| 屋顶 | 观察、报点、短时射击 | 剪影明显，打完就下 |
| 二楼 | 主防线，窗口交叉火力 | 不站窗中央，打完换窗口 |
| 一楼 | 迟滞、诱饵、观察门口 | 不把主力放这里 |
| 地下室 | 电台、兵站、伤员 | 只有一个出口，留人守口 |

守楼的关键是楼梯口，不是大门。敌人进了一楼，不代表楼丢了；只要楼梯口还在你手里，他就上不来。楼梯口架一挺机枪或一名步枪手，配合手雷反清；听到楼下有人集结，先扔雷再探头。不要一个接一个下楼送，也不要把楼梯平台当掩体。

窗口射击要“打一枪换一个地方”。同一扇窗连续露头三次，对面狙击手就记住了。可以在二楼几个窗口之间轮换，也可以在墙后开射孔；开枪后立刻退到墙内，不要探头看战果。敌人会对着枪口火光和窗口回火，你多看一秒，就多一秒被命中的机会。

守楼之前先选好退路：后门、后窗、相邻楼的破洞、屋顶跳下的落点。退路不能被杂物堵死，跳窗前先看高度和落点有没有敌人。撤的时候留一颗雷或一段烟，迟滞追兵；不要从进攻方刚进来的正门往外冲。

被攻入一层时，按“放弃一楼、退二楼、封楼梯、等反冲”处理：一楼的人沿预设路线退，二楼的人投雷封楼梯，不要站在楼梯口接应；等敌人进了一楼房间，再从二楼或相邻楼往下打。守楼最怕的是“舍不得一楼”，为了守一个房间把整队耗死在里面。

:::

## 手雷与破门

手雷的作用是把房间里的敌人从"以逸待劳"变成"被迫移动"。进门前投一颗破片雷，等爆后再进；如果房间可能有队友，先确认再投，需要遮断时改投烟雾。投雷时贴着门框侧面，手臂不要伸过门洞，投完立即收手报"炸"。

| 工具 | 适用 | 风险 |
|---|---|---|
| 破片手雷 | 封闭房间、楼梯转角 | 反弹回来、隔墙伤队友 |
| 烟雾弹 | 过街、撤出、遮断窗口 | 也会挡住自己人视线 |
| C4 / 工兵炸药 | 锁死的大门、需要开新通道 | 声响大，引来增援 |
| 烟幕遮断 | 正门被架枪，需要换入口 | 也会挡住自己人视线 |
| 载具撞击 | 外墙、大门 | 暴露载具，可能被困 |

破门还要决定"从哪进"。正面大门通常被架好枪，能用 C4 炸侧墙或走后院门就不挤正门；开新通道能让敌人预判失效，但声响也会暴露意图，所以开完门立即进入。

手雷投出后不要马上跟进，等爆炸和烟尘稍落、里面的人开始移动再进；按"投、等爆、进"三个节拍走，不要抢拍。

::: takeaway
手雷负责打乱，破门负责改路线；投完等爆再进，破门之后立刻进。
:::

## 室内通信与节奏

室内语音要短，因为房间之间只隔一堵墙，长句子会被回声和枪声切碎。约定一套固定短词，全组用同样的词，不要临场发明。

| 短词 | 含义 | 谁来说 |
|---|---|---|
| 门口 | 已到门口，准备进入 | 第一人 |
| 进 | 开始进入 | 第一人 |
| 清 | 房间确认安全 | 最后进入的人 |
| 停 | 全体停止移动 | 任何人 |
| 楼上 | 注意头顶 | 发现脚步或楼板震动的人 |
| 背后 | 身后有威胁 | 最后一人 |
| 换 | 换弹或换位，需要掩护 | 正在交火的人 |

节奏比速度重要。清完一间房，停三到五秒，确认走廊和下一个门口，再动。连续冲三个房间看起来很快，实际上队形会拉散，第一个人进第三间时，第二个人还在第一间。正确的节奏是"清一间、报一间、等一秒、再动"。

室内不要用无线电处理近距离协同，直接喊或用手势。无线电留给楼外：报占楼进度、请求烟雾、报告敌人增援方向。队长在楼外时，靠短词判断楼内进度，听到"二楼清"就知道可以准备拉点。

::: takeaway
室内用短词不用长句，清一间报一间；节奏是清、报、停、再动，不是一路冲到底。
:::

## 避免重复路线

敌人会学习。你从同一扇门进、同一段楼梯上、同一扇窗开火，第三次就会被预判。预判的后果可能是门口一颗雷、楼梯口一挺机枪，或者退路上一个炸药包。

| 重复行为 | 敌人如何利用 | 改法 |
|---|---|---|
| 每次从正门进出 | 正门架枪或埋雷 | 换侧门、后院门或炸开新通道 |
| 每次走同一段楼梯 | 楼梯口预瞄 | 换楼梯、换楼层顺序、先投雷 |
| 每次在同一窗口开火 | 狙击手记住射孔 | 换窗口、换楼层、打完就撤 |
| 每次沿主街推进 | 街口交叉火力 | 走建筑内部或后巷，逐栋跳 |
| 每次在同一房间集结 | 隔墙榴弹 | 集结点每次换，不固定 |

换路线不是绕远，而是让敌人的预判落空。进攻时可以从一栋楼的二层打通到隔壁楼，形成"鼠洞"通道，避开街道；防守时则要故意留一条看起来好走的路，让敌人走进交叉火力。

时间也要变化，偶尔晚十秒、换一栋楼、先从另一边打，都能打乱对方部署。

::: takeaway
路线、窗口、集结位置都要轮换；敌人记住你的习惯之日，就是你被预瞄之时。
:::

## 决策速查

| 情形 | 先做什么 | 再做什么 |
|---|---|---|
| 要进攻一栋楼 | 占外围观察楼 | 烟雾过街，分批接近 |
| 到门口 | 靠门轴、切角 | 投雷、等爆、进 |
| 进房间 | 近角、远角 | 确认死角后报清 |
| 到楼梯口 | 一人架转角 | 一人快速占平台 |
| 街道被封锁 | 找两侧窗口 | 建立交叉火力再动 |
| 全队挤在点里 | 分出两到三人占周围楼 | 点内只留拉点的人 |
| 要进一个套间 | 外间留人封里门 | 再切角、投雷进里间 |
| 一楼被架死 | 找屋顶或相邻楼入口 | 自上而下清，屋顶留接应组 |
| 守楼只守大门 | 敌人从后门/窗口进 | 主力守二楼和楼梯口，一楼只迟滞 |
| 窗口连续露头 | 狙击手记住射孔 | 打一枪换窗口，退到墙内 |

- 清楼顺序：一楼、楼上、地下室，不跳房间。
- 窗口站内侧一米，只露枪口，打完换窗口。
- 过街一次两到三人，间隔五到十米。
- 室内短词：门口、进、清、停、楼上、背后、换。
- 每次进出换路线，不重复同一扇门和同一段楼梯。
- 守楼守楼梯口，一楼迟滞、二楼主防、地下室放电台。
- 套间先封里门，天井先看头顶，拐角先切角。
- 一楼被架死就找屋顶或相邻楼，自上而下清，屋顶留接应。

::: takeaway
速查表按"先占楼、再清房、后拉点"排序，顺序错了，枪法好也救不回来。
:::

## 实战案例

地图是纳尔瓦，我方进攻火车站。队长把小队分成两个火力组：一组占车站西侧的五角楼，用二楼窗口架住站台和道路；另一组从侧翼后巷绕到车站东侧，占一栋三层楼的二层。

两组到位后，西组报"西侧窗口就位，覆盖站台中段"，东组报"东侧就位，覆盖站台北端"。敌方从站房正面增援，刚出门口就被两侧交叉火力夹住，倒在站台边缘。

队长下令过街。先投两颗烟雾遮断站房正面窗口，第一组两人间隔八米跑过，贴到站房墙根；第二组跟进，在门轴一侧集结。破片雷投入站房，爆后第一人进近角、第二人进远角，第三人封走廊。一楼报清后，沿楼梯上一人架转角、一人占平台，清二楼，最后下地下室确认没有电台。

复盘：占楼、分射界、烟雾过街、五步清房、楼梯交替掩护，每一步都按顺序走。如果全队从正面冲站台，站房窗口一挺机枪就能把整队压在街上；如果清完一楼直接拉点，二楼和地下室的敌人会在背后开火。

::: takeaway
案例的骨架是"先占周围楼、再分段过街、最后逐层清"；跳过任何一步，都会在背后留下枪口。
:::

## 常见错误

| 症状 | 原因 | 改法 |
|---|---|---|
| 全队卡在门口进不去 | 都挤在门洞正中，第一个人倒地后堵死 | 靠门轴一侧集结，先投雷再进 |
| 清完的房间又冒出敌人 | 只看了正面，没清门后和死角 | 近角、远角、家具后逐个确认再报清 |
| 上楼时被一梭子打光 | 整队同时挤楼梯 | 一人架转角，一人占平台，交替上 |
| 窗口对枪总是先死 | 站在窗框中央形成剪影 | 退到墙内一米，只露枪口 |
| 过街时被两侧同时打 | 没有烟雾、没有分批 | 烟雾遮断，两三人一组，间隔五到十米 |
| 拉点时被背后偷袭 | 清楼不彻底就急着占点 | 一楼、楼上、地下室全清再拉点 |
| 同一扇门连续被炸 | 进出路线固定 | 换门、换窗、炸开新通道 |
| 守楼时全队在一楼对枪 | 把楼当平面 | 一楼迟滞、二楼主防、楼梯口架枪 |
| 装甲车开进窄巷 | 把车当堡垒 | 车停街口封远处，步兵清两侧 |

::: takeaway
城区最常见的死法不是对枪输，而是堵门、漏角、挤楼梯、剪影和固定路线。
:::

## 实战练习

找一局有城镇或建筑群的图，完成三项练习。

1. 清一栋两层带地下室的楼，严格按五步走，每间房报一次"清"，记录有没有漏掉门后和家具后。
2. 与一名队友占两栋相邻建筑，约定射界分界，用交叉火力封锁同一段街道，坚持两分钟不被突破。
3. 设计一条不走主街的进攻路线，用后巷、院墙或建筑内部接近目标，记录敌人有没有提前架枪等你。
4. 守一栋两层楼：一楼只放观察和迟滞，主力放二楼，楼梯口架枪，提前指定后门或窗口退路。完成标准：敌人进一楼后，全员能在 15 秒内退到二楼并封住楼梯口。

完成标准：清楼无漏角，交叉火力有明确分界，进攻路线与上一轮不同。练完回答：这一局里，哪一次剪影暴露是可以避免的？

::: takeaway
练清房练的是顺序，练交叉火力练的是分界，练路线练的是不被预判；三样都比枪法更耐用。
:::

## 自检 3 问

1. 进入一个房间的五个步骤是什么？近角和远角分别由谁负责？
2. 窗口观察和开火的正确站位是什么，为什么不能站窗框中央？
3. 为什么清楼顺序是"一楼、楼上、地下室"，而不是直接冲楼上或先下地下室？

::: takeaway
三问都能答清，说明你进楼之前就知道每一步该站哪、该看哪，而不是进门后凭感觉走。
:::
