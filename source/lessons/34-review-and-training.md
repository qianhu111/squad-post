## 学完能做到什么

- 用“事实、判断、动作、结果、下次改什么”五栏，在十分钟内完成一局复盘。
- 分开“运气好”与“做得对”，能指出流程正确和敌人失误各占多少。
- 按 100 小时路线安排训练，并把复盘结论压成下一局只执行的一个动作。
- 按五个带教阶段安排新人成长，让二队长能独立收拢一次。

::: takeaway
复盘不是解释这局为什么输，而是让下一局少一个可重复的错误。一次只改一个动作，才改得动。
:::

## 复盘模板：从事实到动作

复盘最容易变成“我觉得”“当时要是”。固定五栏能把讨论压回可验证的内容，十分钟足够走一轮。

| 栏目 | 写什么 | 合格例子 | 不合格例子 |
|---|---|---|---|
| 事实 | 时间、位置、人数、票数、命令原话 | 8:12，C 点东楼梯口，一组三人被一颗雷击倒，票数 180 比 210 | 我们打得很乱 |
| 判断 | 当时看到什么、有哪些备选、为何选这个 | 听到楼上有脚步，判断二楼有人，决定先扔雷 | 感觉里面有人 |
| 动作 | 谁在何时做了什么 | 二组扔烟后从北门进，一组窗外架枪 | 我们冲了进去 |
| 结果 | 票数、伤亡、据点、耗时 | 占下东楼，九十秒，损失一人，票数反超十票 | 效果还行 |
| 下次改什么 | 一个动作，带触发和标准 | 进未知房间先贴墙听两秒再扔雷 | 下次注意配合 |

顺序不能倒：先事实，再判断，最后改进。一上来就写“下次要谨慎”是没有事实支撑的口号。事实至少三条，判断至少两条，动作写到组一级，结果带数字，改进只能一条。超过一条说明没抓住重点。

时间分配：事实三分钟，判断三分钟，结果两分钟，改进两分钟。主持人负责打断“如果当时”“要不是他”，把话拉回“当时你看见了什么”。结束前让负责改进的人复述一次动作，确认不是主持人替他想出来的。

::: figure 图 34-1：复盘闭环。事实、判断、动作、结果、下次改什么，一轮只留一个动作。
![复盘闭环示意图](../../assets/images/review-loop.svg)
:::

::: takeaway
五栏模板把复盘从情绪拉回证据：先写发生了什么，再写当时怎么想，最后只留一个下次动作。改进超过一条，等于没有改进。
:::

## 把事实写清楚

事实的标准是：换一个人看记录，能还原同样的画面。每条至少包含时间、地点、主体、动作、结果。比如“8:12，C 点东侧楼梯口，一组三人上楼，第一人踩雷倒地，后两人被补枪”，而不是“一组冲楼团灭”。地点用地图上的具名建筑、街道、方向，不用“左边”，因为每个人眼里的左边不一样。

可用来源有四类：票数，能看出交换比和节奏；地图，FOB、HAB、载具残骸能还原战线；频道记录，谁在何时报了什么、队长下了什么命令；个人视角，谁最后看到谁、谁还有弹。个人视角只写“看到”，不写“估计”。

事实层不写评价，但要写异常：命令下达十秒无人确认；某组连续三分钟没报位置；接敌前弹药就见了底；重生的人连续两次走同一条路。异常是判断层的入口，比“大家发挥不好”有用得多。

当场记不全，局末先用三十秒记五个节点：开局部署、第一次接敌、第一次丢人、据点易手、局末状态。五个节点足以支撑一次有效复盘，不必还原每一枪。

::: takeaway
事实要能还原画面：时间、地点、主体、动作、结果，地点用地图具名位置。只写看到和记录到的，异常比情绪更值得记。
:::

## 复盘看哪些数：六个指标

五栏解决“发生了什么”，指标解决“变化有多大”。没有数字，复盘容易停在“感觉这局打得还行”；有了数字，才能判断是进步、退步，还是换了一种输法。

| 指标 | 算法 | 能看出什么 | 常见误读 |
|---|---|---|---|
| 票数交换比 | 我方造成敌方票损 ÷ 我方票损 | 交换是否划算 | 只算击杀，漏掉点位和电台票 |
| 占点用时 | 从第一人进点到拉穿 | 组织效率、复活点远近 | 占得快但守不住，不算好 |
| HAB 存活时间 | 从建好到被压或被毁 | 选址、警戒、反侦察 | 活得久也可能是没人发现，不全是防守好 |
| 有效报点率 | 被队长确认或采用的报点 ÷ 总报点 | 信息质量 | 报得多不等于报得准 |
| 平均存活时间 | 每次复活到倒地的平均时长 | 走位、掩体、交战距离 | 苟在后面也会很长，要结合占点看 |
| 载具损失比 | 我方损失载具票 ÷ 敌方损失载具票 | 载具使用效率 | 不敢用车也会“零损失”，但没贡献 |

一局不必六个全算。选两个和本周训练指标对齐的：这周练报点，就记有效报点率和平均存活时间；这周练载具，就记载具损失比和占点用时。指标要从同一张地图、同一种模式里取，换图换模式后没有可比性。

指标只用来找问题，不用来排名。交换比高但没占点，可能是在刷人头；占点快但票数亏光，可能是拿命换进度。数字必须和五栏里的具体动作对上，才知道下一步改什么。

::: takeaway
一局选两个指标，和本周训练主题对齐；数字用来找问题，不用来排名。指标必须能回到具体动作，否则只是另一种感觉。
:::

## 从事实到判断

判断层回答：在当时能获得的信息下，这个决定是否合理。不是用结果倒推。流程正确可能结果失败，流程错误也可能因敌人更失误而成功。把关键决定放进四象限：

|  | 结果好 | 结果差 |
|---|---|---|
| 流程对 | 保留并标准化 | 保留流程，检查执行和运气 |
| 流程错 | 最危险，必须改 | 直接停用，不找借口 |

“流程错、结果好”最容易骗人。全队挤在一个窗口，恰好敌人从正面送人头，赢了；下一次同样站位会被侧翼一颗雷收掉。复盘要专门抓这种“赢得不明不白”的动作，不因为赢了就放过。

还要区分“信息不足”和“判断失误”。频道里没人报侧翼，队长不知道侧翼有人，选择正面推进是信息不足；侧翼已经报了两次，队长仍把全队压在正面，是判断失误。前者改通信流程，后者改决策规则。

常用三问：当时最关键的三条信息是什么，有没有一条其实早有人报过；除了我选的做法，还有哪个备选当时就能执行；如果结果是敌人失误送的，下一次敌人不失误，这个做法还成立吗。

::: takeaway
判断层只问“当时的信息下是否合理”，不做事后诸葛。尤其要盯住“流程错但赢了”的动作，它会在下一局收利息。
:::

## 100 小时训练路线

100 小时不是死数字，而是排序：先保证不死，再保证能沟通，再保证能协同，最后练指挥。每阶段有验收动作，避免一直待在舒适区打枪。

| 阶段 | 小时 | 练什么 | 验收标准 |
|---|---|---|---|
| 入门定向 | 0–10 | 键位、地图、兵种、出生点、票数 | 能独立进服、选对兵种、找到集结点 |
| 生存与通信 | 11–25 | 掩体、止血、救人、报点五要素 | 连续十次报点不缺要素；中弹先找掩体 |
| 步兵与地形 | 26–45 | 下车、观察推进、清楼、烟与手雷 | 三次下车不挤门；三次清楼不跳房 |
| 火力组与指挥 | 46–65 | 编组、任务卡、交叉火力、防御 | 能管两个组；任务有完成信号；有预备位 |
| 后勤与载具 | 66–80 | FOB 选址、补给线、载具协同 | 能组织完整补给；遇袭能分散下车 |
| 复杂局面 | 81–95 | 多点接敌、撤退、士气、指挥继承 | 两线接敌能说出主次并完成撤离 |
| 认证与复盘 | 96–100 | 综合演练、评分、下一周期 | 综合评分达标；能独立主持复盘 |

每阶段配一个训练场科目：0–10 小时练键位和射击；11–25 小时练听声辨位和地图标记；26–45 小时练三人推进与清楼；46–65 小时练建 FOB、放队包、下任务卡；66–80 小时练载具装卸和补给线；81–95 小时跑复杂局面脚本；96–100 小时走全流程演练。训练场先把动作练熟，再进实战，比在实战里交学费便宜。

每周六小时：一小时离线准备，四小时实战，一小时复盘。离线那一小时最容易被忽略，但它决定实战有没有主题。实战只盯本周一个指标，其他动作照常，不要同时改五件事。

每二十小时回炉一次最早练的报点、下车、掩体。技能会退化，长时间只打指挥位后基础动作更容易变形。回炉不合格，补两小时再往前走。

::: takeaway
100 小时按“活下来、说清楚、能协同、会指挥、懂后勤、扛复杂、能认证”排序，每阶段有验收。每周留一小时离线准备，每二十小时回炉基础。
:::

## 从队员到队长：带教路径

100 小时路线解决“自己会不会”，带教路径解决“能不能让别人也会”。一个人枪法好，不代表能带人；能带人的队长，通常是从被带、带小组、替队长督战，一步一步长出来的。

| 阶段 | 小时 | 角色 | 练什么 | 出师标准 |
|---|---|---|---|---|
| 跟队 | 0–20 | 步枪兵 | 听命令、报点、找掩体、不死 | 连续三局跟住队长；十次报点八次五要素齐全 |
| 专长 | 20–40 | 医疗、筒子、机枪、工兵 | 把一个岗位练到能独立 | 医疗十次救人八次先烟后救；筒子十次先躲后报 |
| 固定火力组 | 40–70 | 三到四人小组 | 互相补位、轮换、交叉火力 | 三次任务无掉队，能复述组长命令 |
| 副组长 | 70–100 | 小组长或督战 | 检查装备、纠正站位、替队长收拢 | 独立带组完成一次绕侧或防守 |
| 队长 | 100 以上 | 小队长 | 任务卡、票账、复盘、对外协调 | 独立带一队完成建 FOB、进攻、拉点、复盘 |

老兵带新兵时，分工要具体：新兵放在前队靠后的位置做试探和第一接触，老兵在后队补漏、纠正站位、记录错误。不是让新兵送死，而是让他在低风险位置先学会看和报；真正危险的方向由老兵或组长带头。

固定队员比临时凑人重要。同一批人连续打四周，才能形成不用解释的默契：谁看哪个扇区、谁先扔烟、谁在队长倒下后接管，都不需要每次重新讲。人员流动大的队伍，战术永远停在第一周。

培养二队长的方法，是让他替你督战、替你下短命令，你在旁边纠正。第一次只让他负责收拢点名，第二次让他分配两个组的位置，第三次让他独立带一次绕侧。他能独立收拢一次，才算接得住；接不住就退回上一阶段，不要硬推。

带教不是讲课，是让他做、你在旁边纠正。一次只纠正一个动作，下一局只检查这一个动作；连续三局做到，再教下一个。教得太多，新人只会记住“我什么都做不好”。

::: takeaway
带教按“跟队、专长、固定火力组、副组长、队长”五阶段走，每阶段有出师标准。新兵在前队学看和报，老兵在后队补漏；二队长要独立收拢一次才算接得住。
:::

## 常见指挥错误

| 错误 | 表现 | 后果 | 改法 |
|---|---|---|---|
| 命令只有意图 | “去打那个点” | 组员不知道走哪、何时动 | 补位置、触发、完成信号、限制 |
| 同时改太多 | 一局想练报点、清楼、反载具 | 每项都做一半 | 一局只设一个训练指标 |
| 没有预备队 | 所有人压主攻 | 侧翼一破全盘崩 | 留三到四人堵漏或接替 |
| 不设集结点 | 打散后各自找路 | 重生的人找不到队伍 | 每次移动前说下一个集结点 |
| 追击杀数 | 打退敌人后追出掩体 | 被第二梯队反打 | 给追击设停止线 |
| 忽略后勤 | 弹尽才想起 FOB | 有优势也推不动 | 接敌前报绿黄红，提前叫补给 |
| 复盘变批斗 | 点名骂操作 | 下次没人说真话 | 只谈动作和系统，不贴标签 |
| 赢了不复盘 | 靠敌人失误赢了就过 | 错误动作被固化 | 赢了也走五栏，专找运气分 |

这些错误都不是枪法问题，而是把选择权交给了对手。改法不需要天赋，只需要把动作写清楚并重复到形成条件反射。

::: takeaway
高频指挥错误集中在“说不清、改太多、不留后手、不看后勤”。复盘先在这些结构问题上找证据，不要先怪队员枪法。
:::

## 把复盘结论变成一个动作

复盘最后必须落到一个动作。合格的动作有四个条件：有触发条件，有具体行为，有完成标准，有检查方式。对比三句话：

- “下次注意沟通。”没有触发、没有行为、无法检查。
- “下次多报点。”有方向，但没有标准和检查。
- “进未知房间前先贴墙听两秒，再扔雷，队友到齐才推门；二组组长局末检查三次。”可执行、可计数。

动作要小到下一局一定能做。“全队下车后五秒内报位置”比“提高战场意识”有效一百倍。连续三局记录做到与否：三局至少两局做到，才算形成习惯；三局全没做到，不是队员不听话，而是动作设计太大，继续拆小。

一个动作练成后再叠加下一个。顺序建议：先说清楚，再活下来，再练配合，最后练指挥。倒过来先练指挥，基础漏洞会被放大。

复盘记录只留三行：本局关键事实一条、关键判断一条、下一局动作一条。三行笔记放进下一局开场提醒，比两千字总结更有用。

::: takeaway
复盘结论必须变成“触发、行为、标准、检查”四件套，小到下一局一定能做。连续三局检查，两局做到才算习惯，做不到就继续拆小。
:::

## 决策速查

- 复盘五栏：事实、判断、动作、结果、下次改什么，顺序不能倒。
- 事实写时间、地点、主体、动作、结果，地点用地图具名位置。
- 判断看“当时信息下是否合理”，重点抓“流程错但赢了”。
- 100 小时排序：生存、通信、步兵、指挥、后勤、复杂局面、认证。
- 一局只练一个指标，每周留一小时离线准备，每二十小时回炉基础。
- 复盘选两个指标，和本周主题对齐；数字用来找问题，不用来排名。
- 带教五阶段：跟队、专长、固定火力组、副组长、队长，每阶段有出师标准。
- 复盘只留一个动作，写成四件套，连续三局验证。
- 赢了也要复盘，专门找运气分；输了不批斗，只找系统问题。

::: takeaway
速查表的核心只有两句：用事实约束判断，用一个小动作约束下一局。其余规则都是为了守住这两句。
:::

## 实战案例

地图 Mutaha，小队任务是在西侧外围建 FOB，再配合大部队进攻中心点。开局 300 比 300。队长带两个组坐车到西侧，一组留 FOB，二组和三组前出到清真寺北侧。前十五分钟顺利，FOB 建好，补给卸下，占了两栋楼。

15:40，二组报告北侧街口有敌方步兵。队长判断是小股侦察，命令二组前出清掉，三组原地。二组追出两个街区，在路口被侧面机枪压制，倒两人。队长让三组去救，三组横穿主街时又倒一人。票数变成 272 比 288，FOB 方向同时报告有敌方载具靠近。

队长选择回防 FOB，不继续救二组。命令是“三组剩的人回 FOB，二组能动的往北楼撤，烟自己打”。二组两人撤进北楼，一人被俘；三组回到 FOB 时，敌方载具已经打掉补给卡车，HAB 还在。筒子从院墙后打了一发，逼退载具，但弹药只剩三成。全队收缩防守，局末丢了外围两栋楼，保住 FOB，票数 240 比 262，主攻因缺少西侧压力而失败。

五栏复盘：事实是 15:40 二组追出两个街区，15:42 倒两人，15:43 三组横穿主街倒一人，15:45 补给车被毁，15:50 收缩 FOB。判断是把“街口有步兵”当成小股侦察，没考虑机枪和载具；二组追击没有停止线；三组救援选了没烟、没掩体的直线。动作是二组无人报“已离开楼体二十米”，三组过街前没等烟，队长先派救援而不是确认 FOB。结果是丢两栋楼、一辆补给车，损失五人。下次只改一个动作：任何组离开当前掩体超过二十米，必须先报“出界”并得到队长“可以”，未回答就停在掩体后。

下一局队长开场只强调这一条。二组再次遇到步兵，追到楼角主动报“二组出界”，队长回答“不准，回楼里架枪”。二组停在墙角，用交叉火力逼退敌人。三组过街前等了两颗烟。整局没有单组脱离楼体二十米，票数交换比从 0.8 提升到 1.4。复盘没有加新动作，继续把“出界报告”练了三局。

::: takeaway
找出一个能同时约束多个错误的动作，比分别批评追人、横穿、回防更有效。动作越靠近触发点，下一局越容易执行。
:::

## 常见错误

| 症状 | 原因 | 改法 |
|---|---|---|
| 复盘变成“谁背锅” | 只盯个人操作 | 只谈动作和条件，主持人打断人身评价 |
| 事实栏写满感受 | 没有时间、地点、票数 | 局末先记五个时间节点 |
| 判断栏用结果倒推 | 知道结局后说“早就该” | 只问当时看到什么、有哪些备选 |
| 改进栏列了五条 | 想一次解决所有问题 | 只留一条，写成四件套 |
| 赢了就不复盘 | 把运气当能力 | 赢了也走五栏，专找“流程错但结果好” |
| 训练没有验收 | 练完就算 | 每阶段设一个可观察标准，不达标不前进 |
| 100 小时路线跳阶段 | 基础没稳就练指挥 | 回炉生存和通信，再往上加 |
| 记录写完就丢 | 下一局不提醒、不检查 | 开场念一次动作，连续三局画勾画叉 |

::: takeaway
复盘的敌人不是失败，而是模糊和贪多。事实写具体、判断不倒退、改进只留一条，复盘才有下一次。
:::

## 实战练习

**第一周，五栏复盘。** 连续三局，每局十分钟内写完五栏，事实至少三条、判断至少两条、改进只一条。标准是三局都按时完成，改进栏没有“注意”“提高”这类无法检查的词。

**第二周，动作验证。** 把第一周最后一条改进带进三局，每局记录做到与否。标准是三局至少两局做到；三局都没做到，就把动作拆小一半再试，比如“进楼先听两秒”拆成“进第一道门前停一步”。

**第三周，路线校准。** 对照 100 小时表，找出当前阶段最弱的验收项，安排两小时专项练习。标准是能说出“我在第几阶段、下一个验收动作是什么、什么时候测”。

**第四周，主持复盘。** 让队友讲事实，你只提问，不替他们下结论。标准是复盘结束时由队员自己说出下一局动作，而不是你宣布。

四周后翻记录，看哪类错误重复最多。重复最多的那一类，就是下一个 20 小时的主攻方向。

::: takeaway
练习顺序是“会写五栏、能验证一个动作、校准路线、会主持复盘”。四周后看重复错误，而不是看赢了多少局。
:::

## 自检 3 问

1. 复盘五栏分别写什么？为什么事实栏不能写“打得很乱”？
2. 什么是“流程错但结果好”？为什么它比“流程对但结果差”更危险？
3. 一个合格的“下次改什么”必须包含哪四个部分？从队员到队长要经过哪五个带教阶段？

::: takeaway
能用自己的话答出五栏、四象限和动作四件套，说明复盘已经能落地；答不出，就先把下一局的事实记完整。
:::
