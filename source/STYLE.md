# 邮差战队课程集 · 作者规范

本文件只供作者端使用，不进入发布包。所有课程 Markdown 必须遵守下面的受控写法。

## 一、文件与标题

- 一课一个文件，文件名见 `source/meta.json` 的 `source` 字段。
- 文件开头不要写 `# 标题`。课名由生成器根据 `meta.json` 自动输出。
- 正文第一个章节固定为：

```md
## 学完能做到什么
```

- 正文最后一个章节固定为：

```md
## 自检 3 问
```

- 章节用 `##`，子章节用 `###`。不要跳级使用 `####`。
- 每一节（每个 `##` 到下一个 `##` 之间）必须以一个 `::: takeaway` 块结束。该块是本节结论，不能省略。

## 二、允许的 Markdown 子集

生成器只支持下列写法：

```md
**粗体**、`行内代码`、[文字](https://example.com)

- 无序列表项
- 第二项

1. 有序列表项
2. 第二项

| 列一 | 列二 |
|---|---|
| 内容 | 内容 |

> 引用或提示句

```text
示意图或流程箭头
```
```

图片只在确有必要时使用，且 URL 必须来自 `Squad战术小队攻略_v10.6.html` 已验证的白名单：

```md
![截图说明](https://images.steamusercontent.com/ugc/12569225777935900210/2D5F86A25C8B3B913FCC978327D06790F886F00D/?imw=1280&ima=fit)
```

生成器会自动补 `loading="lazy"`、`decoding="async"`、`referrerpolicy="no-referrer"`，作者不要手写 `<img>`。没有合适图片时不要插图，不要用生成图。

## 三、自定义区块

统一使用三冒号围栏。支持类型：

| 类型 | 用途 |
|---|---|
| `rule` | 决策规则 / 判断口径 |
| `case` | 完整实战案例 |
| `warn` | 风险提示 |
| `tip` | 速查提醒 |
| `mistake` | 常见错误对照 |
| `drill` | 一局内可执行的练习 |
| `takeaway` | 本节结论（每节必须有一个） |

写法：

```md
::: rule 判断口径
- 先看复活点是否稳定，再看人数是否够。
- 复活点不稳时，人数优势不能立刻兑现。
:::
```

标题可省略：

```md
::: tip
 slowed 时先报方向，再报距离。
:::
```

区块内部可以使用列表、表格、粗体、行内代码和引用，但不要嵌套另一个 `:::` 区块。

## 四、每课固定结构

按以下顺序组织正文；标题必须完全一致，章节内部可加 `###` 子标题：

1. `## 学完能做到什么` — 3–5 条可观察动作，用列表写，结尾 `::: takeaway`。
2. 若干正文小节 — 每节包含场景、结论、规则或数值、案例或对照、常见错误，结尾 `::: takeaway`。
3. `## 决策速查` — 3–7 条判断规则，通常用 `::: rule`，结尾 `::: takeaway`。
4. `## 实战案例` — 至少一个 `::: case`，写清局面、判断、动作、结果或代价，结尾 `::: takeaway`。
5. `## 常见错误` — 至少一个 `::: mistake`，按“症状—原因—改法”写，结尾 `::: takeaway`。
6. `## 实战练习` — 至少一个 `::: drill`，写清一局内怎么练、完成标准是什么，结尾 `::: takeaway`。
7. `## 自检 3 问` — 正好 3 个问题，简短，结尾 `::: takeaway`。

## 五、内容要求

- 不写“勘误”“旧教案”“为什么重写”“原攻略说”“上一版”等元叙述。按正常教案口吻写。
- 不出现“新人线”“进阶线”“你是哪种状态？”。
- 不说大段空话。每一节至少包含一种具体信息：判断规则、数值表、流程步骤、完整案例、常见错误对照或示意图。
- 目标字数见 `source/meta.json` 对应阶段：第一阶 3000–4000 汉字，第二阶 3500–5000，第三阶 4000–5500，第四阶 4500–6000，第五阶 4500–6000，第六阶 4000–5500。宁可多写具体规则，不要靠重复堆字。
- 案例要像真的局：有地图区域、双方动作、队长命令、观察结果、代价和复盘。
- 数值必须和 `source/meta.json`、`source/KEY_VALUES.md` 一致。有出入时以 `source/KEY_VALUES.md` 为准。

## 六、语气

- 面向普通玩家，不用堆叠军事术语。必须用术语时，下一句就解释。
- 多用“先……再……”“如果……就……”“不要……而是……”这类可执行的句子。
- 语气稳定、耐心，不嘲笑新手，不喊口号。
- 每段之后用 `::: takeaway` 给出一句能背走的结论。
