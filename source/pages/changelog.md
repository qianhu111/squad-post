## 2026-11-21 · 学习进度与更新日志

- 新增学习进度页：按六阶汇总 36 课完成情况，显示总进度、下一课和每阶进度。
- 课程页的“标记完成”改为手动确认，打开课程不再自动记为完成。
- 新增本页，集中记录课程与站点功能变化。

::: takeaway
进度只保存在当前浏览器；换设备后需要重新标记。
:::

## 2026-11-20 · 版式与可读性

- 加宽页面容器：普通页面 1200px，课程正文 1000px，正文阅读列 860px。
- 修复页面级横向滚动条，完善 1280 / 1100 / 900 / 760 / 480 断点。
- 顶栏导航改为居中框式按钮，窄屏逐步收起次要入口。
- 标签索引与标签页改为带框卡片，增加计数、描边与主题色。

::: takeaway
宽屏不再把正文挤在中间，窄屏也不会出现左右滚动。
:::

## 2026-11-20 · 标签、RSS 与阅读设置

- 新增 14 个主题标签，课程页显示标签 chips，可按标签浏览。
- 新增 Atom 订阅：`/feed.xml`。
- 新增四套主题：浅色、深色、纸张、高对比。
- 新增阅读模式与三档正文字号。

::: takeaway
阅读偏好保存在本地；阅读模式会隐藏导航和侧栏，只保留正文。
:::

## 2026-11-20 · SEO 与阅读信息

- 每页增加 canonical、Open Graph、Twitter Card 与 JSON-LD。
- 新增 `sitemap.xml` 与 `robots.txt`，并为后台与 API 路径预留屏蔽规则。
- 课程页显示正文约多少字、阅读约几分钟。
- 二三级标题增加 `#` 锚点；图片补充宽高，减少布局跳动。

::: takeaway
搜索引擎能读到完整课程结构，分享链接也有标题、摘要和封面。
:::
