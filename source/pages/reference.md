## 使用说明

速查表是给已经在局里的人看的。按需要直接跳到对应表格，不必从头读。

阅读顺序建议：先看复活与压制，再看票数，最后看报点模板。新兵最容易在 30 米 / 50 米和 30 秒 / 60 秒之间混，下面已经按使用场景分开。

## 数值适用范围与优先级

本页和课程里的数字，是当前版本、官方默认规则的**学习基线**：没有特殊配置时，照着它判断就够了。实际这一局以哪儿为准，按下面顺序。

| 优先级 | 来源 | 说明 |
|---:|---|---|
| 1 | 当前游戏内的记分板、部署界面、地图层信息与可见提示 | 打起来之后唯一的操作依据 |
| 2 | 服务器公告、规则、MOTD 与管理员指令 | 可能改票数、重生时间、载具限制和建造规则 |
| 3 | 这一局选中的模式层与启用的 mod | 层配置、mod 都会改动具体数值 |
| 4 | 本站课程与速查表 | 官方默认值，只用来学习和预估 |

三条使用规则：

- **以本局面板为准**：进了服务器先按 `Tab` 看一眼票数和载具表，别拿速查表里的数字跟面板较劲。
- **发现不一致就报告**：课程值和面板值对不上时，按面板打，并在小队语音里说一句“本局是 X 票，不是 20”，让队友一起对齐。
- **载具票值按局面板查**：速查表只给通用档位（步兵 1、轻车 5、中车 10、坦克 15、电台 20）。具体车型在不同服务器、mod 和层里可能被单独改价，不在这里列表，也不要做成固定答案。

::: takeaway
速查表只记结论，且是官方默认口径；服务器和本局面板改了哪项，就按哪项打。要理解为什么，回到对应课次。
:::

## 复活、压制与队包

| 项目 | 数值 | 使用场景 |
|---|---|---|
| HAB 压制 | 2 名敌人 20 米起，每多 1 人 +10 米，最高 9 人 90 米 | 判断兵站还能不能可靠复活 |
| 压制口径 | 倒地敌人、载具内敌人不计入压制 | 不要把打倒和压制混为一谈 |
| 解除压制 | 敌人离开或倒地后，兵站还需 30 秒恢复复活 | 听到“压制解除”也要再等 |
| 步兵队长放队包 | 15 米内 1 名本队队员 | 步兵队长装 |
| 载具 / 飞行员队长放队包 | 15 米内至少 3 名本队队员 | 载具 / 飞行员队长装 |
| 队包复活 | 60 秒一波，基础复活 30 秒 | 计划下一波出发时间 |
| 队包放置冷却 | 150 秒 | 放歪或被踩后要重新算 |
| 队包被踩 | 30 米内有敌人或敌方载具即消失 | 重生前先看周围 |
| 队包禁放 | 50 米内有敌人放不下来，进入 120 秒冷却 | 不要在敌人眼皮底下放 |
| FOB 电台间距 | 至少 400 米 | 防止一片兵站连成连锁点 |
| FOB 建造圈 | 电台周围 150 米 | 兵站和工事必须在圈内 |
| 电台被毁 | −20 票；主动拆不扣票 | 撤离前优先自拆 |
| 电台流血 | 75 秒；修到 50 HP 可救回 | 守住 75 秒就有机会 |
| HAB 造价 | 500 建材 | 别把建材浪费在无人区 |
| HAB 复活 | 基础 45 秒；新建 / 修复后 30 秒才能复活 | 刚修好别立刻冲 |

::: takeaway
压制看人数和距离，队包看 15 / 30 / 50 米，电台看 400 / 150 米和 75 秒。
:::

## 票数与占领

| 动作 | 票数 | 备注 |
|---|---|---|
| 抢占敌方已占领点 | 我方 +50，敌方 −10 | 净摆动 60 票 |
| 丢失己方已占领点 | 我方 −10，敌方 +50 | 净摆动 −60 票 |
| 占领中立点 | 通常 +20 | 拉白本身不加分，成功占领时结算 |
| 拉白 | 0 | 只改变控制，不结算票 |
| FOB 电台被毁 | −20 票 | 主动拆不扣 |
| 医疗兵救起队友 | 避免队友复活的票消耗 | 救人也是省票 |

::: takeaway
抢敌方点是 +50／−10，净摆动 60；丢点是 −10／+50，净摆动 −60；中立点是 +20，拉白是 0。
:::

## 迫击炮刻度（社区经验值，以游戏内为准）

| 档位 | 经验刻度 | 用途 |
|---|---|---|
| 4.16 | 10 米 | 近距离微调 |
| 8.3 | 20 米 | 小范围修正 |
| 12.5 | 30 米 | 中距离修正 |
| 16.6 | 40 米 | 中远距离修正 |
| 20.8 / 21 | 50 米 | 远距离修正，常记作 21 |

常见社区经验口径为“1 刻度约 2.4 米”。这只是帮助记忆的近似值；实战看炮手屏幕上的刻度和实际落点。

::: takeaway
刻度只用于修正落点；报给炮手的是“落点相对目标在哪里，往哪修多少”。
:::

## 报点模板

### 文字 / 语音模板

> 队长，[目标类型]，[参照物 + 方位]，距离约 [距离]，[状态 / 紧迫性]。

完整示例：

> 队长，机枪，音符西北方向树林边缘，距离约一百二十米，正在压我们，请求压制。

### 目标信息五要素

| 要素 | 要说什么 | 反例 |
|---|---|---|
| 类型 | 机枪 / 步枪组 / 载具 / 单兵 | “那边有人” |
| 位置 | 地图标记 + 参照物 + 方位 | “在前面” |
| 距离 | 约多少米，或远近档位 | “挺远” |
| 状态 | 静止 / 移动 / 倒地 / 进建筑 | “好像在动” |
| 紧迫性 | 正在压制 / 不急 / 需要马上处理 | 什么都不说 |

::: takeaway
好报点让队长不用追问；坏报点只制造更多通话。
:::

## 常见术语

| 术语 | 常用含义 |
|---|---|
| FOB | 前线作战基地，核心是电台和建造圈 |
| HAB | 兵站，提供复活点，不提供弹药 |
| Rally / 队包 | 小队复活点，60 秒一波 |
| 拉白 | 占领条开始推进，但占领尚未结算 |
| 红线 | 据点周围的无效边界，不是安全线 |
| 压制 | 一定数量和距离内的敌人让 HAB 暂时不能复活 |
| 补枪 | 队友已击中目标后，跟进补第二枪确保击倒 |
| 回声 | 接收命令的人复述一遍，确认没听错 |

::: takeaway
术语不用背得花哨，能把状态说清楚最重要。
:::
